Referencia de Lua · Componente

UiEffects

Efectos: componente (Interfaz). Degradado, sombra, resplandor, sombra interior y decoraciones (patrón, raya de acento y brillo) del fondo del elemento

entidad:GetComponent("UiEffects") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

gradient campo

UiEffects.gradient: "None" | "Linear" | "Radial"
Degradado (en el Inspector). Sustituye al color de la imagen

gradientStart campo

UiEffects.gradientStart: Color
Color inicial (en el Inspector).

gradientEnd campo

UiEffects.gradientEnd: Color
Color final (en el Inspector).

gradientUseMiddle campo

UiEffects.gradientUseMiddle: boolean
Tres colores (en el Inspector).

gradientMiddle campo

UiEffects.gradientMiddle: Color
Color del medio (en el Inspector).

gradientMiddlePosition campo

UiEffects.gradientMiddlePosition: number
Posición del medio (en el Inspector). De 0 a 1.

gradientAngle campo

UiEffects.gradientAngle: number
Ángulo (en el Inspector). 0°: de izquierda a derecha; 90°: de arriba abajo En radianes desde Lua (el Inspector lo enseña en grados): math.rad(90) para 90°.

shadow campo

UiEffects.shadow: boolean
Sombra (en el Inspector).

shadowOffset campo

UiEffects.shadowOffset: Vec2
Desplazamiento de la sombra (en el Inspector).

shadowBlur campo

UiEffects.shadowBlur: number
Desenfoque de la sombra (en el Inspector). De 0 a 200.

shadowSpread campo

UiEffects.shadowSpread: number
Extensión de la sombra (en el Inspector). De -100 a 100.

shadowColor campo

UiEffects.shadowColor: Color
Color de la sombra (en el Inspector).

glow campo

UiEffects.glow: boolean
Resplandor (en el Inspector).

glowSize campo

UiEffects.glowSize: number
Tamaño del resplandor (en el Inspector). De 0 a 200.

glowColor campo

UiEffects.glowColor: Color
Color del resplandor (en el Inspector).

innerShadow campo

UiEffects.innerShadow: boolean
Sombra interior (en el Inspector).

innerShadowOffset campo

UiEffects.innerShadowOffset: Vec2
Desplazamiento interior (en el Inspector).

innerShadowBlur campo

UiEffects.innerShadowBlur: number
Desenfoque interior (en el Inspector). De 0 a 200.

innerShadowColor campo

UiEffects.innerShadowColor: Color
Color de la sombra interior (en el Inspector).

pattern campo

UiEffects.pattern: "None" | "DiagonalStripes" | "HorizontalStripes" | "VerticalStripes" | "HazardStripes" | "Dots" | "Grid" | "Checker" | "Scanlines" | "Noise" | "Hexagons" | "Triangles" | "Diamonds" | "Argyle" | "Scales" | "Zigzag" | "Waves" | "Radar" | "Sunburst" | "Spiral" | "Bricks" | "Tiles" | "Weave" | "Herringbone" | "PerspectiveGrid" | "Circuit" | "Topographic" | "Camouflage" | "Clouds" | "Voronoi" | "Stars" | "Confetti" | "Halftone" | "Tartan" | "CrossHatch" | "CarbonFiber"
Patrón (en el Inspector). Un dibujo encima del color o del degradado, sin texturas: rayas, puntos, hexágonos, circuito...

patternColor campo

UiEffects.patternColor: Color
Color del patrón (en el Inspector). El dibujo: las líneas, los puntos, las piezas...

patternColor2 campo

UiEffects.patternColor2: Color
Segundo color (en el Inspector). El fondo del patrón (transparente: se ve el del elemento). En las rayas de peligro, el negro

patternScale campo

UiEffects.patternScale: number
Escala (separación) (en el Inspector). Tamaño de cada celda del patrón, en unidades del lienzo De 2 a 2000.

patternThickness campo

UiEffects.patternThickness: number
Grosor (en el Inspector). Grosor de las líneas o tamaño de los puntos (parte de la celda) De 0 a 1.

patternAngle campo

UiEffects.patternAngle: number
Ángulo del patrón (en el Inspector). En radianes desde Lua (el Inspector lo enseña en grados): math.rad(90) para 90°.

patternOpacity campo

UiEffects.patternOpacity: number
Opacidad del patrón (en el Inspector). De 0 a 1.

patternScroll campo

UiEffects.patternScroll: Vec2
Desplazamiento (unidades/s) (en el Inspector). Animado: hacia dónde y cuánto se mueve por segundo (0, 0: quieto). Los patrones con centro (radar, rayos de sol, espiral) crecen o giran y la rejilla en perspectiva avanza

patternWarp campo

UiEffects.patternWarp: number
Distorsión (en el Inspector). Ondula el dibujo (más orgánico) De 0 a 1.

patternSoftness campo

UiEffects.patternSoftness: number
Suavizado (en el Inspector). Bordes del dibujo más suaves (0: nítidos) De 0 a 1.

patternBlend campo

UiEffects.patternBlend: "Normal" | "Add"
Mezcla (en el Inspector). Normal: pinta encima. Sumar: añade luz (líneas que brillan)

accentStripe campo

UiEffects.accentStripe: "None" | "Left" | "Right" | "Top" | "Bottom" | "Diagonal"
Raya de acento (en el Inspector). Una barra de color en un borde o una franja diagonal que cruza el elemento

accentStripeColor campo

UiEffects.accentStripeColor: Color
Color de la raya (en el Inspector).

accentStripeWidth campo

UiEffects.accentStripeWidth: number
Grosor de la raya (en el Inspector). De 0 a 2000.

accentStripeAngle campo

UiEffects.accentStripeAngle: number
Ángulo de la raya (en el Inspector). Franja diagonal: inclinación respecto a la vertical En radianes desde Lua (el Inspector lo enseña en grados): math.rad(90) para 90°.

accentStripePosition campo

UiEffects.accentStripePosition: number
Posición de la raya (en el Inspector). Franja diagonal: por dónde cruza (0: a la izquierda; 1: a la derecha) De 0 a 1.

accentStripeOpacity campo

UiEffects.accentStripeOpacity: number
Opacidad de la raya (en el Inspector). De 0 a 1.

shine campo

UiEffects.shine: "None" | "Always" | "Interval" | "Hover"
Brillo (en el Inspector). Un destello diagonal que barre el elemento

shineColor campo

UiEffects.shineColor: Color
Color del brillo (en el Inspector).

shineWidth campo

UiEffects.shineWidth: number
Ancho del brillo (en el Inspector). De 1 a 2000.

shineAngle campo

UiEffects.shineAngle: number
Ángulo del brillo (en el Inspector). Inclinación respecto a la vertical En radianes desde Lua (el Inspector lo enseña en grados): math.rad(90) para 90°.

shineSpeed campo

UiEffects.shineSpeed: number
Velocidad del brillo (en el Inspector). 1: cruza el elemento en un segundo; 2: en medio segundo De 0.05 a 20.

shineInterval campo

UiEffects.shineInterval: number
Cada (segundos) (en el Inspector). Con «Cada X segundos»: segundos entre un destello y el siguiente De 0.1 a 600.

entity campo

UiEffects.entity: Entity
La entidad que tiene este componente.
