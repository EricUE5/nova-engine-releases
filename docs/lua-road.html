Referencia de Lua · Componente

Road

Carretera: componente (Splines). Carretera a lo largo del Spline de la entidad

entidad:GetComponent("Road") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

width campo

Road.width: number
Anchura (en el Inspector). Metros de calzada (sin arcenes) De 1 a 40.

lanes campo

Road.lanes: number
Carriles (en el Inspector). De 1 a 8.

surface campo

Road.surface: "Asphalt" | "Dirt" | "Concrete"
Firme (en el Inspector).

centerLine campo

Road.centerLine: "None" | "Dashed" | "Solid" | "DoubleSolid"
Línea central (en el Inspector).

edgeLines campo

Road.edgeLines: boolean
Líneas de borde (en el Inspector).

shoulderWidth campo

Road.shoulderWidth: number
Arcén (en el Inspector). Metros a cada lado De 0 a 10.

shoulder campo

Road.shoulder: "Gravel" | "Dirt" | "Asphalt" | "Grass"
Tipo de arcén (en el Inspector).

sidewalks campo

Road.sidewalks: boolean
Aceras (en el Inspector). Aceras con bordillo a los dos lados

sidewalkWidth campo

Road.sidewalkWidth: number
Anchura de la acera (en el Inspector). De 0.1 a 10.

curbHeight campo

Road.curbHeight: number
Altura del bordillo (en el Inspector). De 0 a 0.5.

conformToGround campo

Road.conformToGround: boolean
Apoyar en el suelo (en el Inspector). Cada vértice se apoya en el terreno o en las mallas estáticas de debajo

groundOffset campo

Road.groundOffset: number
Altura sobre el suelo (en el Inspector). De 0 a 2.

skirtDepth campo

Road.skirtDepth: number
Faldón (en el Inspector). Metros de pared bajo los bordes (tapa huecos con el terreno) De 0 a 5.

segmentLength campo

Road.segmentLength: number
Longitud de tramo (en el Inspector). Metros entre secciones De 0.1 a 20.

widthSegments campo

Road.widthSegments: number
Divisiones a lo ancho (en el Inspector). De 1 a 16.

collision campo

Road.collision: boolean
Colisión (en el Inspector). Colisionador de malla al jugar (los coches y personajes la pisan)

castShadows campo

Road.castShadows: boolean
Proyecta sombras (en el Inspector).

adaptTerrain campo

Road.adaptTerrain: boolean
Adaptar el terreno (en el Inspector). El terreno sigue a la carretera: si la subes se hace un terraplén y si la bajas corta la ladera. No destruye el terreno: al moverla o borrarla vuelve a estar como antes

conformSlope campo

Road.conformSlope: number
Talud (en el Inspector). Grados de la pendiente del terraplén y del desmonte De 10 a 80.

flattenMargin campo

Road.flattenMargin: number
Margen (en el Inspector). Metros más allá de los arcenes que quedan planos (al adaptar o aplanar el terreno) De 0 a 20.

flattenFalloff campo

Road.flattenFalloff: number
Transición (en el Inspector). Metros de transición hasta el terreno de alrededor (al adaptarlo, redondea el pie del talud) De 0 a 50.

paintLayer campo

Road.paintLayer: number
Capa bajo los arcenes (en el Inspector). Capa del terreno que se pinta con «Aplanar terreno» o «Fijar en el terreno» (-1 = ninguna) De -1 a 15.

entity campo

Road.entity: Entity
La entidad que tiene este componente.

ApplyPreset método

Road:ApplyPreset(preset: "TwoLane" | "DirtTrack" | "Highway" | "Street"): (): ()
Aplica un preajuste: "TwoLane" (carretera de 2 carriles), "DirtTrack" (camino de tierra), "Highway" (autopista) o "Street" (calle con aceras).
