ParticleSystem

Sistema de partículas: componente (Efectos). Fuego, humo, chispas, explosiones, lluvia... (Entidad > Efectos tiene preajustes)

entidad:GetComponent("ParticleSystem") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

Play método

ParticleSystem:Play(): (): ()
Empieza a emitir (o sigue si estaba en pausa).

Stop método

ParticleSystem:Stop(clear: boolean?): (): ()
Deja de emitir; con true, borra también las partículas que quedan.

Pause método

ParticleSystem:Pause(): (): ()
Congela el sistema.

Clear método

ParticleSystem:Clear(): (): ()
Borra las partículas.

Restart método

ParticleSystem:Restart(): (): ()
Empieza de cero.

Emit método

ParticleSystem:Emit(count: number, overrides: ParticleOverrides?): number
Emite ya n partículas en la forma del emisor (con cambios opcionales: color, tamaño, velocidad, vida, normal, semilla...). Devuelve cuántas.

EmitAt método

ParticleSystem:EmitAt(position: Vec3, count: number?, overrides: ParticleOverrides?): number
Emite n partículas (1 si no se dice) con la forma centrada en esa posición del mundo: chispas:EmitAt(golpe.point, 20, { normal = golpe.normal }).
