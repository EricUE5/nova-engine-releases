Steam

Steam: el jugador, sus amigos y su avatar, lobbies con invitaciones, estado para los amigos, logros, estadísticas, tablas, overlay y DLC. Sin Steam (o en el editor sin el simulado) todo devuelve false, "" o nil sin errores. Los avisos llegan como eventos: AddEventHandler("steam:overlay", function(abierto) ... end). Guía: docs/steam.md.

IsAvailable función

Steam.IsAvailable(): boolean
true si Steam (real o simulado) está iniciado en este juego.

IsSimulated función

Steam.IsSimulated(): boolean
true con el Steam simulado (editor, --steam-simulado): lobbies e invitaciones entre ventanas del mismo PC, sin Steam.

StatusText función

Steam.StatusText(): string
Texto con el estado de Steam para un menú o la depuración: nombre, App ID y lobby.

LastError función

Steam.LastError(): string
El último error de Steam explicado (no se pudo crear el lobby, el lobby está lleno...).

GetAppId función

Steam.GetAppId(): number
El App ID del juego en Steam (0 sin Steam).

GetSteamID función

Steam.GetSteamID(): string
El SteamID del jugador como texto ("" sin Steam). Los SteamID son textos en Lua.

GetPersonaName función

Steam.GetPersonaName(): string
El nombre del jugador en Steam.

GetFriendName función

Steam.GetFriendName(steamId: string): string
El nombre de un amigo o de alguien del lobby por su SteamID.

GetFriends función

Steam.GetFriends(): {SteamFriend}
Los amigos del jugador: { { id, name, online, playingThisGame, state } }, primero los que juegan a este juego. state: "online", "offline", "busy", "away", "snooze", "lookingToPlay"... Su avatar: Steam.GetAvatarAsync(amigo.id, f).

GetAvatar función

Steam.GetAvatar(steamId: string?, size: ("small" | "medium" | "large")?): Asset?
El avatar de un jugador (sin id: el tuyo) como textura para la interfaz: imagen:SetSprite(Steam.GetAvatar(id)). Tamaño "small" (32), "medium" (64, por defecto) o "large" (184). Devuelve nil mientras Steam lo descarga: vuelve a pedirlo con el evento steam:avatarLoaded o, más fácil, usa Steam.GetAvatarAsync.

GetAvatarAsync función

Steam.GetAvatarAsync((steamId: string?, size: ("small" | "medium" | "large")?, callback: (avatar: Asset?, steamId: string) -> ()) -> boolean)         & ((steamId: string?, callback: (avatar: Asset?, steamId: string) -> ()) -> boolean)         & ((callback: (avatar: Asset?, steamId: string) -> ()): boolean)
Pide el avatar de un jugador (sin id: el tuyo) y llama a tu función con la textura cuando llega (enseguida si ya estaba): Steam.GetAvatarAsync(id, "medium", function(avatar) if avatar then UI("Foto"):SetSprite(avatar) end end). Si no llega (no tiene, sin Steam o 15 s), la llama con nil. Queda en caché: pedirlo otra vez es instantáneo. Devuelve false sin Steam.

IsSteamDeck función

Steam.IsSteamDeck(): boolean
true si el juego corre en una Steam Deck (para elegir la calidad o los controles por defecto).

IsBigPicture función

Steam.IsBigPicture(): boolean
true en el modo Big Picture de Steam (y en la Steam Deck): pantalla grande y mando.

SetLocalFallback función

Steam.SetLocalFallback(on: boolean?): ()
Sin Steam, los logros, estadísticas y tablas se guardan en local (steam-local.json en la carpeta de guardado) para poder probar el juego. Steam.SetLocalFallback(false) lo apaga: sin Steam devuelven false y nil.

IsUsingLocalStats función

Steam.IsUsingLocalStats(): boolean
true si los logros, estadísticas y tablas se están guardando en local (no hay Steam).

GetLanguage función

Steam.GetLanguage(): string
El idioma elegido en Steam para el juego ("spanish", "latam", "english"...).

GetLanguageCode función

Steam.GetLanguageCode(): string
El idioma de Steam como código ("es", "es-419", "en"...). Para el idioma por defecto del juego mejor Application.GetLanguage().

IsSubscribed función

Steam.IsSubscribed(appId: number?): boolean
Sin App ID: true si el jugador tiene el juego. Con App ID: si tiene esa app o DLC.

IsDlcInstalled función

Steam.IsDlcInstalled(appId: number): boolean
true si el DLC de ese App ID está comprado e instalado.

IsOverlayEnabled función

Steam.IsOverlayEnabled(): boolean
true si el overlay de Steam (Mayús+Tab) funciona en este juego.

IsOverlayOpen función

Steam.IsOverlayOpen(): boolean
true mientras el overlay de Steam está abierto (también llega el evento steam:overlay).

OpenOverlay función

Steam.OpenOverlay(dialog: string?): boolean
Abre el overlay en una página: "friends" (por defecto), "achievements", "community", "settings"...

OpenStore función

Steam.OpenStore(appId: number?): boolean
Abre la página de la tienda del juego (o de ese App ID, por ejemplo un DLC) en el overlay.

OpenUrl función

Steam.OpenUrl(url: string): boolean
Abre una página web en el navegador del overlay.

OpenProfile función

Steam.OpenProfile(steamId: string?): boolean
Abre el perfil de Steam de ese jugador (sin id: el tuyo).

CreateLobby función

Steam.CreateLobby(options: SteamLobbyOptions?): boolean
Crea un lobby y entra: Steam.CreateLobby({ type = "friends", maxPlayers = 8 }). Tipos: "public" (sale en las búsquedas), "friends" (los amigos lo ven), "private" (solo con invitación) e "invisible". Opciones: name, map, mode, data (tus datos), invite = true (abre el diálogo de invitar) y startHost (por defecto true: tu partida arranca como anfitrión por Steam y los que entren se conectan solos). Avisa con steam:lobbyCreated o steam:lobbyFailed.

JoinLobby función

Steam.JoinLobby(lobbyId: string): boolean
Entra en un lobby por su id (de FindLobbies o de una invitación). Cuando su anfitrión tiene la partida abierta, te conectas solo. Avisa con steam:lobbyEntered o steam:lobbyFailed.

LeaveLobby función

Steam.LeaveLobby(): ()
Sale del lobby (la partida en red sigue hasta Network.Disconnect).

GetLobby función

Steam.GetLobby(): SteamLobby?
El lobby en el que estás o nil: { id, name, map, mode, owner, host, members, maxMembers, isOwner, data }.

GetLobbyMembers función

Steam.GetLobbyMembers(): {SteamLobbyMember}
Los miembros del lobby: { { id, name, isOwner, isLocal } }.

IsLobbyOwner función

Steam.IsLobbyOwner(): boolean
true si eres el dueño del lobby (solo él cambia sus datos).

SetLobbyData función

Steam.SetLobbyData(key: string, value: string): boolean
Solo el dueño: guarda un dato del lobby que ven todos y las búsquedas ("piso", "7"). Avisa con steam:lobbyDataChanged.

GetLobbyData función

Steam.GetLobbyData(key: string, lobbyId: string?): string
Un dato del lobby actual (o de un lobby de la búsqueda, con su id).

SetLobbyMemberData función

Steam.SetLobbyMemberData(key: string, value: string): boolean
Guarda un dato tuyo en el lobby (personaje elegido, listo...) que ven los demás.

GetLobbyMemberData función

Steam.GetLobbyMemberData(steamId: string, key: string): string
Un dato de un miembro del lobby.

SetLobbyJoinable función

Steam.SetLobbyJoinable(joinable: boolean): boolean
Solo el dueño: abre o cierra el lobby a nuevas entradas (ciérralo al empezar la partida).

SetLobbyType función

Steam.SetLobbyType(lobbyType: "public" | "friends" | "private" | "invisible"): boolean
Solo el dueño: cambia el tipo del lobby ("public", "friends", "private", "invisible").

SendLobbyChat función

Steam.SendLobbyChat(text: string): boolean
Envía un mensaje al chat del lobby: llega a todos con steam:lobbyChat(id, nombre, texto).

FindLobbies función

Steam.FindLobbies(filter: SteamLobbyFilter?, callback: (lobbies: {SteamLobby}) -> ()): boolean
Busca lobbies públicos de este juego y versión y llama a tu función con la lista: Steam.FindLobbies({ map = "Torre" }, function(lista) ... end). Filtros: map, mode, data, freeSlots, distance, max, sameVersion.

InviteFriends función

Steam.InviteFriends(): boolean
Abre el diálogo de invitar amigos del overlay de Steam para el lobby actual. El amigo que acepta entra en el lobby y se conecta solo (aunque tuviera el juego cerrado).

InviteFriend función

Steam.InviteFriend(steamId: string): boolean
Invita a un amigo al lobby actual sin el overlay (le llega una invitación de Steam).

SetStatus función

Steam.SetStatus(text: string?): boolean
Tu estado para los amigos en Steam: Steam.SetStatus("Piso 7"). Sin llamarla, en un lobby sale solo «En el lobby 3/8». nil vuelve al automático. Necesita el fichero de rich presence subido a Steamworks (docs/steam.md).

SetRichPresence función

Steam.SetRichPresence(key: string, value: string?): boolean
Pone una clave del rich presence de Steam tal cual (avanzado; para el estado usa SetStatus).

ClearRichPresence función

Steam.ClearRichPresence(): ()
Borra todo tu rich presence.

UnlockAchievement función

Steam.UnlockAchievement(id: string): boolean
Desbloquea un logro (su id de Ajustes del proyecto > Steam) y lo guarda: sale la notificación de Steam. Avisa con steam:achievementUnlocked. Sin Steam se guarda en local (ver Steam.SetLocalFallback).

ClearAchievement función

Steam.ClearAchievement(id: string): boolean
Vuelve a bloquear un logro (para probar).

IsAchievementUnlocked función

Steam.IsAchievementUnlocked(id: string): boolean
true si el jugador ya tiene ese logro.

IndicateAchievementProgress función

Steam.IndicateAchievementProgress(id: string, current: number, max: number): boolean
Enseña el progreso de un logro (notificación «3/10»); no lo desbloquea.

GetAchievements función

Steam.GetAchievements(): {SteamAchievement}
Los logros con su estado: { { id, name, description, hidden, unlocked } }.

SetStat función

Steam.SetStat(id: string, value: number): boolean
Cambia una estadística (entera o decimal según Ajustes del proyecto > Steam). Guarda con Steam.StoreStats().

GetStat función

Steam.GetStat(id: string): number?
El valor de una estadística (o nil).

AddStat función

Steam.AddStat(id: string, amount: number?): number?
Suma a una estadística (1 si no dices cuánto) y devuelve el valor nuevo. Guarda con Steam.StoreStats().

StoreStats función

Steam.StoreStats(): boolean
Envía a Steam las estadísticas y logros cambiados (llámalo al acabar una ronda, no cada frame).

ResetStats función

Steam.ResetStats(achievementsToo: boolean?): boolean
Pone a cero las estadísticas (y los logros con true): solo para probar.

UploadScore función

Steam.UploadScore(board: string, score: number, options: { keepBest: boolean?, ascending: boolean? }?, callback: ((result: SteamScores) -> ())?): boolean
Sube una puntuación a una tabla de clasificación (se crea si no existe): Steam.UploadScore("Pisos", 12, nil, function(r) print(r.rank) end). Opciones: keepBest (por defecto true) y ascending (menos es mejor).

GetScores función

Steam.GetScores(board: string, options: { range: ("global" | "friends" | "around")?, from: number?, to: number? }?, callback: (result: SteamScores) -> ()): boolean
Lee una tabla de clasificación y llama a tu función con { ok, entries = { { id, name, rank, score } } }. Opciones: range ("global", "friends" o "around"), from y to.
