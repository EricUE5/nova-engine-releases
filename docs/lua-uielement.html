Referencia de Lua · Tipo

UiElement

Un elemento de la interfaz (UI("ruta")). Si la ruta no existe, sus funciones no hacen nada y se avisa una vez.

IsValid método

UiElement:IsValid(): boolean
true si el elemento existe.

GetEntity método

UiElement:GetEntity(): Entity?
La entidad del elemento (o nil).

GetID método

UiElement:GetID(): string
El UUID de su entidad (texto).

Child método

UiElement:Child(path: string): UiElement
Un hijo por su ruta desde este elemento: casilla:Child("Cantidad").

Slot método

UiElement:Slot(index: number): UiElement
La casilla de ese índice de una rejilla de casillas.

SetText método

UiElement:SetText(text: string | number): UiElement
Texto de un texto, un campo de texto o un botón: UI("HUD/Munición"):SetText("12 / 90").

GetText método

UiElement:GetText(): string
El texto del elemento (lo escrito en un campo de texto; con Texto traducido, la traducción que se ve).

SetTextKey método

UiElement:SetTextKey(key: string?): UiElement
El texto sigue una clave de la tabla de idiomas y cambia solo con el idioma: UI("Menú/Jugar"):SetTextKey("menu.jugar"). nil la quita. SetText también la quita.

SetValue método

UiElement:SetValue(value: number): UiElement
Valor de una barra, deslizador, barra radial, interruptor (> 0,5), desplegable o pestañas (índice).

GetValue método

UiElement:GetValue(): number
El valor de una barra, deslizador, interruptor, desplegable o pestañas.

SetOptions método

UiElement:SetOptions(options: {string}): UiElement
Las opciones de un desplegable o de un selector numérico.

SetVisible método

UiElement:SetVisible(visible: boolean): UiElement
Lo muestra u oculta (las pantallas, con su transición).

Show método

UiElement:Show(): UiElement
Lo muestra: las pantallas con su transición (ya ese mismo frame); lo demás se activa.

Hide método

UiElement:Hide(): UiElement
Lo oculta: las pantallas con su transición; lo demás se desactiva.

Toggle método

UiElement:Toggle(): UiElement
Lo muestra si está oculto y lo oculta si se ve.

IsVisible método

UiElement:IsVisible(): boolean
true si se ve.

SetInteractable método

UiElement:SetInteractable(interactable: boolean): UiElement
Activa o desactiva un botón, campo o control (desactivado se ve atenuado y no responde).

SetColor método

UiElement:SetColor(color: Color | Vec4): UiElement
Color de una imagen o un texto.

SetSprite método

UiElement:SetSprite(sprite: Asset | string | nil): UiElement
La imagen de un elemento (Asset o ruta: "sprites/espada.png"; nil la quita).

SetPosition método

UiElement:SetPosition(position: Vec2 | number, y: number?): UiElement
Desplazamiento desde sus anclajes (Vec2 o x, y).

SetSize método

UiElement:SetSize(size: Vec2 | number, y: number?): UiElement
Tamaño en unidades del lienzo (Vec2 o ancho, alto).

WasClicked método

UiElement:WasClicked(): boolean
true el frame en que se ha pulsado (sondeo, en Update).

ValueChanged método

UiElement:ValueChanged(): boolean
true el frame en que ha cambiado su valor (sondeo, en Update).

WasSubmitted método

UiElement:WasSubmitted(): boolean
true el frame en que se ha enviado un campo de texto con Intro (sondeo).

Focus método

UiElement:Focus(): UiElement
Le da el foco (un campo de texto con el foco se edita y se queda el teclado).

FadeTo método

UiElement:FadeTo(alpha: number, seconds: number): UiElement
Animación sencilla de la opacidad hasta alpha en esos segundos.

MoveTo método

UiElement:MoveTo(offset: Vec2, seconds: number): UiElement
Animación sencilla del desplazamiento hasta offset en esos segundos.

ScaleTo método

UiElement:ScaleTo(scale: Vec2, seconds: number): UiElement
Animación sencilla de la escala en esos segundos.

TintTo método

UiElement:TintTo(color: Color | Vec4, seconds: number): UiElement
Animación sencilla del color en esos segundos.

StopTweens método

UiElement:StopTweens(): UiElement
Para sus animaciones sencillas (FadeTo, MoveTo...).

ScreenRect método

UiElement:ScreenRect(): (Vec2, Vec2): ()
Su rectángulo en píxeles de la vista del juego: esquina y tamaño.

GetScale método

UiElement:GetScale(): number
La escala de su lienzo: cuántos píxeles de la vista es una unidad del lienzo (la del escalador; con «igualar alto» y 1080 de referencia, alto / 1080).

CellAt método

UiElement:CellAt(viewPosition: Vec2): (UiElement?, number?): ()
El hijo bajo ese punto en píxeles de la vista (una casilla de un UiSlotGrid o de una rejilla) y su número (desde 1), o nil: local casilla, n = UI("Inventario/Rejilla"):CellAt(Input.MouseViewPosition()).

ViewToCanvas método

UiElement:ViewToCanvas(viewPosition: Vec2): Vec2
Pasa una posición en píxeles de la vista (Input.MouseViewPosition(), ScreenRect) a unidades de su lienzo: UI("HUD"):ViewToCanvas(Input.MouseViewPosition()).

CanvasToView método

UiElement:CanvasToView(canvasPosition: Vec2): Vec2
Al revés que ViewToCanvas: de unidades de su lienzo a píxeles de la vista.

OnClick método

UiElement:OnClick(fn: (e: UiEvent) -> ()): number
Oyente de los clics: UI("Menú/Jugar"):OnClick(function(e) self:Empezar() end). Devuelve un id para RemoveListener; se quita solo al destruirse el script.

OnValueChanged método

UiElement:OnValueChanged(fn: (value: number, e: UiEvent) -> ()): number
Oyente de los cambios de valor (deslizador, interruptor, desplegable, lista...): recibe el valor y el evento.

OnSubmit método

UiElement:OnSubmit(fn: (text: string, e: UiEvent) -> ()): number
Oyente de un campo de texto al pulsar Intro (o una lista al confirmar): recibe el texto y el evento.

On método

UiElement:On(event: UiEventName, fn: (e: UiEvent) -> ()): number
Oyente de cualquier evento por su nombre: "Click", "PointerEnter", "Drop", "Show"...

OnPointerEnter método

UiElement:OnPointerEnter(fn: (e: UiEvent) -> ()): number
Oyente: el puntero entra en el elemento (pasar por un hijo no es salir).

OnPointerExit método

UiElement:OnPointerExit(fn: (e: UiEvent) -> ()): number
Oyente: el puntero sale del elemento.

OnPointerDown método

UiElement:OnPointerDown(fn: (e: UiEvent) -> ()): number
Oyente: se pulsa un botón del ratón encima.

OnPointerUp método

UiElement:OnPointerUp(fn: (e: UiEvent) -> ()): number
Oyente: se suelta el botón (en el elemento en el que se pulsó).

OnPointerClick método

UiElement:OnPointerClick(fn: (e: UiEvent) -> ()): number
Oyente: clic con cualquier botón (e.pointer.button, e.pointer.clickCount para el doble clic).

OnBeginDrag método

UiElement:OnBeginDrag(fn: (e: UiEvent) -> ()): number
Oyente: empieza a arrastrarse (necesita Arrastrable o SetDraggable).

OnDrag método

UiElement:OnDrag(fn: (e: UiEvent) -> ()): number
Oyente: cada frame mientras se arrastra.

OnEndDrag método

UiElement:OnEndDrag(fn: (e: UiEvent) -> ()): number
Oyente en el origen al terminar el arrastre: e.drag.result es "Dropped", "Rejected", "NoTarget", "Outside" o "Cancelled".

OnDrop método

UiElement:OnDrop(fn: (e: UiEvent) -> ()): number
Oyente en el destino: le sueltan algo que acepta (e.drag.payload, e.drag.source).

OnDragEnter método

UiElement:OnDragEnter(fn: (e: UiEvent) -> ()): number
Oyente en un destino: un arrastre entra encima.

OnDragExit método

UiElement:OnDragExit(fn: (e: UiEvent) -> ()): number
Oyente en un destino: un arrastre sale de encima.

OnShow método

UiElement:OnShow(fn: (e: UiEvent) -> ()): number
Oyente: el elemento pasa a verse por lo que sea (las pantallas, al empezar su transición).

OnHide método

UiElement:OnHide(fn: (e: UiEvent) -> ()): number
Oyente: el elemento deja de verse (las pantallas, al empezar a ocultarse).

RemoveListener método

UiElement:RemoveListener(id: number): UiElement
Quita un oyente por el id que devolvió OnClick, On...

SetDraggable método

UiElement:SetDraggable(enabled: boolean?): UiElement
Activa o desactiva su Arrastrable (lo añade si hace falta).

SetDragPayload método

UiElement:SetDragPayload(payload: any, tag: string?): UiElement
La carga de su arrastre: cualquier valor de Lua (una tabla con el objeto) y su tipo (lo miran los destinos).

SetDropFilter método

UiElement:SetDropFilter(filter: ((e: UiEvent) -> boolean)?): UiElement
Filtro de un destino: una función que recibe el evento y dice si acepta lo que llega (nil lo quita).

SetTooltip método

UiElement:SetTooltip(title: string, text: string?, bar: number?): UiElement
Su descripción emergente: título, texto y barra opcional (de 0 a 1; sin barra, -1).

SetTooltipEnabled método

UiElement:SetTooltipEnabled(enabled: boolean): UiElement
Activa o desactiva su descripción emergente.

GetSlotIndex método

UiElement:GetSlotIndex(): number
El índice de una casilla.

SetSlotSelected método

UiElement:SetSlotSelected(selected: boolean): UiElement
Marca la casilla como Elegida (la activa de una barra rápida).

IsSlotSelected método

UiElement:IsSlotSelected(): boolean
true si la casilla está Elegida.

SetSlotCount método

UiElement:SetSlotCount(count: number): UiElement
Cuántas casillas tiene una rejilla de casillas (las rehace jugando).

SetStyle método

UiElement:SetStyle(style: string?): UiElement
Le pone un estilo ("Supervivencia/Botón", "Claro/Panel" o uno de la escena); nil lo quita. Con el nombre de un tema entero ("Militar desgastado", "militar_desgastado", "Metal oxidado"...), se lo pone a él y a todos sus hijos: a cada uno su pieza (botón, barra, panel...).

GetStyle método

UiElement:GetStyle(): string
El estilo que tiene.

SetWear método

UiElement:SetWear(amount: number, seed: number?): UiElement
Desgaste del elemento (componente Desgaste): de 0 (como nuevo) a 1 (muy gastado), y una semilla opcional que cambia el dibujo de los bordes mellados, la pintura saltada y los arañazos.

GetWear método

UiElement:GetWear(): number
El desgaste de su componente Desgaste, o -1 si no tiene (usa el de su estilo).

PlayAnimation método

UiElement:PlayAnimation(reverse: boolean?): UiElement
Reproduce su Animación de UI (al revés con true).

StopAnimation método

UiElement:StopAnimation(): UiElement
Para su Animación de UI.

IsAnimationPlaying método

UiElement:IsAnimationPlaying(): boolean
true mientras su Animación de UI se reproduce.

SetRichText método

UiElement:SetRichText(enabled: boolean): UiElement
Activa el texto enriquecido de su texto, lista o tabla (apagado por defecto: con lo que escribe un jugador, usa UI.Escape).

SetItems método

UiElement:SetItems(items: {string}): UiElement
Las filas de una lista: SetItems({ "Hacha", "Cuerda" }) (desde 0).

AddItem método

UiElement:AddItem(item: string): UiElement
Añade una fila a una lista.

ClearItems método

UiElement:ClearItems(): UiElement
Vacía una lista o una tabla.

GetItemCount método

UiElement:GetItemCount(): number
Cuántas filas tiene una lista o una tabla.

GetItem método

UiElement:GetItem(index: number): string
El texto de la fila de ese índice (desde 0).

SetColumns método

UiElement:SetColumns(titles: {string}): UiElement
Los títulos de las columnas de una tabla.

SetRows método

UiElement:SetRows(rows: {{string}}): UiElement
Las filas de una tabla: SetRows({ { "Ana", "12" }, { "Luis", "7" } }).

SelectTab método

UiElement:SelectTab(page: string | number): UiElement
Elige una pestaña por su índice (desde 0) o por el nombre de su página.

ShowDialog método

UiElement:ShowDialog(title: string, text: string?, buttons: {string}?): UiElement
Muestra un diálogo con título, texto y botones; el pulsado llega a OnDialogResult.

OnDialogResult método

UiElement:OnDialogResult(fn: (index: number, label: string, e: UiEvent) -> ()): number
Oyente del diálogo: recibe el índice del botón (desde 0; -1 si se cerró pulsando fuera), su texto y el evento.

SetIcon método

UiElement:SetIcon(icon: UiIconName): UiElement
El icono vectorial de un botón con icono o un icono: "Corazón", "Estrella", "Engranaje"...
