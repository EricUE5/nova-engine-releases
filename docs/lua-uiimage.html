Referencia de Lua · Componente

UiImage

Imagen: componente (Interfaz). Rectángulo con color o sprite, esquinas redondeadas, borde, nueve cortes y relleno

entidad:GetComponent("UiImage") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

sprite campo

UiImage.sprite: Asset?
Imagen (en el Inspector). Vacío: color liso

color campo

UiImage.color: Color
Color (en el Inspector).

type campo

UiImage.type: "Simple" | "Sliced" | "Filled"
Tipo (en el Inspector).

slice campo

UiImage.slice: Vec4
Bordes (izq., arriba, der., abajo) (en el Inspector). Nueve cortes: píxeles del sprite que no se estiran

sliceScale campo

UiImage.sliceScale: number
Escala de los bordes (en el Inspector). De 0.01 a 3e+38.

uvRect campo

UiImage.uvRect: Vec4
Parte del sprite (UV) (en el Inspector).

preserveAspect campo

UiImage.preserveAspect: boolean
Conservar proporción (en el Inspector).

cornerRadius campo

UiImage.cornerRadius: number
Radio de las esquinas (en el Inspector). De 0 a 3e+38.

outlineWidth campo

UiImage.outlineWidth: number
Grosor del borde (en el Inspector). De 0 a 3e+38.

outlineColor campo

UiImage.outlineColor: Color
Color del borde (en el Inspector).

fillMethod campo

UiImage.fillMethod: "Horizontal" | "Vertical" | "Radial"
Método de relleno (en el Inspector).

fillAmount campo

UiImage.fillAmount: number
Cantidad (en el Inspector). De 0 a 1.

fillReverse campo

UiImage.fillReverse: boolean
Al revés (en el Inspector).

raycastTarget campo

UiImage.raycastTarget: boolean
Bloquea clics (en el Inspector).

cornerRadii campo

UiImage.cornerRadii: Vec4
Radios por esquina (en el Inspector). Arriba izq., arriba der., abajo der., abajo izq. (negativo: el Radio de las esquinas)

dashLength campo

UiImage.dashLength: number
Borde discontinuo (trazo) (en el Inspector). 0: borde continuo De 0 a 3e+38.

dashGap campo

UiImage.dashGap: number
Hueco entre trazos (en el Inspector). De 0 a 3e+38.

tintMode campo

UiImage.tintMode: "Multiply" | "Add" | "Silhouette" | "Grayscale"
Modo del tinte (en el Inspector). Cómo se aplica el Color al sprite: multiplicar (normal), sumar (brillo), silueta (solo la forma) o escala de grises

sliceTiled campo

UiImage.sliceTiled: boolean
Repetir el centro (mosaico) (en el Inspector). Nueve cortes: el centro y los bordes se repiten en vez de estirarse

entity campo

UiImage.entity: Entity
La entidad que tiene este componente.
