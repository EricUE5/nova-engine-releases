Referencia de Lua · Tipo

Entity

Una entidad de la escena: nombre, jerarquía, posición en el mundo, componentes, scripts y etiquetas.

name campo

Entity.name: string
Nombre de la entidad (se puede cambiar).

active campo

Entity.active: boolean
Si está activa (se puede cambiar).

activeInHierarchy campo

Entity.activeInHierarchy: boolean
Activa ella y todos sus padres.

id campo

Entity.id: string
Su UUID (texto): Scene.FindById(id) la encuentra.

parent campo

Entity.parent: Entity?
Su padre, o nil (se puede cambiar).

transform campo

Entity.transform: Transform
Su Transform (posición, rotación y escala locales).

position campo

Entity.position: Vec3
Posición en el mundo (se puede cambiar).

rotation campo

Entity.rotation: Quat
Rotación en el mundo (se puede cambiar).

children campo

Entity.children: {Entity}
Sus hijos.

tags campo

Entity.tags: {string}
Sus etiquetas (lista de textos; se puede asignar una lista nueva).

GetComponent método

Entity:GetComponent(name: "AiAgent"): AiAgent?
Entity:GetComponent(name: "AiSenses"): AiSenses?
Entity:GetComponent(name: "Aircraft"): Aircraft?

… y 100 variantes más.

Un componente por su nombre ("RigidBody", "Animator"...) con todos sus campos y métodos, o nil si no lo tiene.

AddComponent método

Entity:AddComponent(name: "AiAgent"): AiAgent
Entity:AddComponent(name: "AiSenses"): AiSenses
Entity:AddComponent(name: "Aircraft"): Aircraft

… y 100 variantes más.

Añade un componente por su nombre y lo devuelve.

HasComponent método

Entity:HasComponent(name: string): boolean
true si tiene ese componente.

RemoveComponent método

Entity:RemoveComponent(name: string): boolean
Quita un componente.

GetComponentNames método

Entity:GetComponentNames(): {string}
Los nombres de sus componentes.

GetScript método

Entity:GetScript(name: string): any
Un script de la entidad por su nombre ("Jugador", "ia/Enemigo" o "ia/Enemigo.luau": la extensión es opcional; Lua o C++), o nil.

AddScript método

Entity:AddScript(name: string): any
Añade un script por su nombre y devuelve su instancia.

Destroy método

Entity:Destroy(seconds: number?): (): ()
La destruye al final del frame, o dentro de esos segundos de juego.

IsValid método

Entity:IsValid(): boolean
true si la entidad sigue existiendo.

SetParent método

Entity:SetParent(parent: Entity?, keepWorld: boolean?): boolean
Cambia de padre (nil = raíz); con mantenerMundo, sin moverse en el mundo.

FindChild método

Entity:FindChild(nameOrPath: string): Entity?
Un descendiente con ese nombre (a cualquier profundidad), o la ruta de hijos "Puerta/Bisagra".

HasTag método

Entity:HasTag(tag: string): boolean
true si tiene esa etiqueta o una hija suya (jerárquica: HasTag("Objeto.Botin") vale con Objeto.Botin.Oro; exacta: HasTagExact).

AddTag método

Entity:AddTag(tag: string): (): ()
Añade una etiqueta (y el componente Etiquetas si hace falta).

RemoveTag método

Entity:RemoveTag(tag: string): boolean
Quita una etiqueta.

AttachTo método

Entity:AttachTo(target: Entity | Animator, boneOrSocket: string, options: AttachOptions?): BoneAttachment
entidad:AttachTo(personaje, "Arma", opciones?): engancha la entidad a un hueso o a un socket del modelo del personaje (la entidad, o su componente Animator; el Animator puede estar en un hijo) y la pone justo en él. Opciones: keepWorld/mantenerSitio (se queda donde está), inheritScale/heredarEscala, offset/desplazamiento (Vec3) y rotation/rotacion (Quat o Vec3 en grados) respecto al hueso. Devuelve el componente Enganche a hueso.

Detach método

Entity:Detach(keepWorld: boolean?): (): ()
Suelta la entidad del hueso o socket. Por defecto se queda donde estaba; con false, vuelve a su Transform.

GetAttachParent método

Entity:GetAttachParent(): (Entity?, string?): ()
La entidad del Animator al que está enganchada y el hueso o socket (local personaje, socket = arma:GetAttachParent()), o nil.

HasTagExact método

Entity:HasTagExact(tag: GameplayTag): boolean
entidad:HasTagExact("Objeto.Botin"): tiene exactamente esa etiqueta (sin contar las hijas). HasTag es jerárquico: HasTag("Objeto.Botin") también es true con Objeto.Botin.Oro.

HasAnyTag método

Entity:HasAnyTag(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
entidad:HasAnyTag({ ... }): tiene alguna de esas etiquetas (o una hija).

HasAllTags método

Entity:HasAllTags(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
entidad:HasAllTags({ ... }): tiene todas (o hijas suyas).

GetTags método

Entity:GetTags(): TagContainer
Sus etiquetas como TagContainer unido a la entidad: lo que se añada o quite cambia sus etiquetas (y se replica si tiene Identidad de red).

Implements método

Entity:Implements(interface: InterfaceInfo | string): boolean
entidad:Implements("Recogible"): algún script suyo implementa la interfaz.

GetInterface método

Entity:GetInterface(interface: InterfaceInfo | string): any
entidad:GetInterface("Recogible"): un objeto con las funciones de la interfaz del primer script que la implementa (i:AlCoger(jugador)), o nil. i.script es la instancia.
