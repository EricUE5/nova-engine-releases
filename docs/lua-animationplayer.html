Referencia de Lua · Componente

AnimationPlayer

Animación: componente (Animación). Reproduce clips de animación (.anim) en esta entidad y sus hijos: puertas, ascensores, plataformas, luces... Se editan en Ventana > Línea de tiempo

entidad:GetComponent("AnimationPlayer") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

clips campo

AnimationPlayer.clips: { Asset? }
Clips (en el Inspector). Clips .anim que puede reproducir (anim:Play("Nombre") en Lua) Es una copia: para cambiarla, asigna la lista entera.

defaultClip campo

AnimationPlayer.defaultClip: string
Clip por defecto (en el Inspector). El que se reproduce al empezar (vacío = el primero)

playOnStart campo

AnimationPlayer.playOnStart: boolean
Reproducir al empezar (en el Inspector).

speed campo

AnimationPlayer.speed: number
Velocidad (en el Inspector). 1 = normal; negativa = hacia atrás De -5 a 5.

wrap campo

AnimationPlayer.wrap: "FromClip" | "Once" | "Loop" | "PingPong"
Repetición (en el Inspector). Qué pasa al llegar al final (Del clip = la que dice el clip)

syncNetwork campo

AnimationPlayer.syncNetwork: boolean
Sincronizar en red (en el Inspector). Con Identidad de red: lo que reproduce el servidor llega a los clientes con su tiempo

netClip campo

AnimationPlayer.netClip: string
Net Clip (en el Inspector).

netSeq campo

AnimationPlayer.netSeq: number
Net Seq (en el Inspector).

netPlaying campo

AnimationPlayer.netPlaying: boolean
Net Playing (en el Inspector).

netSpeed campo

AnimationPlayer.netSpeed: number
Net Speed (en el Inspector).

netTime campo

AnimationPlayer.netTime: number
Net Time (en el Inspector).

netStamp campo

AnimationPlayer.netStamp: string
Net Stamp (en el Inspector).

entity campo

AnimationPlayer.entity: Entity
La entidad que tiene este componente.

Play método

AnimationPlayer:Play(clip: string?, from: number?): boolean
Reproduce un clip del componente Animación desde el principio (o desde desde segundos): anim:Play("AbrirPuerta"). Sin nombre, el clip por defecto. Error si el componente no tiene ese clip en su lista.

PlayBackwards método

AnimationPlayer:PlayBackwards(clip: string?): boolean
Reproduce el clip hacia atrás desde el final (para cerrar una puerta con el mismo clip que la abre): anim:PlayBackwards("AbrirPuerta").

Stop método

AnimationPlayer:Stop(): (): ()
Para el clip donde está (la entidad se queda así). Resume sigue desde ahí.

Pause método

AnimationPlayer:Pause(): (): ()
Igual que Stop: se para donde está.

Resume método

AnimationPlayer:Resume(): (): ()
Sigue reproduciendo desde donde se paró (en «una vez», si había terminado, vuelve a empezar).

SetSpeed método

AnimationPlayer:SetSpeed(speed: number): (): ()
Velocidad: 1 = normal, 2 = el doble, negativa = hacia atrás.

GetSpeed método

AnimationPlayer:GetSpeed(): number
La velocidad actual.

SetTime método

AnimationPlayer:SetTime(seconds: number): (): ()
Salta a ese segundo del clip actual (se aplica aunque esté parado).

GetTime método

AnimationPlayer:GetTime(): number
Segundo del clip en el que está (de 0 a su duración).

IsPlaying método

AnimationPlayer:IsPlaying(clip: string?): boolean
true si está reproduciendo (con nombre: si está reproduciendo ese clip).

GetClip método

AnimationPlayer:GetClip(): string?
Nombre del clip actual o nil.

GetDuration método

AnimationPlayer:GetDuration(clip: string?): number
Duración en segundos de un clip (o del actual).

GetClips método

AnimationPlayer:GetClips(): {string}
Los nombres de los clips del componente.
