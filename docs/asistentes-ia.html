Asistentes de IA (Claude Code y otros)

En esta página
  • 1. Qué escribe el editor
  • 2. Qué puede hacer el asistente
  • 3. Tus propias instrucciones
  • 4. Desactivarlo

Desde la 0.9.52, al abrir un proyecto el editor lo deja listo para un asistente de IA: si le pides a Claude Code (u otro asistente que lea AGENTS.md) que haga algo en el juego, ya sabe qué es Nova, dónde está la API y el manual, cómo probar el juego y cómo colocar cosas en el editor abierto. No hay que explicarle nada ni configurar nada: abres el proyecto con el editor una vez y le escribes.

  1. Qué escribe el editor
  2. Qué puede hacer el asistente
  3. Tus propias instrucciones
  4. Desactivarlo
  5. Para quien desarrolla el motor

1. Qué escribe el editor#

En la carpeta del proyecto, cada vez que lo abres (y solo si ha cambiado algo):

Fichero Qué es
AGENTS.md La guía para cualquier asistente: qué es Nova, dónde están la API y el manual, cómo es el proyecto, lo mínimo de los scripts Luau y cómo trabajar sin estropear nada. No lleva rutas de tu PC
CLAUDE.md Lo que lee Claude Code al empezar: importa AGENTS.md y le habla de su habilidad nova
.claude/skills/nova/ La habilidad nova de Claude Code, con las rutas de este PC (el motor y el manual) y dos herramientas: probar.ps1 y editor.ps1
nova.d.luau, nova.docs.json La API de Lua entera con sus tipos y su explicación (los mismos que usa VS Code). Para el asistente son la fuente de verdad

El manual se instala también en Markdown (docs\md dentro de la carpeta de Nova), que es lo que lee mejor un asistente; la habilidad le dice dónde está.

2. Qué puede hacer el asistente#

  • Escribir y arreglar scripts, prefabs, materiales, interfaces y escenas (las que no estén abiertas en el editor), con la API de verdad de nova.d.luau.
  • Probar el juego sin ventana: probar.ps1 arranca el juego sin ventana ni sonido, juega unos segundos, guarda una captura y el registro, y le enseña los errores. Usa una carpeta de datos aparte (.nova\ia-datos): no toca tus partidas, tus ajustes ni tu Steam.
  • Colocar, mover, quitar y seleccionar cosas en la escena abierta del editor con editor.ps1, por el Enlace con Nova IA: como si lo hicieras tú, con su Ctrl+Z y, en una sesión de equipo, para todos. Necesita el editor abierto con el proyecto y sin estar jugando.

3. Tus propias instrucciones#

Cada fichero que escribe Nova empieza con una marca (nova:asistente-ia y la versión del motor). Si quieres escribir tus propias instrucciones en AGENTS.md o CLAUDE.md, borra esa línea: desde entonces el fichero es tuyo y Nova no lo vuelve a tocar. Si ya tenías un CLAUDE.md o un AGENTS.md sin la marca, Nova no lo toca nunca.

Con la marca, Nova pone los ficheros al día con cada versión del motor; un editor con un motor más viejo no rehace AGENTS.md ni CLAUDE.md si los escribió uno más nuevo.

En una sesión de equipo estos ficheros no se sincronizan (la sesión solo lleva project.nova, assets/ y scripts/): el editor de cada persona escribe los suyos en su carpeta de trabajo.

Sin abrir el editor (por ejemplo, desde un script): NovaEditor.exe --preparar-ia --project <carpeta del proyecto> hace lo mismo y escribe en la salida qué ha cambiado.

4. Desactivarlo#

Editar > Preferencias del editor... > Preparar los proyectos para asistentes de IA, activado de serie. Desactivado, el editor no escribe nada (lo que ya escribió se queda). Sin ventana (pruebas, capturas y publicar desde la línea de comandos) no escribe nunca.
