VoxelTerrain

VoxelTerrain: terreno de vóxeles deformable (ver docs/terreno-voxel.md). Las funciones de la tabla reciben el terreno (componente o entidad) delante; con el componente se usan como métodos: terreno:Dig(pos, 0.5). Eventos: voxel:dug (terrain, result, player) en el servidor con lo cavado de verdad y voxel:request (terrain, request, player) antes de aceptar la edición de un cliente (CancelEvent() la rechaza).

Dig función

VoxelTerrain.Dig(terrain: VoxelTarget, position: Vec3, radius: number, strength: number?, options: VoxelEditOptions?): VoxelDigResult
Cava en position (mundo) con radio radius (m) y fuerza strength (1 = quita un vóxel entero en el centro con dureza 1; el hielo de dureza 2 necesita el doble). El borde se suaviza (cráter orgánico). Opciones: { shape = "Sphere" | "Capsule" | "Cone" | "Box", direction, length, falloff, noise, seed } (el cono es el soplete). Devuelve lo extraído: volume (m³), kg, value y materials (lista de { id, name, volume, kg, value }). En un cliente en red se ve al momento (predicted = true) y el servidor lo confirma o lo deshace.

Add función

VoxelTerrain.Add(terrain: VoxelTarget, position: Vec3, radius: number, material: number, strength: number?, options: VoxelEditOptions?): VoxelDigResult
Añade material material (índice desde 0) en una esfera (u otra forma de las opciones). Devuelve added (m³).

Smooth función

VoxelTerrain.Smooth(terrain: VoxelTarget, position: Vec3, radius: number, strength: number?, options: VoxelEditOptions?): VoxelDigResult
Suaviza la superficie en el radio (quita picos y rellena hoyos pequeños). Para el pincel del editor y para alisar suelos.

Paint función

VoxelTerrain.Paint(terrain: VoxelTarget, position: Vec3, radius: number, material: number, strength: number?, options: VoxelEditOptions?): VoxelDigResult
Cambia el material de lo que ya hay en el radio (sin quitar ni poner volumen).

Raycast función

VoxelTerrain.Raycast(terrain: VoxelTarget, origin: Vec3, direction: Vec3, maxDistance: number?): VoxelHit?
Rayo contra el terreno: { point, normal, material, distance } o nil. Más preciso que Physics.Raycast (llega antes que la colisión rehecha).

GetMaterialAt función

VoxelTerrain.GetMaterialAt(terrain: VoxelTarget, position: Vec3): number?
Material (índice desde 0) del sólido en ese punto, o nil si es aire.

IsSolid función

VoxelTerrain.IsSolid(terrain: VoxelTarget, position: Vec3): boolean
true si el punto está dentro del sólido.

GetVolume función

VoxelTerrain.GetVolume(terrain: VoxelTarget, material: number?): number
m³ que quedan (de un material o de todos).

GetInitialVolume función

VoxelTerrain.GetInitialVolume(terrain: VoxelTarget, material: number?): number
m³ que había al cargar (o al generar desde Lua).

GetProgress función

VoxelTerrain.GetProgress(terrain: VoxelTarget, material: number?): number
Fracción ya extraída (0..1) de un material o de todo: 1 - GetVolume / GetInitialVolume.

GetRegionVolume función

VoxelTerrain.GetRegionVolume(terrain: VoxelTarget, min: Vec3, max: Vec3, material: number?): number
m³ que quedan dentro de una caja del mundo (para «sección completada %»: guarda el valor al empezar y compáralo).

GetMaterial función

VoxelTerrain.GetMaterial(terrain: VoxelTarget, material: number): VoxelMaterialInfo?
Datos de un material: { id, name, color, hardness, density, value }.

GetMaterialCount función

VoxelTerrain.GetMaterialCount(terrain: VoxelTarget): number
Cuántos materiales tiene la lista.

GetOrigin función

VoxelTerrain.GetOrigin(terrain: VoxelTarget): Vec3
Esquina mínima del volumen en el mundo.

Clear función

VoxelTerrain.Clear(terrain: VoxelTarget): ()
Lo deja todo vacío (para generar desde Lua).

Regenerate función

VoxelTerrain.Regenerate(terrain: VoxelTarget): ()
Vuelve a generar con los ajustes del componente (borra lo editado).

FillBox función

VoxelTerrain.FillBox(terrain: VoxelTarget, min: Vec3, max: Vec3, material: number?, solid: boolean?): ()
Rellena una caja del mundo con un material (solid = false la vacía).

FillSphere función

VoxelTerrain.FillSphere(terrain: VoxelTarget, center: Vec3, radius: number, material: number?, solid: boolean?): ()
Rellena una esfera (solid = false la vacía).

FillCylinder función

VoxelTerrain.FillCylinder(terrain: VoxelTarget, baseCenter: Vec3, radius: number, height: number, material: number?, solid: boolean?): ()
Rellena un cilindro vertical desde el centro de su base.

FillLayers función

VoxelTerrain.FillLayers(terrain: VoxelTarget, layers: { VoxelLayerDesc }, seed: number?): ()
Cambia el material de lo sólido por capas de altura (m desde el fondo): { { fromY = 0, toY = 2, material = 1, noise = 0.3 } }.

FillRegion función

VoxelTerrain.FillRegion(terrain: VoxelTarget, min: Vec3, max: Vec3, fill: (position: Vec3) -> (number?, number?)): ()
Función por vóxel en una caja: fill(posición) -> (relleno 0..1, material); nil deja el vóxel como está.

GenerateChunks función

VoxelTerrain.GenerateChunks(terrain: VoxelTarget, fill: (chunkMin: Vec3, chunkMax: Vec3) -> (number?, number?)): ()
Función por trozo (32³ vóxeles): fill(min, max) -> (relleno, material) deja el trozo entero así (no gasta memoria); nil lo deja.

Serialize función

VoxelTerrain.Serialize(terrain: VoxelTarget): string
Lo editado (los trozos que difieren de lo generado), en texto: para guardar la partida.

Deserialize función

VoxelTerrain.Deserialize(terrain: VoxelTarget, data: string): boolean
Pone lo guardado con Serialize. false si no encaja (otras medidas).

GetStateHash función

VoxelTerrain.GetStateHash(terrain: VoxelTarget): string
Huella del volumen: la misma en el servidor y en los clientes.

Flush función

VoxelTerrain.Flush(terrain: VoxelTarget): ()
Espera a que estén hechas todas las mallas y colisiones pendientes (para pruebas y capturas).

GetStats función

VoxelTerrain.GetStats(): VoxelStatsInfo
Coste medido: mallas hechas y su tiempo medio y máximo (ms, en los hilos de trabajo), formas de colisión, ediciones (ms en el hilo principal), trabajos pendientes y bytes de red.

Find función

VoxelTerrain.Find(): VoxelTerrain?
El primer terreno de vóxeles de la escena (su componente) o nil.
