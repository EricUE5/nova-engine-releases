Referencia de Lua · Componente

CharacterController2D

Controlador de personaje 2D: componente (Física 2D). Personaje de plataformas de precisión: suelo, pendientes, techo y paredes, coyote time, buffer de salto, salto variable, salto en pared, doble salto, dash, parry y plataformas móviles. En Lua: controller:Move(x), Jump(), Dash(dir)

entidad:GetComponent("CharacterController2D") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

size campo

CharacterController2D.size: Vec2
Tamaño (en el Inspector). Ancho y alto de la cápsula del personaje (centrada en la entidad)

offset campo

CharacterController2D.offset: Vec2
Desplazamiento (en el Inspector).

layer campo

CharacterController2D.layer: number
Capa (en el Inspector). De 0 a 31.

collisionMask campo

CharacterController2D.collisionMask: number
Máscara de colisión (en el Inspector). Capas con las que choca (el bit N es la capa N)

maxSlope campo

CharacterController2D.maxSlope: number
Pendiente máxima (en el Inspector). Grados: más empinado es una pared De 0 a 89.

maxSpeed campo

CharacterController2D.maxSpeed: number
Velocidad máxima (en el Inspector). m/s De 0 a 100.

groundAcceleration campo

CharacterController2D.groundAcceleration: number
Aceleración en el suelo (en el Inspector). m/s² hasta la velocidad máxima De 0 a 1000.

groundDeceleration campo

CharacterController2D.groundDeceleration: number
Frenada en el suelo (en el Inspector). m/s² al soltar De 0 a 1000.

airAcceleration campo

CharacterController2D.airAcceleration: number
Aceleración en el aire (en el Inspector). De 0 a 1000.

airDeceleration campo

CharacterController2D.airDeceleration: number
Frenada en el aire (en el Inspector). De 0 a 1000.

jumpHeight campo

CharacterController2D.jumpHeight: number
Altura del salto (en el Inspector). m del salto completo (manteniendo el botón) De 0 a 50.

timeToApex campo

CharacterController2D.timeToApex: number
Tiempo hasta lo más alto (en el Inspector). s: con la altura define la gravedad del personaje (más corto = salto más seco) De 0.05 a 3.

fallGravityMultiplier campo

CharacterController2D.fallGravityMultiplier: number
Gravedad al caer (en el Inspector). Multiplica la gravedad al bajar: las caídas son más rápidas que la subida De 1 a 10.

jumpCutMultiplier campo

CharacterController2D.jumpCutMultiplier: number
Corte del salto (en el Inspector). Salto variable: al soltar el botón subiendo, la velocidad hacia arriba se multiplica por esto (1 = sin salto variable) De 0 a 1.

maxFallSpeed campo

CharacterController2D.maxFallSpeed: number
Velocidad máxima de caída (en el Inspector). m/s De 0 a 200.

coyoteTime campo

CharacterController2D.coyoteTime: number
Coyote time (en el Inspector). s en los que aún se puede saltar después de salir de un borde De 0 a 1.

jumpBuffer campo

CharacterController2D.jumpBuffer: number
Buffer de salto (en el Inspector). s que se recuerda un salto pulsado justo antes de tocar el suelo De 0 a 1.

airJumps campo

CharacterController2D.airJumps: number
Saltos en el aire (en el Inspector). 1 = doble salto De 0 a 10.

wallJump campo

CharacterController2D.wallJump: boolean
Salto en pared (en el Inspector). Pegado a una pared en el aire: se desliza despacio y puede saltar

wallSlideSpeed campo

CharacterController2D.wallSlideSpeed: number
Velocidad de deslizar (en el Inspector). m/s máximos cayendo pegado a una pared De 0 a 100.

wallJumpVelocity campo

CharacterController2D.wallJumpVelocity: Vec2
Impulso del salto en pared (en el Inspector). m/s: x hacia fuera de la pared e y hacia arriba

wallJumpLock campo

CharacterController2D.wallJumpLock: number
Bloqueo tras el salto en pared (en el Inspector). s sin control horizontal después de saltar de una pared (para no volver a pegarse) De 0 a 1.

dashEnabled campo

CharacterController2D.dashEnabled: boolean
Dash (en el Inspector).

dashDistance campo

CharacterController2D.dashDistance: number
Distancia del dash (en el Inspector). m De 0 a 50.

dashDuration campo

CharacterController2D.dashDuration: number
Duración del dash (en el Inspector). s (sin gravedad mientras dura) De 0.01 a 2.

dashCooldown campo

CharacterController2D.dashCooldown: number
Recarga del dash (en el Inspector). s desde que empieza hasta el siguiente De 0 a 10.

airDashes campo

CharacterController2D.airDashes: number
Dashes en el aire (en el Inspector). Antes de volver a tocar el suelo De 0 a 10.

dashInvulnerable campo

CharacterController2D.dashInvulnerable: boolean
Invulnerable en el dash (en el Inspector). IsInvulnerable() da true mientras dura

parryEnabled campo

CharacterController2D.parryEnabled: boolean
Parry (en el Inspector). Saltar (o Parry()) en el aire junto a algo con la etiqueta de parry rebota hacia arriba y llama a OnParry

parryTag campo

CharacterController2D.parryTag: string
Etiqueta de parry (en el Inspector). Etiqueta (componente Etiquetas) de lo que se puede golpear

parryRange campo

CharacterController2D.parryRange: number
Alcance del parry (en el Inspector). m alrededor del personaje De 0 a 5.

parryBounce campo

CharacterController2D.parryBounce: number
Rebote del parry (en el Inspector). m/s hacia arriba al acertar De 0 a 100.

rideMovingPlatforms campo

CharacterController2D.rideMovingPlatforms: boolean
Ir sobre plataformas móviles (en el Inspector). Las plataformas cinemáticas arrastran al personaje que está encima

pushStrength campo

CharacterController2D.pushStrength: number
Empuje (en el Inspector). Lo que empuja a los cuerpos dinámicos (cajas): 0 = nada De 0 a 1.

moveInput campo

CharacterController2D.moveInput: Vec2
Move Input (en el Inspector).

jumpHeld campo

CharacterController2D.jumpHeld: boolean
Jump Held (en el Inspector).

velocity campo

CharacterController2D.velocity: Vec2
Velocidad (en el Inspector).

grounded campo

CharacterController2D.grounded: boolean
En el suelo (en el Inspector).

onWall campo

CharacterController2D.onWall: boolean
En una pared (en el Inspector).

onCeiling campo

CharacterController2D.onCeiling: boolean
Contra el techo (en el Inspector).

dashing campo

CharacterController2D.dashing: boolean
Haciendo dash (en el Inspector).

invulnerable campo

CharacterController2D.invulnerable: boolean
Invulnerable (en el Inspector).

facing campo

CharacterController2D.facing: number
Mira hacia (en el Inspector).

groundNormal campo

CharacterController2D.groundNormal: Vec2
Normal del suelo (en el Inspector).

entity campo

CharacterController2D.entity: Entity
La entidad que tiene este componente.

Move método

CharacterController2D:Move(input: number | Vec2, down: number?): (): ()
Entrada del personaje: pj:Move(x) con x de -1 a 1, o pj:Move(Vec2.new(x, y)): y < -0,5 es «abajo» (abajo + Jump() baja de una plataforma de un sentido). Cada frame.

Jump método

CharacterController2D:Jump(): (): ()
Pulsar saltar: salta si está en el suelo o en el coyote time; si no, se recuerda durante el buffer de salto. En el aire: parry, salto en pared o doble salto si están activos.

ReleaseJump método

CharacterController2D:ReleaseJump(): (): ()
Soltar saltar: corta el salto (salto variable).

Dash método

CharacterController2D:Dash(direction: Vec2?): boolean
Dash en direction (sin ella, hacia donde mira). false si está recargando o sin dashes en el aire. Llama a OnDash(direccion).

Parry método

CharacterController2D:Parry(): boolean
Golpe de parry ahora: si toca algo con la etiqueta de parry, rebota y llama a OnParry(otra). Devuelve si ha acertado.

IsGrounded método

CharacterController2D:IsGrounded(): boolean
true si está en el suelo.

IsOnWall método

CharacterController2D:IsOnWall(): boolean
true si está en el aire pegado a una pared.

IsDashing método

CharacterController2D:IsDashing(): boolean
true mientras dura el dash.

IsInvulnerable método

CharacterController2D:IsInvulnerable(): boolean
true durante el dash si «Invulnerable en el dash» está activo.

GetVelocity método

CharacterController2D:GetVelocity(): Vec2
Velocidad propia (m/s), sin la de la plataforma.

SetVelocity método

CharacterController2D:SetVelocity(velocity: Vec2): (): ()
Cambia la velocidad (empujones, rebotes de un enemigo).

Teleport método

CharacterController2D:Teleport(position: Vec2): (): ()
Lo lleva a position sin pasar por en medio.
