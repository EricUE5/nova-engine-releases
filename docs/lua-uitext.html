Referencia de Lua · Componente

UiText

Texto: componente (Interfaz). Texto con cualquier fuente TTF, contorno y sombra

entidad:GetComponent("UiText") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

text campo

UiText.text: string
Texto (en el Inspector).

font campo

UiText.font: Asset?
Fuente (en el Inspector). Vacío: Roboto (integrada en el motor)

fontSize campo

UiText.fontSize: number
Tamaño (en el Inspector). De 1 a 512.

color campo

UiText.color: Color
Color (en el Inspector).

alignH campo

UiText.alignH: "Left" | "Center" | "Right"
Alineación horizontal (en el Inspector).

alignV campo

UiText.alignV: "Top" | "Middle" | "Bottom"
Alineación vertical (en el Inspector).

wrap campo

UiText.wrap: boolean
Ajuste de línea (en el Inspector).

overflow campo

UiText.overflow: "Overflow" | "Clip" | "Ellipsis"
Si no cabe (en el Inspector).

lineSpacing campo

UiText.lineSpacing: number
Interlineado (en el Inspector). De 0.1 a 5.

letterSpacing campo

UiText.letterSpacing: number
Espaciado entre letras (en el Inspector). De -20 a 100.

weight campo

UiText.weight: number
Grosor (en el Inspector). De -0.3 a 0.3.

outlineWidth campo

UiText.outlineWidth: number
Contorno (en el Inspector). De 0 a 16.

outlineColor campo

UiText.outlineColor: Color
Color del contorno (en el Inspector).

shadow campo

UiText.shadow: boolean
Sombra (en el Inspector).

shadowOffset campo

UiText.shadowOffset: Vec2
Desplazamiento de la sombra (en el Inspector).

shadowColor campo

UiText.shadowColor: Color
Color de la sombra (en el Inspector).

autoSize campo

UiText.autoSize: boolean
Tamaño automático (en el Inspector). Busca el mayor tamaño entre el mínimo y el máximo con el que cabe

minFontSize campo

UiText.minFontSize: number
Tamaño mínimo (en el Inspector). De 1 a 512.

maxFontSize campo

UiText.maxFontSize: number
Tamaño máximo (en el Inspector). De 1 a 512.

raycastTarget campo

UiText.raycastTarget: boolean
Bloquea clics (en el Inspector).

richText campo

UiText.richText: boolean
Texto enriquecido (en el Inspector). negrita, cursiva, subrayado, tachado, <color=#ffaa00>color y <size=40>tamaño. Apagado por defecto: actívalo solo en textos que no lleven lo que escribe un jugador (o usa UI.Escape)

uppercase campo

UiText.uppercase: boolean
Mayúsculas (en el Inspector).

gradient campo

UiText.gradient: "None" | "Vertical" | "Horizontal"
Degradado (en el Inspector). Del Color al Color del degradado

gradientColor campo

UiText.gradientColor: Color
Color del degradado (en el Inspector).

entity campo

UiText.entity: Entity
La entidad que tiene este componente.
