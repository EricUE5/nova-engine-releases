Referencia de Lua · Componente

MeshRenderer

Malla: componente (Render).

entidad:GetComponent("MeshRenderer") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

model campo

MeshRenderer.model: Asset?
Modelo (en el Inspector).

mesh campo

MeshRenderer.mesh: number
Malla (en el Inspector). Índice de la malla en el modelo (-1 = todas)

materials campo

MeshRenderer.materials: { Asset? }
Materiales (en el Inspector). Es una copia: para cambiarla, asigna la lista entera.

castShadows campo

MeshRenderer.castShadows: boolean
Proyecta sombras (en el Inspector).

receiveShadows campo

MeshRenderer.receiveShadows: boolean
Recibe sombras (en el Inspector). Si se desactiva, ninguna luz le hace sombra

visible campo

MeshRenderer.visible: boolean
Visible (en el Inspector). Desmarcado no se dibuja (la entidad y sus scripts siguen activos)

shadowOnly campo

MeshRenderer.shadowOnly: boolean
Solo sombra (en el Inspector). Proyecta su sombra pero no se dibuja en la vista (con «Proyecta sombras»). En el Inspector es la opción «Solo sombra» de Sombras

ownerVisibility campo

MeshRenderer.ownerVisibility: "Todos" | "Solo el propietario" | "Oculto para el propietario"
Visibilidad en red (en el Inspector). En una partida en red, según quién es el propietario (el jugador de su Identidad de red o la de un ancestro): «Solo el propietario» para los brazos en primera persona; «Oculto para el propietario» para su cuerpo, del que solo ve la sombra

occluder campo

MeshRenderer.occluder: "Automático" | "Sí" | "No"
Ocluidor (en el Inspector). Si tapa lo que hay detrás para no dibujarlo (oclusión). Automático: las mallas opacas grandes (1,5 m de radio o más) y con pocos triángulos, como muros, suelos y edificios. No: cristales, rejas o lo que no tapa del todo

lodBias campo

MeshRenderer.lodBias: number
Sesgo de LOD (en el Inspector). Multiplica el tamaño en pantalla con el que se elige el nivel de detalle: 2 = mantiene el detalle el doble de lejos, 0,5 = pasa antes a los niveles simplificados. 1 = el del proyecto (Ajustes del proyecto > Render) De 0.1 a 10.

maxDistance campo

MeshRenderer.maxDistance: number
Distancia máxima (en el Inspector). Metros: más lejos de la cámara (hasta el punto más cercano de la malla) no se dibuja ni proyecta sombra. Sirve para lo que tapa la niebla. 0 = sin límite De 0 a 1e+05.

fadeDistance campo

MeshRenderer.fadeDistance: number
Desvanecido (en el Inspector). Metros antes de la distancia máxima en los que se desvanece poco a poco (0 = desaparece de golpe) De 0 a 1000.

viewLayer campo

MeshRenderer.viewLayer: boolean
Vista en primera persona (en el Inspector). Arma y brazos en primera persona: se dibuja por delante de todo (no atraviesa paredes), con el campo de visión y el plano cercano de la «Capa de vista» de un ancestro (si no hay, 68 grados y 1 cm). Tiene que colgar de la cámara

staticLighting campo

MeshRenderer.staticLighting: boolean
Estático (iluminación) (en el Inspector). No se mueve: entra en el horneado de la iluminación (ventana Iluminación), recibe un lightmap con la luz que rebota, la del cielo y la de las luces horneadas, y hace sombra y rebota la luz para lo demás

lightmapScale campo

MeshRenderer.lightmapScale: number
Escala del lightmap (en el Inspector). Multiplica la densidad de texeles del proyecto en este objeto: 2 = el doble de detalle en las sombras horneadas (y 4 veces más memoria), 0,5 = la mitad. Para objetos grandes y lejanos, menos; para el suelo junto a una ventana, más De 0.05 a 20.

meshOffset campo

MeshRenderer.meshOffset: Vec3
Desplazamiento (pivote) (en el Inspector). Dónde está la malla respecto al origen de la entidad, que es su pivote (el punto sobre el que gira y escala). Lo cambian «Editar pivote» del visor y el menú Pivote de la Jerarquía sin mover el objeto

entity campo

MeshRenderer.entity: Entity
La entidad que tiene este componente.

SetColor método

MeshRenderer:SetColor(color: Color, slot: (number | string)?): (): ()
Color base de su material propio (la primera vez se copia el material solo para esta entidad). Sin submalla, todas; la primera es la 1.

GetColor método

MeshRenderer:GetColor(slot: (number | string)?): Color
Color base (de una submalla).

SetEmissive método

MeshRenderer:SetEmissive(color: Color, intensity: (number | string)?, slot: (number | string)?): (): ()
Brillo propio con su intensidad (con bloom si pasa del umbral). La submalla puede ser su número o el nombre de su material: SetEmissive(color, 4, "M_tritio") o SetEmissive(Color.black, "M_punto_rojo").

SetTexture método

MeshRenderer:SetTexture(texture: (Asset | string)?, slot: (number | string)?): (): ()
Textura de color (Asset o ruta; nil la quita).

SetMaterial método

MeshRenderer:SetMaterial(material: (Asset | string)?, slot: (number | string)?): (): ()
Usa un material del proyecto (compartido); nil = el del modelo.

GetMaterial método

MeshRenderer:GetMaterial(slot: (number | string)?): Asset?
El material de una submalla.

SetMaterialValue método

MeshRenderer:SetMaterialValue(name: string, value: any, slot: (number | string)?): (): ()
Cualquier valor del material: "metallic", "roughness", "emissiveIntensity", "uvScale", "alphaCutoff"...

GetMaterialValue método

MeshRenderer:GetMaterialValue(name: string, slot: (number | string)?): any
Un valor del material.

GetSlotCount método

MeshRenderer:GetSlotCount(): number
Cuántas submallas (materiales) tiene.

GetSlotName método

MeshRenderer:GetSlotName(slot: number): string
El nombre del material de una ranura (submalla): el del modelo o, si no tiene, el que usa ahora. Las funciones que reciben una submalla aceptan también este nombre: malla:SetEmissive(color, 4, "M_tritio").

FindSlot método

MeshRenderer:FindSlot(name: string): number?
El número de la primera ranura con ese material (nil si no hay ninguna).

SetParam método

MeshRenderer:SetParam(name: string, value: number | Vec2 | Vec3 | Vec4 | Color | Asset | string | nil): (): ()
Cambia un parámetro expuesto de sus materiales por nodos solo para esta entidad (no duplica el shader y se replica por la red): un número, Vec2, Vec3, Vec4, Color o una textura (Asset o ruta). malla:SetParam("Brillo", 3).

GetParam método

MeshRenderer:GetParam(name: string): number | Vec4 | Color | Asset | nil
El valor de un parámetro de sus materiales por nodos para esta entidad (o el del material): número, Vec4, Color o Asset.
