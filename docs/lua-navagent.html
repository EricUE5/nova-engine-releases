Referencia de Lua · Componente

NavAgent

Agente de navegación: componente (Navegación). Va hasta un destino por la malla de navegación (con agente:SetDestination(pos) en Lua), esquivando a los demás agentes. Mueve su CharacterController o su Transform; en red lo mueve el servidor

entidad:GetComponent("NavAgent") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

surface campo

NavAgent.surface: Entity?
Malla (en el Inspector). Entidad con la «Malla de navegación» que usa (vacío = la primera de la escena)

speed campo

NavAgent.speed: number
Velocidad (en el Inspector). m/s De 0 a 100.

acceleration campo

NavAgent.acceleration: number
Aceleración (en el Inspector). m/s² De 0 a 500.

angularSpeed campo

NavAgent.angularSpeed: number
Velocidad de giro (en el Inspector). Grados por segundo al girar hacia donde va De 0 a 3600.

stoppingDistance campo

NavAgent.stoppingDistance: number
Distancia de parada (en el Inspector). Metros del destino a los que se da por llegado (OnArrived) De 0 a 50.

radius campo

NavAgent.radius: number
Radio (en el Inspector). Para esquivar a los demás agentes De 0.05 a 10.

height campo

NavAgent.height: number
Altura (en el Inspector). De 0.1 a 20.

drive campo

NavAgent.drive: "Auto" | "Character" | "Transform" | "None"
Mover con (en el Inspector). Automático: el CharacterController si la entidad lo tiene, si no el Transform. «Nada»: el script o el root motion mueven la entidad con desiredVelocity y nextPosition

target campo

NavAgent.target: Entity?
Seguir a (en el Inspector). Si se pone, el destino es esta entidad (y el camino se rehace al moverse)

autoRepath campo

NavAgent.autoRepath: boolean
Rehacer el camino (en el Inspector). Si el destino se mueve o el camino se corta (un obstáculo), buscar otro

repathDistance campo

NavAgent.repathDistance: number
Distancia para rehacer (en el Inspector). Metros que se mueve el destino antes de rehacer el camino De 0.05 a 100.

avoidance campo

NavAgent.avoidance: boolean
Esquivar agentes (en el Inspector). Evitar chocar con los demás agentes (RVO)

avoidancePriority campo

NavAgent.avoidancePriority: number
Prioridad (en el Inspector). Los de número más bajo se apartan menos (0 = el más importante) De 0 a 99.

partialPath campo

NavAgent.partialPath: boolean
Ir al punto más cercano (en el Inspector). Si no se puede llegar, acercarse todo lo posible (y avisar con OnPathFailed)

autoTraverseLinks campo

NavAgent.autoTraverseLinks: boolean
Cruzar enlaces (en el Inspector). Saltar y subir escaleras por los «Enlace de navegación» solo

destination campo

NavAgent.destination: Vec3
Destino (en el Inspector).

remainingDistance campo

NavAgent.remainingDistance: number
Distancia que falta (en el Inspector).

hasPath campo

NavAgent.hasPath: boolean
Tiene camino (en el Inspector).

pathPending campo

NavAgent.pathPending: boolean
Buscando camino (en el Inspector).

isStopped campo

NavAgent.isStopped: boolean
Parado (en el Inspector). Parado sin olvidar el camino (ponlo a false para seguir)

onLink campo

NavAgent.onLink: boolean
En un enlace (en el Inspector).

velocity campo

NavAgent.velocity: Vec3
Velocidad actual (en el Inspector).

desiredVelocity campo

NavAgent.desiredVelocity: Vec3
Velocidad deseada (en el Inspector).

nextPosition campo

NavAgent.nextPosition: Vec3
Siguiente posición (en el Inspector).

destinationRequest campo

NavAgent.destinationRequest: number
Destination Request (en el Inspector).

stopRequest campo

NavAgent.stopRequest: number
Stop Request (en el Inspector).

warpRequest campo

NavAgent.warpRequest: number
Warp Request (en el Inspector).

warpPosition campo

NavAgent.warpPosition: Vec3
Warp Position (en el Inspector).

entity campo

NavAgent.entity: Entity
La entidad que tiene este componente.

SetDestination método

NavAgent:SetDestination(position: Vec3): boolean
Va hasta ese punto por la malla: busca el camino (los largos en otro hilo), lo sigue, esquiva a los demás agentes y cruza los enlaces. Avisa con OnArrived al llegar u OnPathFailed si no puede. En red, llámalo en el servidor (if IsServer() then ... end): los clientes ven moverse al agente por su NetworkTransform. Devuelve false si aún no hay malla.

Stop método

NavAgent:Stop(): (): ()
Se para y olvida el camino (isStopped pasa a true). Para seguir, otro SetDestination.

Resume método

NavAgent:Resume(): (): ()
Sigue con el camino que tenía (pone isStopped a false).

Warp método

NavAgent:Warp(position: Vec3): (): ()
Lleva el agente a ese punto de la malla al momento (sin andar), por ejemplo al reaparecer. Si tenía destino, busca otro camino desde allí.

GetPath método

NavAgent:GetPath(): {Vec3}
Las esquinas del camino que sigue, desde donde está hasta el destino ({Vec3}; vacío si no tiene).

OnArrived método

NavAgent:OnArrived(callback: () -> ()): number
Llama a la función cuando llega al destino (a stoppingDistance). Devuelve un número para quitarla con RemoveListener. Se quita sola al destruirse el script que la puso; ponla una vez (en Start).

OnPathFailed método

NavAgent:OnPathFailed(callback: (reason: string) -> ()): number
Llama a funcion(motivo) si no puede ir al destino: "SinMalla" (no hay malla), "FueraDeLaMalla" (el agente o el destino están lejos de ella) o "Inalcanzable" (no hay camino: con «Ir al punto más cercano» se acerca todo lo posible).

RemoveListener método

NavAgent:RemoveListener(id: number): (): ()
Quita una función puesta con OnArrived u OnPathFailed (el número que devolvieron).
