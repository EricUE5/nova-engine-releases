Referencia de Lua · Componente

UiStyle

Estilo (definición): componente (Interfaz). Un estilo con nombre, como una clase de CSS: los elementos que lo usan cambian todos a la vez al editarlo

entidad:GetComponent("UiStyle") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

name campo

UiStyle.name: string
Nombre (en el Inspector). Los elementos lo nombran en su componente «Estilo». Con el nombre de un estilo de un tema integrado («Supervivencia/Botón») lo sustituye en esta escena

background campo

UiStyle.background: Color
Fondo (en el Inspector).

cornerRadius campo

UiStyle.cornerRadius: number
Radio de las esquinas (en el Inspector). De 0 a 3e+38.

cornerRadii campo

UiStyle.cornerRadii: Vec4
Radios por esquina (en el Inspector). Arriba izq., arriba der., abajo der., abajo izq. (negativo: el radio de arriba)

borderWidth campo

UiStyle.borderWidth: number
Grosor del borde (en el Inspector). De 0 a 3e+38.

borderColor campo

UiStyle.borderColor: Color
Color del borde (en el Inspector).

accent campo

UiStyle.accent: Color
Acento (en el Inspector). Relleno de barras y deslizadores, marca de los interruptores, pestaña elegida, fila elegida...

padding campo

UiStyle.padding: Vec4
Relleno (izq., arriba, der., abajo) (en el Inspector). De los grupos de layout, campos de texto y listas

gradient campo

UiStyle.gradient: "None" | "Linear" | "Radial"
Degradado (en el Inspector). Sustituye al color de la imagen

gradientStart campo

UiStyle.gradientStart: Color
Color inicial (en el Inspector).

gradientEnd campo

UiStyle.gradientEnd: Color
Color final (en el Inspector).

gradientUseMiddle campo

UiStyle.gradientUseMiddle: boolean
Tres colores (en el Inspector).

gradientMiddle campo

UiStyle.gradientMiddle: Color
Color del medio (en el Inspector).

gradientMiddlePosition campo

UiStyle.gradientMiddlePosition: number
Posición del medio (en el Inspector). De 0 a 1.

gradientAngle campo

UiStyle.gradientAngle: number
Ángulo (en el Inspector). 0°: de izquierda a derecha; 90°: de arriba abajo En radianes desde Lua (el Inspector lo enseña en grados): math.rad(90) para 90°.

shadow campo

UiStyle.shadow: boolean
Sombra (en el Inspector).

shadowOffset campo

UiStyle.shadowOffset: Vec2
Desplazamiento de la sombra (en el Inspector).

shadowBlur campo

UiStyle.shadowBlur: number
Desenfoque de la sombra (en el Inspector). De 0 a 200.

shadowSpread campo

UiStyle.shadowSpread: number
Extensión de la sombra (en el Inspector). De -100 a 100.

shadowColor campo

UiStyle.shadowColor: Color
Color de la sombra (en el Inspector).

glow campo

UiStyle.glow: boolean
Resplandor (en el Inspector).

glowSize campo

UiStyle.glowSize: number
Tamaño del resplandor (en el Inspector). De 0 a 200.

glowColor campo

UiStyle.glowColor: Color
Color del resplandor (en el Inspector).

innerShadow campo

UiStyle.innerShadow: boolean
Sombra interior (en el Inspector).

innerShadowOffset campo

UiStyle.innerShadowOffset: Vec2
Desplazamiento interior (en el Inspector).

innerShadowBlur campo

UiStyle.innerShadowBlur: number
Desenfoque interior (en el Inspector). De 0 a 200.

innerShadowColor campo

UiStyle.innerShadowColor: Color
Color de la sombra interior (en el Inspector).

font campo

UiStyle.font: Asset?
Fuente (en el Inspector). Vacío: la del texto

fontSize campo

UiStyle.fontSize: number
Tamaño (en el Inspector). 0: el del texto De 0 a 512.

textColor campo

UiStyle.textColor: Color
Color del texto (en el Inspector).

uppercase campo

UiStyle.uppercase: boolean
Mayúsculas (en el Inspector).

letterSpacing campo

UiStyle.letterSpacing: number
Espaciado entre letras (en el Inspector). De -20 a 100.

textOutline campo

UiStyle.textOutline: number
Contorno (en el Inspector). De 0 a 16.

textOutlineColor campo

UiStyle.textOutlineColor: Color
Color del contorno (en el Inspector).

textShadow campo

UiStyle.textShadow: boolean
Sombra del texto (en el Inspector).

textShadowOffset campo

UiStyle.textShadowOffset: Vec2
Desplazamiento de la sombra del texto (en el Inspector).

textShadowColor campo

UiStyle.textShadowColor: Color
Color de la sombra del texto (en el Inspector).

textGradient campo

UiStyle.textGradient: "None" | "Vertical" | "Horizontal"
Degradado del texto (en el Inspector).

textGradientColor campo

UiStyle.textGradientColor: Color
Color del degradado del texto (en el Inspector).

applyToChildText campo

UiStyle.applyToChildText: boolean
También a los textos hijos (en el Inspector). Los textos hijos sin estilo propio toman el texto de este estilo (la etiqueta de un botón)

states campo

UiStyle.states: { normal: Color, hover: Color, pressed: Color, selected: Color, disabled: Color, fade: number, }
Colores por estado (en el Inspector). Botones, interruptores, casillas, desplegables...

sprite campo

UiStyle.sprite: Asset?
Textura del fondo (en el Inspector). Fondo con textura de nueve cortes (vacío: el color y la forma de arriba). Las de la biblioteca de estilos son «builtin:Estilos/...»

slice campo

UiStyle.slice: Vec4
Bordes (izq., arriba, der., abajo) (en el Inspector). Píxeles de la textura que no se estiran

sliceScale campo

UiStyle.sliceScale: number
Escala de los bordes (en el Inspector). 0,5: la textura está al doble de resolución (nítida en 4K) De 0.01 a 3e+38.

sliceTiled campo

UiStyle.sliceTiled: boolean
Repetir el centro (mosaico) (en el Inspector).

hoverSprite campo

UiStyle.hoverSprite: Asset?
Textura encima (en el Inspector). Botones: con el ratón encima (vacía: la del fondo)

pressedSprite campo

UiStyle.pressedSprite: Asset?
Textura pulsado (en el Inspector).

disabledSprite campo

UiStyle.disabledSprite: Asset?
Textura desactivado (en el Inspector).

fillSprite campo

UiStyle.fillSprite: Asset?
Textura del relleno (en el Inspector). Barras y deslizadores: se tiñe con el acento

fillSlice campo

UiStyle.fillSlice: Vec4
Bordes del relleno (en el Inspector).

handleSprite campo

UiStyle.handleSprite: Asset?
Textura del tirador (en el Inspector).

checkSprite campo

UiStyle.checkSprite: Asset?
Textura de la marca (en el Inspector). Interruptores: se tiñe con el acento

danger campo

UiStyle.danger: Color
Peligro (en el Inspector). Color de las barras con valor bajo

trailColor campo

UiStyle.trailColor: Color
Color del rastro (en el Inspector).

segments campo

UiStyle.segments: number
Segmentos (en el Inspector). 0: los de cada barra De 0 a 64.

segmentGap campo

UiStyle.segmentGap: number
Hueco entre segmentos (en el Inspector). De 0 a 3e+38.

wear campo

UiStyle.wear: number
Desgaste (en el Inspector). Bordes mellados, pintura saltada, arañazos y suciedad. Cada elemento lo dibuja distinto (semilla); un componente «Desgaste» lo cambia en uno De 0 a 1.

wearEdges campo

UiStyle.wearEdges: boolean
Bordes mellados (en el Inspector).

wearChips campo

UiStyle.wearChips: boolean
Pintura saltada (en el Inspector).

wearScratches campo

UiStyle.wearScratches: boolean
Arañazos (en el Inspector).

wearDirt campo

UiStyle.wearDirt: boolean
Suciedad (en el Inspector).

wearColor campo

UiStyle.wearColor: Color
Color bajo la pintura (en el Inspector).

wearScale campo

UiStyle.wearScale: number
Tamaño del detalle (en el Inspector). De 0.1 a 8.

entity campo

UiStyle.entity: Entity
La entidad que tiene este componente.
