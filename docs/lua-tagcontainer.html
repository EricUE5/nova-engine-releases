Referencia de Lua · Tipo

TagContainer

Contenedor de etiquetas: un campo Tags(), entidad:GetTags() o Tags.Container(). Los dos primeros leen y escriben el original.

Has método

TagContainer:Has(tag: GameplayTag): boolean
c:Has("Objeto.Botin"): alguna etiqueta es esa o una hija suya.

HasExact método

TagContainer:HasExact(tag: GameplayTag): boolean
c:HasExact("Objeto.Botin"): tiene exactamente esa etiqueta.

HasAny método

TagContainer:HasAny(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
c:HasAny({ ... }): encaja con alguna de las etiquetas (jerárquico).

HasAll método

TagContainer:HasAll(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
c:HasAll({ ... }): encaja con todas (jerárquico).

Add método

TagContainer:Add(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
c:Add(etiqueta o lista): añade las que no tenga. true si añadió alguna.

Remove método

TagContainer:Remove(tags: GameplayTag | {GameplayTag} | TagContainer): boolean
c:Remove(etiqueta o lista): quita esas (exactas). true si quitó alguna.

Clear método

TagContainer:Clear(): (): ()
Quita todas.

GetAll método

TagContainer:GetAll(): {string}
Las etiquetas en una lista.

Count método

TagContainer:Count(): number
Cuántas tiene (también #c).

Copy método

TagContainer:Copy(): TagContainer
Una copia suelta.
