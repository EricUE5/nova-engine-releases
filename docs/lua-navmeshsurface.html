NavMeshSurface

Malla de navegación: componente (Navegación). Por dónde pueden ir los agentes: se hornea en el panel «Navegación» (Ventana > Navegación) y se guarda en un fichero .navmesh

entidad:GetComponent("NavMeshSurface") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

data campo

NavMeshSurface.data: Asset?
Malla horneada (en el Inspector). Fichero .navmesh (lo crea el botón «Hornear» del panel Navegación)

agentRadius campo

NavMeshSurface.agentRadius: number
Radio del agente (en el Inspector). Metros: lo caminable se separa esto de las paredes De 0.05 a 5.

agentHeight campo

NavMeshSurface.agentHeight: number
Altura del agente (en el Inspector). Altura libre mínima (techos, mesas) De 0.2 a 10.

maxSlope campo

NavMeshSurface.maxSlope: number
Pendiente máxima (en el Inspector). Grados De 0 a 85.

stepHeight campo

NavMeshSurface.stepHeight: number
Escalón máximo (en el Inspector). Metros que se suben sin saltar De 0 a 3.

cellSize campo

NavMeshSurface.cellSize: number
Tamaño de celda (en el Inspector). Metros de cada celda: más pequeño, más detalle y más lento. 0,25 para escenas normales; 0,5 o 1 para mundos de kilómetros De 0.05 a 4.

cellHeight campo

NavMeshSurface.cellHeight: number
Altura de celda (en el Inspector). Precisión vertical (metros) De 0.02 a 1.

tileSize campo

NavMeshSurface.tileSize: number
Tamaño de tesela (en el Inspector). Celdas por lado de cada tesela (se hornean y se rehacen por separado) De 16 a 255.

useColliders campo

NavMeshSurface.useColliders: boolean
Colisionadores (en el Inspector). Colisionadores estáticos (sin cuerpo rígido o con uno estático)

useMeshes campo

NavMeshSurface.useMeshes: boolean
Mallas estáticas (en el Inspector). Mallas (MeshRenderer) de lo que no se mueve

useTerrain campo

NavMeshSurface.useTerrain: boolean
Terreno (en el Inspector). Los terrenos, con las carreteras y los ríos que los adaptan

useRoads campo

NavMeshSurface.useRoads: boolean
Carreteras (en el Inspector). Carreteras y cruces, con el área «Carretera»

useTrees campo

NavMeshSurface.useTrees: boolean
Troncos de los árboles (en el Inspector). Los troncos de los árboles pintados en el terreno no se pueden atravesar

useWater campo

NavMeshSurface.useWater: boolean
Agua (en el Inspector). Mar, lagos y ríos: lo poco hondo es «Agua» y lo más hondo no se camina

maxWaterDepth campo

NavMeshSurface.maxWaterDepth: number
Profundidad máxima (en el Inspector). Metros de agua que aún se cruzan andando (0 = el agua nunca se camina) De 0 a 5.

terrainLayers campo

NavMeshSurface.terrainLayers: { { layer: number, area: "NotWalkable" | "Walkable" | "Road" | "Mud" | "Water" | "Custom1" | "Custom2" | "Custom3", } }
Áreas de las capas (en el Inspector). Área de cada capa del terreno. Sin nada, la capa «Barro» es Barro y el resto Caminable Es una copia: para cambiarla, asigna la lista entera.

limitToBox campo

NavMeshSurface.limitToBox: boolean
Solo dentro de la caja (en el Inspector). Hornear solo lo que hay dentro de una caja centrada en esta entidad

boxSize campo

NavMeshSurface.boxSize: Vec3
Caja (en el Inspector). Medidas de la caja (metros)

dynamicObstacles campo

NavMeshSurface.dynamicObstacles: boolean
Obstáculos dinámicos (en el Inspector). Guarda lo necesario para que los «Obstáculo de navegación» tallen la malla al jugar (el fichero ocupa más)

costWalkable campo

NavMeshSurface.costWalkable: number
Caminable (en el Inspector). Lo que cuesta cada metro (1 = normal; menos, preferido; más, se evita) De 0.01 a 100.

costRoad campo

NavMeshSurface.costRoad: number
Carretera (en el Inspector). De 0.01 a 100.

costMud campo

NavMeshSurface.costMud: number
Barro (en el Inspector). De 0.01 a 100.

costWater campo

NavMeshSurface.costWater: number
Agua (en el Inspector). De 0.01 a 100.

costCustom1 campo

NavMeshSurface.costCustom1: number
Personalizada 1 (en el Inspector). De 0.01 a 100.

costCustom2 campo

NavMeshSurface.costCustom2: number
Personalizada 2 (en el Inspector). De 0.01 a 100.

costCustom3 campo

NavMeshSurface.costCustom3: number
Personalizada 3 (en el Inspector). De 0.01 a 100.

entity campo

NavMeshSurface.entity: Entity
La entidad que tiene este componente.
