Referencia de Lua · Librería

Mathf

Ayudas de matemáticas además de la librería math de Luau (math.clamp, math.lerp, math.rad, math.noise...).

PI campo

Mathf.PI: number
π (3,14159...).

Lerp función

Mathf.Lerp(a: number, b: number, t: number): number
De a a b según t, con t limitado a 0..1 (math.lerp no lo limita).

InverseLerp función

Mathf.InverseLerp(a: number, b: number, value: number): number
En qué fracción (0..1) de a a b está valor.

SmoothStep función

Mathf.SmoothStep(edge0: number, edge1: number, x: number): number
0 antes de borde0, 1 después de borde1 y una curva suave entre medias.

MoveTowards función

Mathf.MoveTowards(current: number, target: number, maxStep: number): number
Acerca actual a objetivo como mucho pasoMaximo.

Approximately función

Mathf.Approximately(a: number, b: number, epsilon: number?): boolean
true si los dos números son casi iguales (con un margen opcional).

Repeat función

Mathf.Repeat(t: number, length: number): number
t dentro de [0, largo): como un módulo que funciona con negativos.

PingPong función

Mathf.PingPong(t: number, length: number): number
Sube de 0 a largo y vuelve a bajar según t.

DeltaAngle función

Mathf.DeltaAngle(a: number, b: number): number
La diferencia más corta entre dos ángulos en grados (−180 a 180).

LerpAngle función

Mathf.LerpAngle(a: number, b: number, t: number): number
Como Lerp, por el camino más corto entre dos ángulos (grados).

SmoothDamp función

Mathf.SmoothDamp(current: number, target: number, velocity: number, smoothTime: number, dt: number, maxSpeed: number?): (number, number)
Un muelle crítico: acerca actual a objetivo sin pasarse (cámaras que siguen). Devuelve el valor y la velocidad nueva: x, self._vel = Mathf.SmoothDamp(x, objetivo, self._vel, 0.3, dt).

Infinity campo

Mathf.Infinity: number
Infinito (math.huge).

NegativeInfinity campo

Mathf.NegativeInfinity: number
Menos infinito.

Epsilon campo

Mathf.Epsilon: number
Un margen pequeño (0,000001) para comparar decimales.

Deg2Rad campo

Mathf.Deg2Rad: number
Multiplica grados por esto para tener radianes (π / 180).

Rad2Deg campo

Mathf.Rad2Deg: number
Multiplica radianes por esto para tener grados (180 / π).

Clamp función

Mathf.Clamp(value: number, min: number, max: number): number
El valor limitado entre min y max.

Clamp01 función

Mathf.Clamp01(value: number): number
El valor limitado entre 0 y 1.

Sign función

Mathf.Sign(value: number): number
1 si el valor es 0 o positivo y −1 si es negativo (math.sign(0) da 0).

FloorToInt función

Mathf.FloorToInt(value: number): number
El entero de abajo (math.floor).

CeilToInt función

Mathf.CeilToInt(value: number): number
El entero de arriba (math.ceil).

RoundToInt función

Mathf.RoundToInt(value: number): number
El entero más cercano; 2,5 da 3 y −2,5 da −3 (como math.round).

IsPowerOfTwo función

Mathf.IsPowerOfTwo(value: number): boolean
true si es 1, 2, 4, 8, 16...

NextPowerOfTwo función

Mathf.NextPowerOfTwo(value: number): number
La potencia de dos más pequeña que no es menor que el valor (texturas): 100 da 128.

ClosestPowerOfTwo función

Mathf.ClosestPowerOfTwo(value: number): number
La potencia de dos más cercana (en un empate, la mayor): 100 da 128, 90 da 64.

GammaToLinear función

Mathf.GammaToLinear(value: number): number
De gamma (sRGB, lo que se ve en un selector de color) a lineal (lo que usa la luz).

LinearToGamma función

Mathf.LinearToGamma(value: number): number
De lineal a gamma (sRGB).

Remap función

Mathf.Remap(value: number, fromMin: number, fromMax: number, toMin: number, toMax: number): number
Pasa un valor de un rango a otro (sin limitar): Mathf.Remap(vida, 0, 100, 0, 1).

Wrap función

Mathf.Wrap(value: number, min: number, max: number): number
Da la vuelta dentro de [min, max): Mathf.Wrap(370, 0, 360) da 10.

Step función

Mathf.Step(edge: number, x: number): number
0 si x es menor que borde y 1 si no.

LerpUnclamped función

Mathf.LerpUnclamped(a: number, b: number, t: number): number
De a a b según t sin limitar t (con t = 2, el doble de lejos).
