Referencia de Lua · Componente

RigidBody

Cuerpo rígido: componente (Física). La entidad se mueve con las físicas (necesita un Collider)

entidad:GetComponent("RigidBody") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

type campo

RigidBody.type: "Estático" | "Cinemático" | "Dinámico"
Tipo (en el Inspector). Estático: no se mueve. Cinemático: lo mueve el juego. Dinámico: lo mueve la simulación

mass campo

RigidBody.mass: number
Masa (en el Inspector). kg (0 = calculada por volumen) De 0 a 1e+05.

friction campo

RigidBody.friction: number
Fricción (en el Inspector). De 0 a 1.

restitution campo

RigidBody.restitution: number
Rebote (en el Inspector). De 0 a 1.

linearDamping campo

RigidBody.linearDamping: number
Amortiguación lineal (en el Inspector). De 0 a 10.

angularDamping campo

RigidBody.angularDamping: number
Amortiguación angular (en el Inspector). De 0 a 10.

gravityFactor campo

RigidBody.gravityFactor: number
Factor de gravedad (en el Inspector). 0 = flota De -10 a 10.

continuousCollision campo

RigidBody.continuousCollision: boolean
Colisión continua (CCD) (en el Inspector). Para objetos pequeños y rápidos

interpolate campo

RigidBody.interpolate: boolean
Interpolar (en el Inspector). Suaviza el movimiento entre pasos de física

lockPositionX campo

RigidBody.lockPositionX: boolean
Bloquear posición X (en el Inspector).

lockPositionY campo

RigidBody.lockPositionY: boolean
Bloquear posición Y (en el Inspector).

lockPositionZ campo

RigidBody.lockPositionZ: boolean
Bloquear posición Z (en el Inspector).

lockRotationX campo

RigidBody.lockRotationX: boolean
Bloquear rotación X (en el Inspector).

lockRotationY campo

RigidBody.lockRotationY: boolean
Bloquear rotación Y (en el Inspector).

lockRotationZ campo

RigidBody.lockRotationZ: boolean
Bloquear rotación Z (en el Inspector).

layer campo

RigidBody.layer: "Automática" | "Estática" | "Dinámica" | "Jugador" | "Sensor" | "Escombros"
Capa (en el Inspector).

entity campo

RigidBody.entity: Entity
La entidad que tiene este componente.

velocity campo

RigidBody.velocity: Vec3
Velocidad del cuerpo (m/s, lectura y escritura).

angularVelocity campo

RigidBody.angularVelocity: Vec3
Velocidad de giro (radianes por segundo, lectura y escritura).

sleeping campo

RigidBody.sleeping: boolean
true si está dormido (no se simula hasta que algo lo toca).

isKinematic campo

RigidBody.isKinematic: boolean
Cinemático: lo mueve el código (plataformas, puertas) con MovePosition/MoveRotation (lectura y escritura).

AddForce método

RigidBody:AddForce(force: Vec3): (): ()
Fuerza continua (en cada paso fijo).

AddForceAtPoint método

RigidBody:AddForceAtPoint(force: Vec3, point: Vec3): (): ()
Fuerza en un punto del mundo: también lo hace girar.

AddImpulse método

RigidBody:AddImpulse(impulse: Vec3): (): ()
Impulso instantáneo: un golpe, un salto.

AddImpulseAtPoint método

RigidBody:AddImpulseAtPoint(impulse: Vec3, point: Vec3): (): ()
Impulso en un punto del mundo: también lo hace girar.

AddTorque método

RigidBody:AddTorque(torque: Vec3): (): ()
Par de giro.

WakeUp método

RigidBody:WakeUp(): (): ()
Lo despierta.

Sleep método

RigidBody:Sleep(): (): ()
Lo duerme hasta que algo lo toca.

Teleport método

RigidBody:Teleport(position: Vec3, rotation: Quat?): (): ()
Lo mueve sin atravesar ni interpolar.

MovePosition método

RigidBody:MovePosition(position: Vec3): (): ()
Cinemáticos: llega ahí en el siguiente paso fijo empujando a lo que toca.

MoveRotation método

RigidBody:MoveRotation(rotation: Quat): (): ()
Cinemáticos: gira hasta ahí en el siguiente paso fijo.
