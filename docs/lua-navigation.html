Navigation

Caminos por la malla de navegación (la que se hornea en el panel Navegación del editor): buscar un camino, el punto de la malla más cercano, un rayo sobre la malla, un punto al azar para pasear y si se puede llegar. Los agentes (componente Agente de navegación, NavAgent) lo hacen solos con agente:SetDestination(pos). Todo va en código nativo: cientos de caminos cortos por frame.

FindPath función

Navigation.FindPath(from: Vec3, to: Vec3, options: NavPathOptions?): ({Vec3}?, boolean)
Camino de desde a hasta por la malla: una lista de puntos ({Vec3}, el primero es el origen llevado a la malla y el último el destino) y si llega (true) o solo se acerca. nil si no hay malla, si los puntos están lejos de ella o si no se puede llegar (salvo con partial = true en las opciones). Para caminos muy largos, mejor FindPathAsync.

FindPathAsync función

Navigation.FindPathAsync(from: Vec3, to: Vec3, callback: (path: {Vec3}?, complete: boolean) -> (), options: NavPathOptions?): number
Lo mismo que FindPath en otro hilo: llama a callback(camino, completo) en un frame siguiente (camino es nil si no hay). Devuelve un número para cancelarlo con Navigation.CancelPath. Si el script que lo pidió se destruye antes, no se llama.

CancelPath función

Navigation.CancelPath(id: number): ()
Cancela un camino pedido con FindPathAsync (su función ya no se llama).

SamplePosition función

Navigation.SamplePosition(position: Vec3, maxDistance: number?): (Vec3?, string?)
El punto de la malla más cercano a position a menos de maxDistance metros (2 si no se pone) y su área ("Walkable", "Road"...), o nil si no hay ninguno. Sirve para saber si un sitio es pisable o para llevar un punto al suelo.

Raycast función

Navigation.Raycast(from: Vec3, to: Vec3): (boolean, Vec3)
Rayo sobre la malla de from a to (en planta, siguiendo el suelo): true y el punto del borde si choca antes de llegar (una pared, un precipicio); false y el destino si se puede ir en línea recta. Para saber si un bot ve el camino libre hasta alguien.

RandomPoint función

Navigation.RandomPoint(center: Vec3, radius: number): Vec3?
Un punto al azar de la malla a menos de radius metros de center (por zonas conectadas), o nil. Para que un bot pasee: agente:SetDestination(Navigation.RandomPoint(casa, 20)).

IsReachable función

Navigation.IsReachable(from: Vec3, to: Vec3): boolean
true si se puede ir de un punto al otro por la malla (con los enlaces de salto y escalera).

SetAreaCost función

Navigation.SetAreaCost(area: NavAreaName, cost: number): ()
Cambia el coste de un área para toda la partida (los agentes y las consultas sin areaCosts): Navigation.SetAreaCost("Water", 20) hace que se evite el agua. 1 es lo normal; menos, se prefiere (las carreteras valen 0,6).

GetAreaCost función

Navigation.GetAreaCost(area: NavAreaName): number
El coste de un área (el de la malla o el puesto con SetAreaCost).

IsReady función

Navigation.IsReady(surface: Entity?): boolean
true si hay una malla de navegación cargada (la de esa entidad, o cualquiera).

Bake función

Navigation.Bake(callback: ((ok: boolean, error: string?) -> ())?): boolean
Vuelve a hornear la malla en otro hilo con lo que hay ahora en la escena (para mapas que se generan al jugar) y llama a callback(ok, error) al terminar. Devuelve false si la escena no tiene ninguna «Malla de navegación». La malla nueva solo vale en esta partida.
