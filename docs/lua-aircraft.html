Referencia de Lua · Componente

Aircraft

Aeronave: componente (Vehículos). Helicóptero o avión sencillo sobre un Cuerpo rígido dinámico: colectivo, cabeceo, alabeo y guiñada, estabilización asistida, efecto suelo, motor y daño

entidad:GetComponent("Aircraft") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

type campo

Aircraft.type: "Helicopter" | "Airplane"
Tipo (en el Inspector).

maxLift campo

Aircraft.maxLift: number
Sustentación máxima (en el Inspector). En veces su peso: por encima de 1 sube De 1 a 10.

climbRate campo

Aircraft.climbRate: number
Velocidad de subida (en el Inspector). m/s con el colectivo a tope (con la estabilización) De 0.5 a 50.

groundEffect campo

Aircraft.groundEffect: number
Efecto suelo (en el Inspector). Sustentación de más pegado al suelo De 0 a 1.

rotorDiameter campo

Aircraft.rotorDiameter: number
Diámetro del rotor (en el Inspector). m: el efecto suelo se nota por debajo de esta altura De 0.5 a 50.

maxThrust campo

Aircraft.maxThrust: number
Empuje (en el Inspector). N a todo gas De 0 a 1e+06.

wingArea campo

Aircraft.wingArea: number
Superficie alar (en el Inspector). m² De 0.1 a 1000.

liftCoefficient campo

Aircraft.liftCoefficient: number
Sustentación de las alas (en el Inspector). De 0 a 5.

stallSpeed campo

Aircraft.stallSpeed: number
Velocidad de pérdida (en el Inspector). m/s: por debajo las alas apenas sustentan De 1 a 200.

pitchRate campo

Aircraft.pitchRate: number
Cabeceo (en el Inspector). rad/s con la palanca a tope De 0 a 10.

rollRate campo

Aircraft.rollRate: number
Alabeo (en el Inspector). rad/s De 0 a 10.

yawRate campo

Aircraft.yawRate: number
Guiñada (en el Inspector). rad/s De 0 a 10.

response campo

Aircraft.response: number
Respuesta (en el Inspector). Rapidez con la que obedece a los mandos (1/s) De 0.1 a 30.

assist campo

Aircraft.assist: boolean
Estabilización asistida (en el Inspector). Se pone recto solo al soltar los mandos y mantiene la altura (el colectivo sube o baja a velocidad constante). T la activa o desactiva

maxPitch campo

Aircraft.maxPitch: number
Cabeceo máximo (en el Inspector). Grados, con la estabilización De 1 a 89.

maxRoll campo

Aircraft.maxRoll: number
Alabeo máximo (en el Inspector). Grados, con la estabilización De 1 a 89.

drag campo

Aircraft.drag: number
Resistencia del aire (en el Inspector). De 0 a 5.

engineStartTime campo

Aircraft.engineStartTime: number
Arranque del motor (en el Inspector). Segundos hasta coger todas las vueltas De 0 a 60.

startOnEnter campo

Aircraft.startOnEnter: boolean
Arrancar al subir (en el Inspector). El motor arranca cuando sube el piloto (también con I)

stopOnExit campo

Aircraft.stopOnExit: boolean
Apagar al bajar (en el Inspector).

maxHealth campo

Aircraft.maxHealth: number
Vida (en el Inspector). De 1 a 1e+05.

crashSpeed campo

Aircraft.crashSpeed: number
Golpe que daña (en el Inspector). m/s de cambio de velocidad en un golpe a partir de los que se daña De 0 a 100.

crashDamage campo

Aircraft.crashDamage: number
Daño por golpe (en el Inspector). Vida por cada m/s por encima De 0 a 1000.

rotors campo

Aircraft.rotors: { { entity: Entity?, axis: Vec3, rpm: number, } }
Rotores (en el Inspector). Entidades que giran con el motor (el rotor principal y el de cola, o la hélice) Es una copia: para cambiarla, asigna la lista entera.

defaultControls campo

Aircraft.defaultControls: boolean
Controles de serie (en el Inspector). Mayús/Ctrl o gatillos: colectivo (avión: gas); W/S: cabeceo; A/D: alabeo; Q/E o ratón: guiñada; I: motor; T: estabilización

mouseControl campo

Aircraft.mouseControl: boolean
Con el ratón (en el Inspector). El ratón maneja la guiñada y el cabeceo además del teclado

mouseSensitivity campo

Aircraft.mouseSensitivity: number
Sensibilidad del ratón (en el Inspector). De 0.001 a 1.

soundPitchIdle campo

Aircraft.soundPitchIdle: number
Tono al arrancar (en el Inspector). Con un Fuente de audio en bucle en la aeronave, su tono sigue a las vueltas del motor De 0.05 a 4.

soundPitchMax campo

Aircraft.soundPitchMax: number
Tono a tope (en el Inspector). De 0.05 a 4.

inCollective campo

Aircraft.inCollective: number
In Collective (en el Inspector).

inPitch campo

Aircraft.inPitch: number
In Pitch (en el Inspector).

inRoll campo

Aircraft.inRoll: number
In Roll (en el Inspector).

inYaw campo

Aircraft.inYaw: number
In Yaw (en el Inspector).

inThrottle campo

Aircraft.inThrottle: number
In Throttle (en el Inspector).

scriptInputStep campo

Aircraft.scriptInputStep: string
Script Input Step (en el Inspector).

engineRequest campo

Aircraft.engineRequest: boolean
Engine Request (en el Inspector).

engineWanted campo

Aircraft.engineWanted: boolean
Engine Wanted (en el Inspector).

engineOn campo

Aircraft.engineOn: boolean
Motor encendido (en el Inspector).

rotorSpeed campo

Aircraft.rotorSpeed: number
Vueltas del motor (en el Inspector). De 0 a 1.

health campo

Aircraft.health: number
Vida actual (en el Inspector). De 0 a 1e+05.

destroyed campo

Aircraft.destroyed: boolean
Destruida (en el Inspector).

altitude campo

Aircraft.altitude: number
Altura (en el Inspector). m sobre el suelo De 0 a 10000.

airSpeed campo

Aircraft.airSpeed: number
Velocidad (en el Inspector). m/s De 0 a 1000.

netSeq campo

Aircraft.netSeq: number
Net Seq (en el Inspector).

netPos campo

Aircraft.netPos: Vec3
Net Pos (en el Inspector).

netRot campo

Aircraft.netRot: Quat
Net Rot (en el Inspector).

netVel campo

Aircraft.netVel: Vec3
Net Vel (en el Inspector).

netAngVel campo

Aircraft.netAngVel: Vec3
Net Ang Vel (en el Inspector).

entity campo

Aircraft.entity: Entity
La entidad que tiene este componente.

SetInput método

Aircraft:SetInput(input: AircraftInput): (): ()
Pone la entrada de la aeronave: { collective = 1, pitch = 0, roll = 0, yaw = 0 } (el colectivo sube o baja; con la estabilización asistida, 0 mantiene la altura). Gana a los controles de serie durante un cuarto de segundo.

SetEngine método

Aircraft:SetEngine(on: boolean): (): ()
Arranca (true) o apaga el motor (en el servidor). Los rotores tardan «Arranque del motor» segundos en coger vueltas; sin vueltas no sube.

IsEngineOn método

Aircraft:IsEngineOn(): boolean
true con el motor encendido.

GetAltitude método

Aircraft:GetAltitude(): number
Metros sobre lo que haya debajo.

GetRotorSpeed método

Aircraft:GetRotorSpeed(): number
Vueltas del motor de 0 a 1.

Damage método

Aircraft:Damage(amount: number): (): ()
Le quita vida (en el servidor). Sin vida, el motor se para y no vuelve a arrancar: cae.

Repair método

Aircraft:Repair(): (): ()
Vida completa y deja de estar destruida (en el servidor).

SetAssist método

Aircraft:SetAssist(on: boolean): (): ()
Activa o desactiva la estabilización asistida (se pone recta sola y mantiene la altura).
