Referencia de Lua · Librería

Network

La partida en red: modo, jugadores, objetos de red, y empezar o unirse a partidas desde un menú. Lo normal para comunicar servidor y clientes son los atributos --[Replicated], --[Server], --[Client] y --[Multicast].

IsServer función

Network.IsServer(): boolean
Igual que IsServer(): el servidor, el anfitrión o sin red.

IsClient función

Network.IsClient(): boolean
Igual que IsClient(): las máquinas con jugador.

IsAvailable función

Network.IsAvailable(): boolean
true si el programa tiene servicio de red.

IsRunning función

Network.IsRunning(): boolean
true si hay una partida en red en marcha.

IsConnected función

Network.IsConnected(): boolean
true si este cliente está conectado al servidor.

LocalClientId función

Network.LocalClientId(): number
El id del jugador de esta máquina.

PlayerName función

Network.PlayerName(): string
El nombre con el que juega esta máquina (en una partida, como lo ven los demás: «Ana 2» si ya había una «Ana»).

Mode función

Network.Mode(): "None" | "Offline" | "Host" | "Client" | "DedicatedServer"
"None", "Offline", "Host", "Client" o "DedicatedServer".

Spawn función

Network.Spawn(prefab: Asset | string, position: Vec3?, rotation: Quat?, options: SpawnOptions?): Entity?
Igual que Spawn: crea un prefab con Identidad de red en el servidor y en todos los clientes (solo el servidor).

SetOwner función

Network.SetOwner(entity: Entity, player: number): boolean
Solo el servidor: cambia el dueño de un objeto de red (quién puede llamar a sus [Server], a quién llegan sus [Client] y sus campos OwnerOnly).

GetOwner función

Network.GetOwner(entity: Entity): number
El id del dueño de un objeto de red (0 = el servidor).

Teleport función

Network.Teleport(entity: Entity, position: Vec3, rotation: Quat?): ()
Solo el servidor: teletransporte de red. Los demás no ven el salto interpolado y un personaje con predicción se corrige también en su dueño.

Host función

Network.Host(options: SessionOptions?): (string?, string?)
Pide una partida con este jugador de anfitrión: Network.Host({ port = 7777, maxPlayers = 8 }). Con { relay = true } (Nova Enlace, por Internet) devuelve el código de la partida, o nil y el motivo si el relé no contesta. Con { transport = "steam" } la partida va por Steam (los demás entran con Network.Connect("steam:<tu SteamID>") o desde un lobby); sin transport, el de Ajustes del proyecto > Red.

Connect función

Network.Connect(address: string, options: SessionOptions?): ()
Se une a una partida: "ip:puerto", un código de Nova Enlace ("NOVA-7K2F-Q9XM") o "steam:<id>", con contraseña opcional.

GetCode función

Network.GetCode(): string
El código de la partida por Nova Enlace ("NOVA-XXXX-XXXX"), o "" si no va por código.

PlayOffline función

Network.PlayOffline(): ()
Pide una partida de un jugador, sin red. Se abre aunque la escena no tenga componentes de red: Network.Mode() da "Offline", el jugador es el servidor de sí mismo y Network.LoadScene cambia de escena dentro de la partida.

Disconnect función

Network.Disconnect(): ()
Deja la partida (o la cierra en el anfitrión) y vuelve a la escena inicial.

SetPlayerName función

Network.SetPlayerName(name: string): ()
Cambia tu nombre: el de la próxima partida y, ya dentro, el de esta (el servidor lo limpia y lo hace único: «Ana 2»; lo ven todos).

SetSystemMessages función

Network.SetSystemMessages(enabled: boolean): ()
false: los avisos del motor («Ana se ha unido a la partida», «Ana ha salido (...)») no salen en el HUD ni en el chat de esta máquina (solo en el registro); el juego pone los suyos con los eventos playerJoined/playerDropped (en el servidor) o Lobby.OnChanged. Salen en el idioma del juego; una tabla de idiomas del proyecto con nova.red.unido y nova.red.salido (con {nombre} y {motivo}) cambia el texto.

GetSystemMessages función

Network.GetSystemMessages(): boolean
true si los avisos del motor salen en el HUD y el chat (por defecto).

StartLanSearch función

Network.StartLanSearch(): ()
Empieza a buscar partidas en la red local (las da LanServers()).

StopLanSearch función

Network.StopLanSearch(): ()
Deja de buscar partidas en la red local.

LanServers función

Network.LanServers(): {LanServer}
Las partidas encontradas en la red local: { address, name, players, maxPlayers, password, ping... }.

StatusText función

Network.StatusText(): string
Texto del estado de la red (para un menú).

LastError función

Network.LastError(): string
El último error de la red (para un menú).

IsHost función

Network.IsHost(): boolean
true en el anfitrión (servidor con jugador).

IsDedicatedServer función

Network.IsDedicatedServer(): boolean
true en el servidor dedicado (NovaServer.exe).

Players función

Network.Players(): {NetworkPlayer}
Los jugadores con sus datos: { { id, name, ping, isLocal } } (el servidor los conoce todos).

GetPing función

Network.GetPing(player: number?): number?
Ida y vuelta en ms de ese jugador (en el servidor); sin jugador, el de esta máquina con el servidor (0 en el servidor).

GetServerTime función

Network.GetServerTime(): number
Hora del servidor en segundos desde que empezó la partida (en un cliente, su estimación). 0 sin red.

GetViewTime función

Network.GetViewTime(): number
Hora del servidor de lo que esta máquina ve ahora de los demás (en un cliente, la de las entidades interpoladas). Envíala con el disparo para que el servidor rebobine a eso: Physics.RaycastRewind(..., { time = vista }).

Kick función

Network.Kick(player: number, reason: string?): boolean
Solo el servidor: expulsa a un jugador (le llega el motivo). true si estaba conectado.

GetLocalPlayer función

Network.GetLocalPlayer(): Entity?
El personaje del jugador de esta máquina, o nil.

Stats función

Network.Stats(): NetworkStats
La conexión: { rtt, jitter, loss, kbIn, kbOut, players, entities, tick, packetsOut, packetsIn } (paquetes enviados y recibidos desde que empezó la sesión).

SetObservers función

Network.SetObservers(entity: Entity, players: {number}): ()
Solo el servidor: qué jugadores reciben las tablas replicadas con condition = "Observers" de esa entidad ({} = nadie).

GetObservers función

Network.GetObservers(entity: Entity): {number}
La lista de jugadores de SetObservers de esa entidad.

LoadScene función

Network.LoadScene(scene: string | Asset, options: LoadSceneOptions?): (boolean, string?)
Servidor: cambia de escena a todos a la vez (o a unos jugadores) con pantalla de carga: Network.LoadScene("scenes/Ronda", { loadingScreen = "prefabs/Carga", waitForAll = true }). Cada máquina la carga en segundo plano, avisa al servidor y este espera a todos (como mucho timeout segundos, 60 por defecto) antes de quitar las pantallas: entonces llega allPlayersLoaded / OnAllPlayersLoaded. Los personajes salen del «Aparición de jugadores» de la escena nueva y quien entra tarde carga la escena actual. Con to = id (o {ids}) solo esos jugadores van a una escena local suya (un menú, una sala de espera) sin objetos de red; vuelven con Network.LoadScene(Network.GetScene(), { to = id }). Sin red, cambia de escena con la pantalla de carga. Devuelve true, o false y el motivo.

GetScene función

Network.GetScene(): string
La escena del servidor (ruta en assets/, "scenes/Ronda.scene").

IsLoading función

Network.IsLoading(): boolean
true mientras esta máquina carga una escena o espera a los demás (la pantalla de carga está puesta).

AllPlayersLoaded función

Network.AllPlayersLoaded(): boolean
true cuando todos los jugadores tienen la escena actual (el servidor ya dio la salida).

GetLoadingPlayers función

Network.GetLoadingPlayers(): {number}
Los jugadores que aún están cargando la escena del servidor (ids).

GetLoadProgress función

Network.GetLoadProgress(): number
Progreso de la carga de esta máquina, de 0 a 1 (1 si no carga nada).

GetPlayerEntity función

Network.GetPlayerEntity(player: number): Entity?
La entidad del personaje del jugador con ese id, o nil: local personaje = Network.GetPlayerEntity(source). Primero la que creó su «Aparición de jugadores»; si no, la entidad con Identidad de red marcada como jugador (isPlayer) de ese dueño; sin red, con el id del jugador local (0), el primer personaje marcado como jugador. Ya no hace falta recorrer FindAllWithComponent("CharacterController") con GetOwner.

GetPlayersInRadius función

Network.GetPlayersInRadius(position: Vec3, radius: number, options: PlayerQueryOptions?): ({number}, {number}?)
Network.GetPlayersInRadius(posicion, radio, opciones?): los ids de los jugadores con su personaje a esa distancia como mucho, de más cerca a más lejos. Opciones: { team = 2, excludeTeam = 1, ignore = source, max = 5, distances = true } (con distances, devuelve también la lista de distancias). Vale en cualquier máquina: en un cliente, con los personajes que le llegan. local cerca = Network.GetPlayersInRadius(bomba.position, 10).

GetNearestPlayer función

Network.GetNearestPlayer(position: Vec3, options: NearestPlayerOptions?): (number?, Entity?, number?)
Network.GetNearestPlayer(posicion, opciones?): el id del jugador más cercano, su personaje y la distancia (o nil). Opciones: { team, excludeTeam, ignore, maxDistance }. local id, personaje = Network.GetNearestPlayer(self.entity.position, { excludeTeam = self.equipo }) para que un zombi persiga al más cercano.

GetPlayerInfo función

Network.GetPlayerInfo(player: number?): PlayerInfo?
Network.GetPlayerInfo(id?): todo lo de un jugador en una tabla (sin id, el de esta máquina): { id, name, ping, team, isLocal, isLeader, entity, steamId }. ping en ms (un cliente solo sabe el suyo; el de los demás, 0); steamId (texto) en el servidor si entró por Steam. nil si no está en la partida.

GetPlayersOnTeam función

Network.GetPlayersOnTeam(team: number): {number}
Network.GetPlayersOnTeam(equipo): los ids de los jugadores de ese equipo (Lobby.SetTeam o Network.AssignTeams), de menor a mayor.

SendToPlayers función

Network.SendToPlayers(players: number | {number}, event: string, ...any): number
Servidor: Network.SendToPlayers(ids, evento, ...) manda un evento de red (como TriggerClientEvent) a esos jugadores, serializado una sola vez. Lo reciben con RegisterNetEvent(evento, fn). Devuelve a cuántos se envió. En un cliente es un error que lo dice.

SendToTeam función

Network.SendToTeam(team: number, event: string, ...any): number
Servidor: Network.SendToTeam(equipo, evento, ...) manda un evento de red a los jugadores de ese equipo (el aviso de «bomba plantada» solo a los defensores). Devuelve a cuántos se envió.

SendToNearby función

Network.SendToNearby(position: Vec3, radius: number, event: string, ...any): number
Servidor: Network.SendToNearby(posicion, radio, evento, ...) manda un evento de red solo a los jugadores con su personaje a esa distancia (una explosión, un grito, un sonido que no hace falta mandar a todo el mapa). Devuelve a cuántos se envió.

AssignTeams función

Network.AssignTeams(teamCount: number, options: AssignTeamsOptions?): {[number]: number}
Servidor: Network.AssignTeams(n, opciones?) reparte a los jugadores en los equipos 1..n con el mismo número (como mucho uno de diferencia), llama a Lobby.SetTeam y devuelve { [id] = equipo }. Con skill = { [id] = nivel }, además, el nivel total de los equipos queda lo más parecido posible. Sin nivel, por turnos en el orden de players (por defecto, por id; players = Random.Shuffle(...) para equipos al azar).

PickSpawnPoint función

Network.PickSpawnPoint(points: {Vec3 | Entity} | string, options: SpawnPointOptions?): (any, number?, number?)
Network.PickSpawnPoint(puntos, opciones?): el punto de aparición más lejos del enemigo más cercano. puntos: una lista de Vec3 o de entidades, o una etiqueta ("Aparicion"). Opciones: { player = source, team = 2, ignore = {...} }: enemigos son los jugadores de otro equipo (con equipo 0, todos los demás). Entre puntos igual de lejos de los enemigos, el más lejos de cualquier jugador. Devuelve el punto (el Vec3 o la entidad), su índice y la distancia al enemigo más cercano (math.huge si no hay ninguno).
