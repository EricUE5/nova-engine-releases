Esta guía es para quien usa el motor instalado con NovaEngine-Setup.exe (no para quien lo compila desde el código fuente: eso está en empezar.md). Explica qué hace el instalador, cómo se usa Nova Hub para crear y abrir proyectos, cómo llegan las actualizaciones, cómo desinstalar el motor y, para quien use scripts en C++ (opcional), qué compilador hace falta. Para hacer juegos en Lua no hace falta instalar nada más.

Requisitos#

Qué Detalle
Sistema Windows 10 (versión 1903 o posterior) u 11, de 64 bits
GPU Cualquier tarjeta con Direct3D 11. Sin GPU compatible se usa WARP (render por software de Windows), más lento
Espacio Unos 100 MB para el motor, más lo que ocupen tus proyectos (cada proyecto guarda su compilación en build\)
Permisos Ninguno especial: se instala solo para tu usuario, sin permisos de administrador
Scripts en Lua Nada: no se compilan. Para escribirlos, mejor VS Code con la extensión de Nova (viene con el motor; ver VS Code y Lua)
Scripts en C++ (opcional, avanzado) Visual Studio 2022 o sus Build Tools (gratis) con la carga de trabajo «Desarrollo para el escritorio con C++». Ver Compilar los scripts

El runtime de Visual C++ va incluido con el motor (en bin\): no hace falta instalar el «Visual C++ Redistributable». Sin Visual Studio se hace todo con Lua: crear proyectos, editar escenas, programar y jugar. Los proyectos con scripts C++ se abren y se juegan con la DLL que ya tengan compilada (las plantillas de C++ traen la suya), pero sin Visual Studio no se puede compilar código C++ nuevo.

Instalar#

  1. Descarga NovaEngine-Setup-<versión>.exe de la página de versiones del motor (GitHub Releases). Opcionalmente, compara su suma SHA-256 con la del fichero .sha256 publicado a su lado:

    Símbolo del sistema
    certutil -hashfile NovaEngine-Setup-0.2.0.exe SHA256

  2. Ejecútalo. Si aparece «Windows protegió su PC», lee SmartScreen.

  3. Sigue el asistente:

Página Qué hace
Bienvenida Qué se va a instalar. Si ya tienes Nova Engine en la carpeta, dice que se actualizará
Licencia La licencia del motor y los avisos de las librerías de terceros (TERCEROS.md)
Carpeta Por defecto %LOCALAPPDATA%\Programs\NovaEngine (solo tu usuario, sin administrador). Muestra el espacio necesario y el disponible y, al pulsar Siguiente, comprueba que se puede instalar ahí (ver Problemas al instalar)
Componentes Editor, Nova Hub y SDK (obligatorio, con las plantillas vacías «Vacío (Lua)» y «Vacío (C++, avanzado)»); plantillas y ejemplos; documentación; acceso directo en el escritorio; abrir los project.nova con Nova Hub
Instalación Comprueba el paquete (SHA-256) y copia los ficheros
Finalizar «Abrir Nova Hub»

El instalador comprueba la suma SHA-256 de todo el paquete antes de copiar nada y la de cada fichero al extraerlo: un instalador descargado a medias o modificado se rechaza sin tocar tu PC.

Qué se instala#

%LOCALAPPDATA%\Programs\NovaEngine\
  bin\                 NovaHub.exe, NovaEditor.exe, NovaGame.exe, NovaServer.exe, NovaBuild.exe,
                       runtime de Visual C++ y shaders\
  include\  lib\       el SDK para compilar los scripts de tus proyectos
  cmake\               NovaEngineConfig.cmake (find_package(NovaEngine))
  templates\           plantillas de proyecto: vacio_lua y vacio (siempre) y, con «Plantillas y ejemplos»,
                       ejemplo3d_lua, inventario_lua, ejemplo3d y multijugador
  docs\                esta documentación en HTML (index.html)
  tools\               nova-engine-<versión>.vsix: la extensión de Nova para VS Code (se instala desde el editor)
  nova-sdk.json        versión y datos del SDK
  nova-instalacion.txt lista de lo instalado (la usan el desinstalador y las actualizaciones)
  Desinstalar.exe
  LICENCIA.txt, TERCEROS.md

Fuera de esa carpeta (salvo en modo portable) el instalador crea:

  • la carpeta Nova Engine del menú Inicio, con Nova Hub y Desinstalar Nova Engine;
  • el acceso directo del escritorio, si lo marcaste;
  • la entrada de Configuración > Aplicaciones > Aplicaciones instaladas (en HKEY_CURRENT_USER);
  • la asociación de los ficheros .nova (doble clic en un project.nova abre el proyecto en el editor).

Windows protegió su PC (SmartScreen)#

Al abrir un programa descargado de Internet que no está firmado digitalmente, Windows muestra «Windows protegió su PC» y, en Editor, «Desconocido». Para seguir: Más información > Ejecutar de todas formas.

El aviso no significa que el programa tenga un virus: significa que Windows no sabe quién lo ha publicado. Para eso existen los certificados de firma de código (code signing): una entidad certificadora comprueba la identidad de quien publica y le da un certificado con el que firma sus .exe. Windows muestra entonces el nombre del editor y, con el tiempo (o desde el principio con un certificado EV), deja de avisar. Nova Engine todavía no está firmado; firmarlo es un paso posterior para quien publica el motor (ver publicar-motor.md).

Instalación desde la línea de comandos#

Opción Efecto
/S Instalación silenciosa (sin ventanas). El resultado queda en %TEMP%\NovaEngine-Setup.log
/D=<carpeta> Carpeta de instalación. Va al final y puede tener espacios sin comillas
/componentes=plantillas,docs,escritorio,asociacion Componentes opcionales (sin la opción, en silencioso: plantillas, docs y asociación)
/portable Modo portable: ver abajo
/norun No abre Nova Hub al terminar una actualización
/log=<fichero> Otro fichero de registro
/update Actualiza una instalación existente (lo usa Nova Hub, ver Actualizaciones)
/uninstall Desinstala (igual que Desinstalar.exe)

Códigos de salida: 0 bien, 1 error, 2 cancelado, 3 Nova Hub o el editor siguen abiertos, 4 instalador dañado, 5 no hay ninguna instalación en esa carpeta (al actualizar o desinstalar).

Símbolo del sistema
NovaEngine-Setup-0.2.0.exe /S /D=D:\Herramientas\Nova Engine

Modo portable#

Con /portable el instalador no escribe nada fuera de la carpeta: ni el registro, ni el menú Inicio, ni el escritorio, ni la asociación de .nova. Sirve para llevar el motor en un disco USB o para probar una versión sin tocar la instalación normal:

Símbolo del sistema
NovaEngine-Setup-0.2.0.exe /S /portable /D=E:\NovaEngine

La instalación portable recuerda que lo es (en nova-instalacion.txt): sus actualizaciones y su desinstalación tampoco tocan el registro. Abre Nova Hub con bin\NovaHub.exe.

Problemas al instalar#

Antes de copiar nada, el instalador comprueba la carpeta (también en silencio y al actualizar): crea y borra una carpeta y un fichero de prueba con los mismos nombres que usa al instalar, mira el espacio libre y qué unidad es. Si algo falla lo dice en la página Carpeta con la ruta exacta y el motivo de Windows, por ejemplo No se puede escribir en G:\NovaEngine\_actualizacion_nova: Acceso denegado. (5), y el botón Usar la carpeta recomendada vuelve a %LOCALAPPDATA%\Programs\NovaEngine. Si una instalación falla, no deja nada a medias: quita las carpetas que había creado y, en una actualización, vuelven los ficheros anteriores.

  • Dónde instalar. Lo mejor es la carpeta recomendada o una tuya en un disco de este PC (D:\Herramientas\NovaEngine). Evita las carpetas creadas por otro usuario o como administrador y los discos que vienen de otro PC: puede que tu usuario no tenga permiso para escribir en ellos («Acceso denegado»).
  • Nube y red. No instales el motor en una carpeta que se sincroniza con la nube (OneDrive, Google Drive —su unidad G: o «Mi unidad»—, Dropbox, iCloud) ni en una unidad de red: la sincronización bloquea los ficheros mientras los sube y puede dejar la instalación o una actualización a medias, y por la red el editor va más lento y falla si se corta la conexión. El instalador avisa; si aun así quieres, pulsa Siguiente otra vez. Tus proyectos sí pueden estar en la nube o en git. En un CD o DVD no se puede instalar.
  • Antivirus y «Acceso controlado a carpetas». Como el instalador todavía no está firmado, algunos antivirus y la protección contra ransomware de Windows (Seguridad de Windows > Protección antivirus y contra amenazas > Administrar la protección contra ransomware > Acceso controlado a carpetas) pueden no dejarle escribir aunque la carpeta sea tuya: el error dice «Acceso denegado» y Windows avisa de que ha bloqueado un cambio no autorizado. Usa la carpeta recomendada, o permite NovaEngine-Setup-<versión>.exe en Permitir una aplicación a través del Acceso controlado a carpetas (o en tu antivirus) y vuelve a instalar.
  • El registro. Todo queda en %TEMP%\NovaEngine-Setup.log (o en el fichero de /log=): el instalador que se ejecutó, la carpeta y si ya existía, el tipo de unidad, su sistema de archivos y su etiqueta, el espacio libre, la prueba de escritura y cada error con su ruta y su código de Windows. Si pides ayuda, adjúntalo.

Nova Hub#

Nova Hub es la puerta de entrada del motor: desde él se crean y se abren los proyectos, se entra en las sesiones de tus equipos, se lee la documentación y se actualiza el motor. Tiene cuatro páginas a la izquierda.

Proyectos#

La lista de proyectos recientes muestra el nombre, la carpeta, la versión del motor con la que se guardó cada uno (motorVersion de project.nova), cuándo se abrió por última vez y su miniatura (miniatura.png del proyecto, si existe). Un proyecto que ya no está en su carpeta aparece en rojo.

Acción Cómo
Abrir en el editor Doble clic, el botón Abrir o el menú del botón derecho
Mostrar en el Explorador Botón derecho
Quitar de la lista Botón derecho. No borra nada: solo lo quita de la lista
Abrir proyecto Elige la carpeta que contiene project.nova
Buscar El cuadro de búsqueda filtra por nombre y carpeta

Si un proyecto se guardó con una versión del motor más nueva que la instalada, Nova Hub avisa antes de abrirlo (puede que no se abra bien): lo mejor es actualizar el motor.

La primera vez, Nova Hub importa los proyectos recientes del editor. Sus ajustes y la lista se guardan en %APPDATA%\NovaEngine\hub.json.

Equipos#

Los equipos fijos de la edición en equipo: una tarjeta por equipo con su estado, en verde En marcha · Marta · 2 personas cuando su dueña tiene la sesión abierta, o Cerrado. Unirse o doble clic abre Nova Editor ya unido (sin escribir el código, con tu nombre y tu carpeta de trabajo de siempre). Unirse a un equipo... guarda un equipo con su invitación (NOVA-EQUIPO-..., se pega una sola vez). Botón derecho: Abrir sesión, Copiar invitación del equipo y Renovar invitación... (en los tuyos) y Quitar.... Si tienes equipos, también salen arriba en Proyectos, y cuando uno abre la sesión con Nova Hub abierto aparece un aviso con Unirse. Cómo se crean y cómo funciona: edicion-en-equipo.md.

Nuevo proyecto#

Nuevo proyecto pide una plantilla, un nombre y una carpeta (por defecto Documentos\Nova Projects). La plantilla elegida al abrirlo es Vacío (Lua). Las de Lua van primero; las de C++ están debajo, en Avanzado: scripts en C++:

Plantilla Contenido
Vacío (Lua) Sol, cielo, cámara, suelo con colisionador y un cubo con el script de ejemplo GirarYFlotar.luau. Sin compilar ni Visual Studio (scripts-lua.md)
Ejemplo 3D (Lua) El proyecto de ejemplo de un jugador con sus scripts en Lua: personaje con cámara orbital, zorro animado que pasea, rotador, materiales y luces
Inventario tipo Rust (Lua) Inventario multijugador como el de Rust (cinturón, mochila, ropa, caja de botín, arrastrar y soltar, tirar y coger) con el servidor al mando (ejemplo-inventario.md)
Mundo abierto (Lua) Una isla generada con el generador de terrenos (montañas, playas y mar) bajo un cielo con pocas nubes, un bosque que se reparte solo con la API Terrain, cámara libre y un clic para excavar (terreno.md)
Vacío (C++, avanzado) Como «Vacío (Lua)», con el script de ejemplo en C++: para compilarlo hace falta Visual Studio (scripts-cpp.md)
Ejemplo 3D (C++, avanzado) El ejemplo 3D con sus scripts en C++ (viene compilado)
Multijugador (C++, avanzado) La arena en red con sus scripts en C++: menú, anfitrión, clientes, servidor dedicado, predicción, físicas en red y RPCs (viene compilado)

Un proyecto de Lua queda así (con «Mi Juego» como nombre):

Documentos\Nova Projects\Mi Juego\
  project.nova          ajustes del proyecto (nombre, motorVersion, escena inicial, controles, red...)
  assets\               escenas, modelos, materiales...
  scripts\*.luau        los scripts del juego (no se compilan: se recargan al guardarlos)

No tiene DLL, CMakeLists.txt ni módulo de scripts: sus scripts\*.luau los carga el motor. Al crear un script en el editor, o al abrirlo con VS Code, se crean además nova.d.luau, nova.docs.json, .luaurc y .vscode\settings.json, para el autocompletado en VS Code (scripts-lua.md).

Un proyecto de C++ (avanzado) tiene además:

  scripts\*.cpp         el código C++ del juego
  CMakeLists.txt        compila scripts\ con el SDK del motor (no hace falta tocarlo)
  bin\mi_juego.dll      la DLL de scripts (ya compilada en las plantillas)
  build\                carpeta de compilación de CMake (se crea al compilar)
  .gitignore            build\ y bin\ (por si usas git)

Su módulo de scripts (el nombre de la DLL, en project.nova) sale del nombre del proyecto: minúsculas, sin tildes y con _. Las plantillas de C++ traen la DLL compilada con el motor instalado, así que el proyecto se abre y se juega sin compilar; para cambiar sus scripts hace falta el compilador. Si no lo tienes, Nova Hub lo avisa al elegir una plantilla de C++.

Aprender#

Abre esta documentación en tu navegador (está instalada en docs\, no necesita Internet): la guía de Scripts en Lua va la primera, y VS Code y Lua lleva a cómo instalar la extensión de Nova para VS Code. Crear un proyecto de ejemplo crea uno con la plantilla Ejemplo 3D (Lua), y Ejemplo en C++ (avanzado), con la de C++. Si no marcaste el componente «Documentación», vuelve a ejecutar el instalador para añadirla.

Ajustes#

  • Motor: versión, carpeta de instalación y editor; carpeta de proyectos por defecto.
  • Actualizaciones: canal (estable o beta), buscar al abrir Nova Hub y Buscar actualizaciones ahora.
  • Compilador de C++ (opcional, solo para scripts C++): si se encuentran Visual Studio 2022 o sus Build Tools (con CMake y Ninja) y, si no, qué instalar y el enlace de descarga. Los scripts en Lua no lo necesitan.
  • Equipos (los dos desactivados por defecto): Avisarme con una notificación de Windows cuando un equipo abra su sesión y Abrir Nova Hub al iniciar Windows, minimizado en la bandeja (junto al reloj: doble clic en su icono lo abre; cerrar la ventana lo devuelve a la bandeja y Salir, en el menú del icono, lo cierra). Se guarda en HKCU\Software\Microsoft\Windows\CurrentVersion\Run (valor NovaHub); desinstalar Nova Engine lo quita.
  • Steamworks: si el motor se compiló con el SDK de Steamworks (ver steam.md). El motor que se distribuye se compila sin él: los juegos funcionan por la red local o por IP, pero sin Steam.

VS Code y Lua#

El motor trae una extensión para VS Code (tools\nova-engine-<versión>.vsix, con la misma versión que el motor): la API en español al escribir y al pasar el ratón, los atributos (--[Server]...) resaltados y comprobados, fragmentos, órdenes y los errores de los scripts en el panel Problemas. Se instala desde el editor: Editar > Preferencias del editor > Extensión de Nova para VS Code > Instalar la extensión de Nova en VS Code (VS Code descarga con ella luau-lsp, que entiende el Luau de los scripts; la primera vez hace falta Internet). Al actualizar el motor, el .vsix nuevo se instala con el mismo botón. Todo lo demás, y qué hacer si VS Code marca errores que no lo son porque tienes otras extensiones de Lua (como Lua, de sumneko), en scripts-lua.md.

Compilar los scripts (Visual Studio o Build Tools)#

Solo para los scripts en C++ (opcionales: scripts-cpp.md). Los scripts en Lua no se compilan y no necesitan nada de esto. Los de C++ se compilan en una DLL, y el motor no incluye el compilador: hace falta el de Microsoft, que es gratis.

  1. Descarga Build Tools para Visual Studio 2022 de la página oficial: https://visualstudio.microsoft.com/visual-cpp-build-tools/ (también vale Visual Studio Community 2022).
  2. En el instalador de Visual Studio marca la carga de trabajo «Desarrollo para el escritorio con C++». Trae el compilador MSVC, el SDK de Windows y las herramientas de CMake (CMake y Ninja).
  3. Pulsa Instalar. No hace falta reiniciar el editor.

Nova Engine necesita MSVC 14.44 o posterior (Visual Studio 2022 versión 17.14): las librerías del SDK se compilan con él y un compilador más antiguo no puede enlazarlas. Si tienes una versión anterior, actualízala desde el Visual Studio Installer.

En el editor, Compilar scripts (Ctrl+B; solo aparece en los proyectos con scripts C++) ejecuta bin\NovaBuild.exe, que:

  1. busca Visual Studio con vswhere y prepara su entorno (vcvars64.bat);
  2. configura el proyecto con el CMake y el Ninja de Visual Studio en <proyecto>\build (find_package(NovaEngine) con el SDK instalado);
  3. compila scripts\*.cpp en <proyecto>\bin\<módulo>.dll.

La salida aparece en la Consola del editor y, al terminar, el editor recarga los scripts sin cerrarse (la recarga en caliente de scripts-cpp.md). Si falta el compilador, el editor muestra qué instalar.

También se puede compilar desde una terminal:

Símbolo del sistema
"%LOCALAPPDATA%\Programs\NovaEngine\bin\NovaBuild.exe" --project "C:\Users\Ana\Documents\Nova Projects\Mi Juego"
"%LOCALAPPDATA%\Programs\NovaEngine\bin\NovaBuild.exe" --comprobar

--comprobar solo dice si encuentra Visual Studio, CMake y Ninja.

La DLL de scripts y la versión del motor#

La DLL de scripts y los programas del motor intercambian objetos de C++ (std::string, componentes...), así que tienen que compilarse igual:

  • con el mismo motor (la misma versión);
  • con MSVC (conjunto de herramientas v14x, 14.44 o posterior), en 64 bits;
  • con el runtime de C++ en DLL de la versión optimizada (/MD) y sin el STL de depuración.

nova_add_game (en cmake\NovaEngineConfig.cmake) lo fija aunque el proyecto se configure en Debug. Al cargar la DLL, el editor y NovaGame.exe comprueban su firma (versión del motor, compilador y runtime): si no coincide, la rechazan con el mensaje «se compiló para otro motor... vuelve a compilar los scripts». Por eso, después de actualizar el motor hay que compilar los scripts de cada proyecto con C++ (Ctrl+B); los datos de los scripts no se pierden. Los proyectos solo con Lua no tienen que hacer nada.

Para depurar los scripts con Visual Studio, compila el proyecto en Debug en otra carpeta (cmake -S . -B build-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug -DNovaEngine_DIR=<motor>\cmake) y adjunta el depurador a NovaEditor.exe (Depurar > Asociar al proceso).

Rutas largas#

CMake y el compilador de Microsoft no admiten rutas de más de 260 caracteres, y al configurar un proyecto CMake crea carpetas de unos 110 caracteres dentro de build\. Si Compilar scripts falla con «No se puede abrir el archivo generado por el compilador», mueve el proyecto a una carpeta con una ruta más corta (por ejemplo C:\Juegos\MiJuego). Las tildes y los espacios en la ruta no son un problema.

Actualizaciones#

Nova Hub busca actualizaciones en segundo plano al abrirse (en las versiones publicadas del motor en GitHub Releases). Si hay una versión más nueva, muestra un aviso arriba con su número y sus novedades:

  • Actualizar primero mira si hay programas del motor abiertos (Nova Editor, un juego o un servidor lanzados desde la carpeta del motor, otra ventana de Nova Hub): el instalador no podría cambiar sus ficheros. Si los hay, no se descarga nada y Nova Hub lo dice, por ejemplo «Cierra Nova Editor (guarda tus cambios) para actualizar.»: nunca los cierra por ti. Ciérralos tú y pulsa Reintentar.
  • Después descarga el instalador nuevo a %TEMP%\NovaEngine\actualizacion y comprueba su suma SHA-256 con la publicada (si no coincide, no se instala). Si ese instalador ya estaba descargado y su suma es buena, se usa sin volver a descargarlo; si está en uso (un instalador que sigue abierto), el nuevo se descarga con otro nombre (NovaEngine-Setup-<versión>-2.exe). Al terminar bien, se borran los instaladores viejos de esa carpeta.
  • Nova Hub ejecuta el instalador con /update /S /resultado=<fichero> y se cierra. El instalador:
    1. espera a que se cierren Nova Hub y los programas del motor (hasta un minuto);
    2. comprueba la carpeta, extrae la versión nueva en <motor>\_actualizacion_nova y cambia los ficheros uno a uno, guardando los anteriores;
    3. si algo falla, deshace todo y la versión anterior queda como estaba;
    4. vuelve a abrir Nova Hub, que muestra «Nova Engine se ha actualizado a la versión...». Si no ha podido actualizar (por ejemplo, porque Nova Editor seguía abierto), deja el motivo en ese fichero y Nova Hub, al abrirse otra vez, lo muestra arriba («No se pudo actualizar a Nova Engine...», con el motivo y los programas que seguían abiertos) junto a Reintentar.
  • Ver novedades muestra las notas de la versión.
  • Omitir esta versión no vuelve a avisar de esa versión (sí de las siguientes).
  • Más tarde oculta el aviso hasta la próxima vez.

Desde el editor, Ayuda > Buscar actualizaciones… abre Nova Hub en sus ajustes y busca en ese momento.

En Ajustes > Actualizaciones se elige el canal:

Canal Qué recibe
Estable Solo las versiones normales
Beta También las versiones de prueba (por ejemplo 0.3.0-beta.1), antes que nadie y con más riesgo

Sin conexión, o si el repositorio de versiones todavía no existe, Nova Hub lo dice en sus ajustes y sigue funcionando con normalidad. También puedes actualizar a mano: ejecuta el instalador nuevo y elige la misma carpeta. Tus proyectos nunca se tocan al actualizar; lo único que hay que hacer después es compilar los scripts de los proyectos con C++ (los de Lua no necesitan nada).

Desinstalar#

Cualquiera de estas formas:

  • Configuración > Aplicaciones > Aplicaciones instaladas > Nova Engine > Desinstalar;
  • Inicio > Nova Engine > Desinstalar Nova Engine;
  • Desinstalar.exe en la carpeta del motor (/S para hacerlo sin ventanas).

El desinstalador borra solo lo que instaló el instalador (la lista de nova-instalacion.txt), los accesos directos, la entrada de Aplicaciones instaladas y la asociación de .nova. Nunca toca tus proyectos, estén donde estén, ni nada que tú hayas guardado dentro de la carpeta del motor (en ese caso la carpeta se queda con lo tuyo). Como no se puede borrar a sí mismo mientras se ejecuta, se copia a %TEMP%, sigue desde allí y esa copia se borra sola al terminar.

Se quedan, por si vuelves a instalar el motor: los ajustes de Nova Hub (%APPDATA%\NovaEngine\hub.json) y los del editor y sus registros (%LOCALAPPDATA%\NovaEngine). Puedes borrar esas carpetas a mano.

Solución de problemas#

Problema Causa y solución
«Windows protegió su PC» El instalador no está firmado: Más información > Ejecutar de todas formas (ver SmartScreen)
«Este instalador está incompleto o dañado» Descarga cortada o modificada: vuelve a descargarlo y compara su SHA-256
«No se puede escribir en...», «No se puede crear la carpeta...» o «No hay espacio suficiente...» al instalar La carpeta elegida no vale: el mensaje dice la ruta y el motivo. Usa la carpeta recomendada; ver Problemas al instalar
«Cierra estos programas antes de continuar» El editor, Nova Hub o un juego se están ejecutando desde la carpeta del motor: ciérralos
«Falta el compilador de C++» al compilar Solo afecta a los scripts C++: instala las Build Tools de Visual Studio 2022 (Compilar los scripts) o usa Lua, que no se compila
«MSVC 14.44 o posterior» Actualiza Visual Studio 2022 a la 17.14 o posterior desde el Visual Studio Installer
«se compiló para otro motor» en la consola La DLL de scripts es de otra versión del motor: Compilar scripts (Ctrl+B)
«No se puede abrir el archivo generado por el compilador» Ruta demasiado larga: ver Rutas largas
«Cierra Nova Editor (guarda tus cambios) para actualizar» Hay programas del motor abiertos: guarda, ciérralos y pulsa Reintentar
«No se pudo actualizar a Nova Engine...» al abrir Nova Hub El instalador no pudo actualizar y dice por qué (por ejemplo, un programa del motor seguía abierto). No se ha cambiado nada: cierra lo que diga y pulsa Reintentar (no se vuelve a descargar)
La actualización falla No se ha cambiado nada (se deshace sola). Mira %TEMP%\NovaEngine-Setup.log, cierra el editor y vuelve a intentarlo
Nova Hub no encuentra actualizaciones Mira el mensaje de Ajustes > Actualizaciones (sin conexión, límite de consultas de GitHub o repositorio sin versiones)
