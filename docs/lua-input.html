Input

Teclado, ratón y mando. Mejor por acciones y ejes del proyecto (Ajustes del proyecto > Entrada): así teclado y mando funcionan a la vez y el jugador puede cambiar las teclas.

GetAxis función

Input.GetAxis(axis: string): number
Valor de un eje del proyecto, de −1 a 1: Input.GetAxis("MoverX").

IsActionDown función

Input.IsActionDown(action: string): boolean
true mientras la acción está pulsada: Input.IsActionDown("Correr").

WasActionPressed función

Input.WasActionPressed(action: string): boolean
true solo en el frame en que se pulsa la acción: Input.WasActionPressed("Saltar").

WasActionReleased función

Input.WasActionReleased(action: string): boolean
true solo en el frame en que se suelta la acción.

IsKeyDown función

Input.IsKeyDown(key: string): boolean
true mientras la tecla está pulsada. Nombres: "A"…"Z", "0"…"9", "F1", "Space", "Enter", "Esc", "Tab", "LeftShift", "LeftCtrl", "LeftAlt", "Up", "Down", "Left", "Right"...

WasKeyPressed función

Input.WasKeyPressed(key: string): boolean
true solo en el frame en que se pulsa la tecla: Input.WasKeyPressed("Space").

AnyKeyPressed función

Input.AnyKeyPressed(): (boolean, string?)
true (y su nombre) si en este frame se pulsó cualquier tecla, botón del ratón o botón del mando ("Gamepad:A"): «pulsa cualquier tecla».

WasAnyKeyPressed función

Input.WasAnyKeyPressed(): (boolean, string?)
Lo mismo que Input.AnyKeyPressed.

GetKeyNames función

Input.GetKeyNames(): {string}
Lista con los nombres de todas las teclas (los que aceptan IsKeyDown y WasKeyPressed).

SimulateKey función

Input.SimulateKey(key: string, down: boolean?): ()
Pruebas: simula una tecla en el frame siguiente, como si se pulsara de verdad (IsKeyDown, WasKeyPressed, acciones y la interfaz la ven). Sin pulsada, una pulsación completa (baja y, un frame después, sube). Solo con NovaGame --entrada-simulada (y en las pruebas del motor); si no, da un error.

SimulateMouseMove función

Input.SimulateMouseMove(viewPosition: Vec2): ()
Pruebas: lleva el puntero a esa posición en píxeles de la vista (la de Input.MouseViewPosition) en el frame siguiente: la interfaz lo ve (encima, arrastrar). Solo con --entrada-simulada.

SimulateMouseButton función

Input.SimulateMouseButton(button: (string | number)?, down: boolean?): ()
Pruebas: botón del ratón ("MouseLeft" por defecto) en el frame siguiente; sin pulsado, un clic (baja y sube un frame después). Con true y después false (en otro frame), arrastrar y soltar de verdad. Solo con --entrada-simulada.

SimulateWheel función

Input.SimulateWheel(notches: number): ()
Pruebas: muescas de la rueda del ratón en el frame siguiente. Solo con --entrada-simulada.

SimulateText función

Input.SimulateText(text: string): ()
Pruebas: texto tecleado (campos de texto) en el frame siguiente. Solo con --entrada-simulada.

IsSimulationAllowed función

Input.IsSimulationAllowed(): boolean
true si la entrada simulada está activa (NovaGame --entrada-simulada o las pruebas del motor).

WasKeyReleased función

Input.WasKeyReleased(key: string): boolean
true solo en el frame en que se suelta la tecla.

IsMouseDown función

Input.IsMouseDown(button: string | number): boolean
true mientras el botón del ratón está pulsado: "MouseLeft", "MouseRight", "MouseMiddle" (o 0, 1, 2).

WasMousePressed función

Input.WasMousePressed(button: string | number): boolean
true solo en el frame en que se pulsa el botón del ratón ("MouseLeft", "MouseRight", "MouseMiddle").

WasMouseReleased función

Input.WasMouseReleased(button: string | number): boolean
true solo en el frame en que se suelta el botón del ratón.

MousePosition función

Input.MousePosition(): Vec2
El ratón en píxeles de la ventana (Vec2). Para las coordenadas de Camera, GUI y UI: MouseViewPosition().

MouseDelta función

Input.MouseDelta(): Vec2
Lo que se ha movido el ratón en este frame (Vec2, en píxeles).

MouseWheel función

Input.MouseWheel(): number
Lo que ha girado la rueda del ratón en este frame.

IsGamepadConnected función

Input.IsGamepadConnected(pad: number?): boolean
true si hay un mando conectado (el primero, o ese número).

IsGamepadDown función

Input.IsGamepadDown(button: string, pad: number?): boolean
true mientras el botón del mando está pulsado: "A", "B", "X", "Y", "LB", "RB", "Start", "Back", "L3", "R3", "DPadUp"...

WasGamepadPressed función

Input.WasGamepadPressed(button: string, pad: number?): boolean
true solo en el frame en que se pulsa el botón del mando.

GetGamepadAxis función

Input.GetGamepadAxis(axis: string, pad: number?): number
Un eje del mando: "LeftStickX", "LeftStickY", "RightStickX", "RightStickY", "LT", "RT".

SetGamepadVibration función

Input.SetGamepadVibration(low: number, high: number, pad: number?): ()
Vibración del mando: motor grave y agudo, de 0 a 1.

SetCursorLocked función

Input.SetCursorLocked(locked: boolean): ()
Bloquea y oculta el cursor (cámaras en primera persona), o lo suelta.

IsCursorLocked función

Input.IsCursorLocked(): boolean
true si el cursor está bloqueado.

SetCursorVisible función

Input.SetCursorVisible(visible: boolean): ()
Oculta el cursor sin bloquearlo (punteros propios). Al terminar la partida vuelve a verse.

IsCursorVisible función

Input.IsCursorVisible(): boolean
true si el cursor se ve.

MouseViewPosition función

Input.MouseViewPosition(): Vec2
El ratón en píxeles de la vista del juego: las coordenadas de Camera, GUI y UI (en NovaGame.exe es lo mismo que MousePosition(), en el editor no).

GetTextInput función

Input.GetTextInput(): string
Lo tecleado en este frame (UTF-8): campos de texto propios, códigos de trucos.
