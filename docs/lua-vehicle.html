Referencia de Lua · Componente

Vehicle

Vehículo: componente (Vehículos). Coche, moto u orugas con físicas de verdad (Jolt): ruedas con suspensión, motor y caja de cambios. Necesita Colisionador y Cuerpo rígido dinámico

entidad:GetComponent("Vehicle") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

type campo

Vehicle.type: "Coche" | "Moto" | "Orugas"
Tipo (en el Inspector).

wheels campo

Vehicle.wheels: { { position: Vec3, radius: number, width: number, suspensionMin: number, suspensionMax: number, suspensionFrequency: number, suspensionDamping: number, grip: number, sideGrip: number, steerAngle: number, driven: boolean, brakeTorque: number, handBrake: boolean, track: "Automática" | "Izquierda" | "Derecha", visual: Entity?, } }
Ruedas (en el Inspector). Vacío = cuatro ruedas en las esquinas de la caja del colisionador Es una copia: para cambiarla, asigna la lista entera.

maxTorque campo

Vehicle.maxTorque: number
Par máximo (en el Inspector). N·m De 0 a 1e+05.

minRpm campo

Vehicle.minRpm: number
RPM mínimas (en el Inspector). De 100 a 30000.

maxRpm campo

Vehicle.maxRpm: number
RPM máximas (en el Inspector). De 200 a 30000.

torqueCurve campo

Vehicle.torqueCurve: { Vec2 }
Curva de par (en el Inspector). Puntos (fracción de las rpm entre la mínima y la máxima, fracción del par máximo). Vacía = 80 % abajo, 100 % a dos tercios y 80 % arriba Es una copia: para cambiarla, asigna la lista entera.

automatic campo

Vehicle.automatic: boolean
Automático (en el Inspector). Cambia de marcha solo según las rpm

gears campo

Vehicle.gears: { number }
Marchas (en el Inspector). Relación de cada marcha hacia delante (primera, segunda...) Es una copia: para cambiarla, asigna la lista entera.

reverseGear campo

Vehicle.reverseGear: number
Marcha atrás (en el Inspector). De -20 a -0.01.

shiftUpRpm campo

Vehicle.shiftUpRpm: number
Subir de marcha a (en el Inspector). rpm De 100 a 30000.

shiftDownRpm campo

Vehicle.shiftDownRpm: number
Bajar de marcha a (en el Inspector). rpm De 100 a 30000.

differentialRatio campo

Vehicle.differentialRatio: number
Diferencial (en el Inspector). Relación entre la caja y las ruedas De 0.1 a 50.

centerOfMass campo

Vehicle.centerOfMass: Vec3
Centro de masas (en el Inspector). Desplazamiento del centro de masas (local). Bajo (y negativo) = estable en las curvas

maxTilt campo

Vehicle.maxTilt: number
Inclinación máxima (en el Inspector). Grados. Menos de 180: no puede volcar del todo De 1 a 180.

antiRoll campo

Vehicle.antiRoll: number
Barras estabilizadoras (en el Inspector). N/m (0 = sin barras): se inclina menos en las curvas De 0 a 1e+05.

maxLean campo

Vehicle.maxLean: number
Inclinación de la moto (en el Inspector). Grados que se inclina en las curvas De 0 a 80.

wheelCast campo

Vehicle.wheelCast: "Cilindro" | "Esfera" | "Rayo"
Contacto de las ruedas (en el Inspector). Cómo tocan el suelo. Esfera (de serie): sube bordillos y no se frena en los cantos verticales (bordes de las carreteras). Cilindro: la forma exacta de la rueda, pero un canto vertical la para como una pared. Rayo: lo más barato

defaultControls campo

Vehicle.defaultControls: boolean
Controles de serie (en el Inspector). W/S o gatillos: acelerar y frenar; A/D o stick: girar; Espacio o A: freno de mano. Desmárcalo para manejarlo solo desde un script (vehiculo:SetInput)

steerSpeed campo

Vehicle.steerSpeed: number
Velocidad del volante (en el Inspector). Controles de serie: 1/s hasta el tope De 0.1 a 50.

soundPitchIdle campo

Vehicle.soundPitchIdle: number
Tono al ralentí (en el Inspector). Con un Fuente de audio en bucle en el vehículo, su tono sigue a las rpm De 0.05 a 4.

soundPitchMax campo

Vehicle.soundPitchMax: number
Tono a tope (en el Inspector). De 0.05 a 4.

inThrottle campo

Vehicle.inThrottle: number
In Throttle (en el Inspector).

inSteer campo

Vehicle.inSteer: number
In Steer (en el Inspector).

inBrake campo

Vehicle.inBrake: number
In Brake (en el Inspector).

inHandBrake campo

Vehicle.inHandBrake: number
In Hand Brake (en el Inspector).

scriptInputStep campo

Vehicle.scriptInputStep: string
Script Input Step (en el Inspector).

rpm campo

Vehicle.rpm: number
RPM (en el Inspector). De 0 a 30000.

gear campo

Vehicle.gear: number
Marcha (en el Inspector). De -1 a 30.

speed campo

Vehicle.speed: number
Velocidad (en el Inspector). m/s hacia delante De -200 a 200.

steering campo

Vehicle.steering: number
Steering (en el Inspector). De -1 a 1.

throttle campo

Vehicle.throttle: number
Throttle (en el Inspector). De -1 a 1.

onGround campo

Vehicle.onGround: boolean
En el suelo (en el Inspector).

netSeq campo

Vehicle.netSeq: number
Net Seq (en el Inspector).

netPos campo

Vehicle.netPos: Vec3
Net Pos (en el Inspector).

netRot campo

Vehicle.netRot: Quat
Net Rot (en el Inspector).

netVel campo

Vehicle.netVel: Vec3
Net Vel (en el Inspector).

netAngVel campo

Vehicle.netAngVel: Vec3
Net Ang Vel (en el Inspector).

entity campo

Vehicle.entity: Entity
La entidad que tiene este componente.

SetInput método

Vehicle:SetInput(input: VehicleInput): (): ()
Pone la entrada del vehículo: { throttle = 1, steer = -0.5, brake = 0, handbrake = false }. Gana a los controles de serie durante un cuarto de segundo: llámalo en cada Update o FixedUpdate. En la máquina del conductor se envía al servidor; en el servidor sirve para conducir con IA un vehículo sin conductor.

GetSpeed método

Vehicle:GetSpeed(): number
Velocidad hacia delante en m/s (negativa hacia atrás).

GetSpeedKmh método

Vehicle:GetSpeedKmh(): number
Velocidad hacia delante en km/h.

GetRPM método

Vehicle:GetRPM(): number
Revoluciones del motor.

GetGear método

Vehicle:GetGear(): number
Marcha: -1 marcha atrás, 0 punto muerto, 1 primera...

IsOnGround método

Vehicle:IsOnGround(): boolean
true si alguna rueda toca el suelo.

GetWheel método

Vehicle:GetWheel(index: number): VehicleWheelState?
Estado de una rueda (desde 1): posición y giro en el mundo, suspensión, dirección, contacto, lo que pisa (ground) y cuánto derrapa (slip). nil si no existe.
