Con el chat de voz los jugadores de una partida en red se oyen hablar: la voz sale del personaje de cada uno (más baja cuanto más lejos, a la izquierda o a la derecha según dónde esté y, si quieres, apagada detrás de las paredes) y, además, puedes meter a varios jugadores en un canal para que se oigan sin distancia, como en una llamada de teléfono, un intercomunicador o una radio, con su efecto de sonido.

Todo se maneja desde Lua con el global Voice y dos eventos. El motor se encarga de lo difícil: el micrófono, quitar el ruido grave y ajustar el volumen, decidir cuándo estás hablando, comprimir la voz (Opus, unos 24 kbit/s), enviarla por la red del juego (por IP, Steam o Nova Enlace con código), que el servidor solo se la mande a quien la oye, y reproducirla en 3D aunque la red pierda o desordene paquetes.

1. Tu chat de voz en cinco minutos#

La voz solo funciona en partidas en red (anfitrión, cliente o servidor dedicado). Las voces de los demás se oyen siempre; lo que hay que encender es tu micrófono, normalmente desde el menú de opciones del juego. Un script [Global] (existe en todas las máquinas) basta para empezar:

Lua
--[Global]
local ChatDeVoz = Script()

ChatDeVoz.hablando = "" --[NoSave]

function ChatDeVoz:Awake()
    -- Mi micrófono: encendido y abierto (se envía solo cuando hablo)
    Voice.SetEnabled(true)
    Voice.SetPushToTalk(false)

    -- Lo decide el servidor y lo manda a los clientes
    if IsServer() then
        Voice.SetProximity({ min = 2, max = 18, occlusion = true })
    end

    -- Quién habla (para un icono encima de su cabeza o en la lista de jugadores)
    AddEventHandler("OnVoiceStart", function(jugador)
        self.hablando = "Habla el jugador " .. tostring(jugador)
    end)
    AddEventHandler("OnVoiceStop", function(jugador)
        self.hablando = ""
    end)
end

return ChatDeVoz

Juega con dos ventanas (o dos PCs) y habla: el otro te oye salir de tu personaje. Si os alejáis más de 18 metros dejáis de oíros.

La voz sale del personaje del jugador: el que da GetOwner(jugador), la entidad con NetworkIdentity que el PlayerSpawner crea para él (o, si el juego crea los personajes a mano, una entidad suya con «Controlador de personaje»).

2. Opciones del jugador#

Todo esto es de tu máquina y vale también para las escenas siguientes (al cambiar de mapa no se pierde). Guárdalo con PlayerPrefs si quieres que se recuerde entre partidas.

Opción Función Por defecto
Micrófono encendido Voice.SetEnabled(on) / Voice.IsEnabled() apagado
Modo Voice.SetPushToTalk(on, accion?): false = micrófono abierto, true = pulsar para hablar abierto
Tecla para hablar la acción de Entrada "HablarVoz" (o la que pases); si el proyecto no la tiene, la tecla V V
Micrófono Voice.GetInputDevices() (lista de nombres) y Voice.SetInputDevice(nombre); nil = el de Windows el de Windows
Volumen del micrófono Voice.SetInputVolume(0..2) 1
Volumen de los demás Voice.SetOutputVolume(0..2) (además del bus "Voice" de Audio.SetBusVolume) 1
Sensibilidad (micro abierto) Voice.SetThreshold(0..1): más alto, hace falta hablar más fuerte 0.5

Con el micrófono abierto, el motor decide que estás hablando cuando tu voz pasa el umbral y está claramente por encima del ruido de fondo; sigue enviando 300 ms después de la última sílaba para no cortar las palabras, y manda también los 20 ms de antes para no comerse el principio.

Para la típica prueba de micrófono de las opciones, Voice.GetLevel() (sin argumentos) da el nivel de tu micrófono de 0 a 1 aunque no estés enviando nada: úsalo para mover una barra mientras el jugador ajusta la sensibilidad.

Lua
local OpcionesVoz = Script()

OpcionesVoz.nivel = 0 --[NoSave]

function OpcionesVoz:Start()
    local micros = Voice.GetInputDevices()
    if #micros > 0 then
        print("Micrófonos: " .. table.concat(micros, ", "))
    end
    Voice.SetPushToTalk(PlayerPrefs.Get("vozPulsar", false))
    Voice.SetThreshold(PlayerPrefs.Get("vozSensibilidad", 0.5))
end

function OpcionesVoz:Update(dt)
    self.nivel = Voice.GetLevel() -- la barra de la prueba de micrófono
end

function OpcionesVoz:CambiarModo(pulsar: boolean)
    Voice.SetPushToTalk(pulsar)
    PlayerPrefs.Set("vozPulsar", pulsar)
end

return OpcionesVoz

3. Voz de proximidad#

Lua
Voice.SetProximity({ min = 2, max = 18, occlusion = true })
  • Hasta min metros se oye entera; desde ahí baja en línea recta hasta max, donde ya no se oye.
  • Más allá de max el servidor ni siquiera envía la voz (ahorra ancho de banda).
  • El panorama (izquierda y derecha) y la distancia se miden desde el oyente del audio: el componente «Oyente de audio» o la cámara principal, como el resto de sonidos 3D (ver audio.md).
  • Con occlusion = true, si un rayo de físicas del oyente al que habla choca con algo (una pared, una puerta), la voz se oye a la mitad y apagada (paso bajo). Sin oclusión, solo cuenta la distancia.

Llámalo en el servidor (o en un script que corre en todos): el servidor manda sus valores a los clientes cada pocos segundos, así que manda él.

4. Canales: llamadas, intercomunicadores y radios#

Un canal es un grupo de jugadores que se oyen entre ellos sin distancia, estén donde estén. Lo maneja el servidor:

Lua
Voice.SetChannel(jugador, "llamada1")              -- dentro
Voice.SetChannel(jugador, nil)                     -- fuera
Voice.SetChannel(jugador, "radio", { mix = true }) -- en el canal y también en la proximidad
Voice.SetEffect("llamada1", "phone")            -- efecto de lo que se oye por ese canal
Voice.SetEffect(jugador, "radio")                  -- efecto de todo lo que dice ese jugador
  • Mientras un jugador está en un canal no oye ni se le oye por proximidad (como quien está al teléfono en otra habitación). Con { mix = true } sigue en las dos cosas: los de su canal le oyen sin distancia y los que tiene cerca, por proximidad.
  • Los efectos son "phone" (teléfono: 300-3400 Hz, poca distorsión), "intercom" (intercomunicador: más estrecho y más saturado) y "radio" (estrecho, saturado, con ruido y un chasquido al soltar) y "tv" (una tele vieja: 220-4200 Hz, algo saturada y con ruido). Todos añaden paso banda, saturación y algo de ruido. El efecto de un jugador tiene prioridad sobre el del canal. Los sonidos del juego tienen el mismo altavoz pequeño (effect de la Fuente de audio, audio.md).
  • SetChannel y SetEffect solo funcionan en el servidor (en un cliente dan un error claro). Los canales se borran al cambiar de escena.

Ejemplo: llamar a otro jugador por teléfono y colgar.

Lua
--[Global]
local TelefonoVoz = Script()

local llamadas = {} -- canal -> { quien llama, a quien llama } (solo en el servidor)

function TelefonoVoz:Awake()
    if not IsServer() then return end
    RegisterNetEvent("telefono:llamar", function(destino)
        local canal = "llamada" .. tostring(source)
        llamadas[canal] = { source, destino }
        Voice.SetChannel(source, canal)
        Voice.SetChannel(destino, canal)
        Voice.SetEffect(canal, "phone")
    end)
    RegisterNetEvent("telefono:colgar", function()
        local canal = Voice.GetChannel(source)
        local llamada = canal and llamadas[canal]
        if not llamada then return end
        for _, jugador in ipairs(llamada) do
            Voice.SetChannel(jugador, nil)
        end
        llamadas[canal] = nil
    end)
end

-- Desde la interfaz del cliente: TriggerServerEvent("telefono:llamar", 3) y TriggerServerEvent("telefono:colgar")

return TelefonoVoz

5. Silenciar y volumen de cada jugador#

Lua
Voice.Mute(jugador)            -- ya no le oyes (Voice.Mute(jugador, false) para volver a oírle)
Voice.SetVolume(jugador, 0.5)  -- más bajo (0 a 2)

Solo afecta a tu máquina. Al silenciar a alguien, tu cliente se lo dice al servidor y este deja de mandarte su voz.

6. Quién está hablando: eventos e indicadores#

  • AddEventHandler("OnVoiceStart", function(jugador) ... end) y "OnVoiceStop": en cada cliente, cuando un jugador empieza o deja de hablar (también tú mismo, cuando empiezas o dejas de enviar).
  • Voice.IsSpeaking(jugador): si habla ahora. Voice.IsSpeaking() sin argumento: si tú estás enviando.
  • Voice.GetLevel(jugador): el nivel de su voz de 0 a 1 (sube al momento y baja despacio), para un icono que se mueve al hablar.

En un servidor dedicado no hay eventos (no oye a nadie).

Con la sala y el chat integrados (lobby-y-escenas.md), el nombre de quien habla sale solo arriba a la izquierda y en talking de Lobby.GetPlayers(), sin escribir nada.

7. Cómo viaja la voz por la red#

  1. Tu micrófono se lee a 48 kHz en mono. Se le quita el zumbido grave (paso alto), se aplica tu volumen, el control automático de ganancia lleva tu voz a un nivel parecido al de los demás y un limitador evita que sature.
  2. Cada 20 ms de voz se comprime con Opus (unos 50-70 bytes) con FEC: cada paquete lleva también una copia barata del anterior, así que si se pierde uno suelto se recupera del siguiente.
  3. El paquete va al servidor por el canal no fiable de la red del motor (mejor perder un trozo que llegar tarde). Funciona igual por IP directa, por Steam y por Nova Enlace con código.
  4. El servidor lo reenvía solo a quien lo oye: los del mismo canal y los que están dentro del alcance de la proximidad, sin los que le han silenciado. Cada jugador tiene además un límite de voz que puede recibir (24 KB/s, unas siete voces a la vez); si se pasa, lo que sobra se descarta.
  5. Quien escucha guarda los paquetes de cada hablante en un búfer de jitter que los ordena y espera lo justo (de 40 a 160 ms según lo irregular que llegue la red). Si falta un trozo, lo reconstruye con el FEC o lo inventa (PLC) para que no se oiga un corte.
  6. La voz suena en 3D en el personaje del que habla (o sin distancia si llega por un canal), con su efecto, por el bus "Voice" del audio.

El anfitrión es servidor y jugador a la vez: su voz y la que le llega no salen a la red. El servidor dedicado (NovaServer.exe) no tiene audio ni micrófono: solo reparte.

8. Ancho de banda y CPU#

Medido con las pruebas del motor (nova_tests.exe voz, compilación release):

Qué Cuánto
Voz de un jugador que habla (subida) ~20 kbit/s de voz (~2,5 KB/s; con las cabeceras de la red, ~4 KB/s)
Un jugador que oye a 7 hablando a la vez (bajada) ~150 kbit/s
Mientras nadie habla nada (no se envía el silencio)
CPU: comprimir 20 ms de voz ~0,13 ms (en el hilo del juego: un 0,7 % de un núcleo mientras hablas)
CPU: descomprimir 20 ms de una voz ~0,016 ms (en el hilo de audio: siete voces a la vez, menos del 1 % de un núcleo)

En una partida de 8 en la que hablan todos a la vez, el servidor reenvía como mucho 8 x 7 voces (~1,2 Mbit/s en total); lo normal es bastante menos porque no habla todo el mundo y la proximidad recorta.

9. Probar sin micrófono y limitaciones#

  • NovaGame.exe --mute, el editor sin ventana y las pruebas usan el audio nulo: el micrófono nunca se abre y no suena nada.
  • No hay cancelación de eco: con altavoces, los demás pueden oírse a sí mismos a través de tu micrófono. Recomienda cascos (o pulsar para hablar).
  • No hay supresión de ruido avanzada: el paso alto quita el zumbido grave y la detección de voz no envía el ruido de fondo constante, pero un ventilador fuerte o un teclado se pueden colar mientras hablas.
  • La voz es mono y en banda ancha (hasta 8 kHz), pensada para hablar, no para música.
  • Los canales y los efectos se borran al cambiar de escena: vuelve a ponerlos (por ejemplo en playerJoined o al empezar la ronda).

10. Referencia de la API de Lua#

Función Dónde Qué hace
Voice.SetEnabled(on), Voice.IsEnabled() cliente Tu micrófono encendido o apagado
Voice.SetPushToTalk(on, accion?), Voice.IsPushToTalk() cliente Pulsar para hablar (acción "HablarVoz" o la tecla V) o micrófono abierto
Voice.SetInputDevice(nombre?), Voice.GetInputDevice(), Voice.GetInputDevices() cliente Elegir el micrófono
Voice.SetInputVolume(v), Voice.GetInputVolume() cliente Volumen de tu micrófono (0 a 2)
Voice.SetOutputVolume(v), Voice.GetOutputVolume() cliente Volumen de las voces de los demás (0 a 2)
Voice.SetThreshold(t), Voice.GetThreshold() cliente Sensibilidad del micrófono abierto (0 a 1)
Voice.SetVolume(jugador, v), Voice.GetVolume(jugador) cliente Volumen de un jugador (0 a 2)
Voice.Mute(jugador, on?), Voice.IsMuted(jugador) cliente Silenciar a un jugador
Voice.IsSpeaking(jugador?), Voice.GetLevel(jugador?) cliente Si habla y su nivel (sin argumento: tú)
Voice.SetProximity({ min, max, occlusion }), Voice.GetProximity() servidor y clientes Voz de proximidad
Voice.SetChannel(jugador, canal?, { mix }?), Voice.GetChannel(jugador) servidor Canales sin distancia
Voice.SetEffect(canal o jugador, efecto?) servidor "phone", "intercom", "radio", "tv" o nil
Voice.GetStats() todos { kbpsUp, kbpsDown, framesSent, packetsReceived, forwarded, dropped, encodeMs, decodeMs }: kbit/s de subida y bajada, tramas, reenviados, descartados y CPU del códec
OnVoiceStart(jugador), OnVoiceStop(jugador) cliente Eventos (con AddEventHandler)

El texto de cada función también sale al pasar el ratón en VS Code (nova.d.luau y nova.docs.json).
