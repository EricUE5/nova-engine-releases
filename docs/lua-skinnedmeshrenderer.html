SkinnedMeshRenderer

Malla con huesos: componente (Render).

entidad:GetComponent("SkinnedMeshRenderer") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

model campo

SkinnedMeshRenderer.model: Asset?
Modelo (en el Inspector).

mesh campo

SkinnedMeshRenderer.mesh: number
Malla (en el Inspector).

skin campo

SkinnedMeshRenderer.skin: number
Piel (en el Inspector). Índice del skin (esqueleto) en el modelo

materials campo

SkinnedMeshRenderer.materials: { Asset? }
Materiales (en el Inspector). Es una copia: para cambiarla, asigna la lista entera.

castShadows campo

SkinnedMeshRenderer.castShadows: boolean
Proyecta sombras (en el Inspector).

receiveShadows campo

SkinnedMeshRenderer.receiveShadows: boolean
Recibe sombras (en el Inspector). Si se desactiva, ninguna luz le hace sombra

visible campo

SkinnedMeshRenderer.visible: boolean
Visible (en el Inspector). Desmarcado no se dibuja (la entidad y sus scripts siguen activos)

shadowOnly campo

SkinnedMeshRenderer.shadowOnly: boolean
Solo sombra (en el Inspector). Proyecta su sombra pero no se dibuja en la vista (con «Proyecta sombras»). En el Inspector es la opción «Solo sombra» de Sombras

ownerVisibility campo

SkinnedMeshRenderer.ownerVisibility: "Everyone" | "OwnerOnly" | "HiddenForOwner"
Visibilidad en red (en el Inspector). En una partida en red, según quién es el propietario (el jugador de su Identidad de red o la de un ancestro): «Solo el propietario» para los brazos en primera persona; «Oculto para el propietario» para su cuerpo, del que solo ve la sombra

lodBias campo

SkinnedMeshRenderer.lodBias: number
Sesgo de LOD (en el Inspector). Multiplica el tamaño en pantalla con el que se elige el nivel de detalle: 2 = mantiene el detalle el doble de lejos, 0,5 = pasa antes a los niveles simplificados. 1 = el del proyecto (Ajustes del proyecto > Render) De 0.1 a 10.

maxDistance campo

SkinnedMeshRenderer.maxDistance: number
Distancia máxima (en el Inspector). Metros: más lejos de la cámara (hasta el punto más cercano de la malla) no se dibuja ni proyecta sombra. Sirve para lo que tapa la niebla. 0 = sin límite De 0 a 1e+05.

fadeDistance campo

SkinnedMeshRenderer.fadeDistance: number
Desvanecido (en el Inspector). Metros antes de la distancia máxima en los que se desvanece poco a poco (0 = desaparece de golpe) De 0 a 1000.

viewLayer campo

SkinnedMeshRenderer.viewLayer: boolean
Vista en primera persona (en el Inspector). Arma y brazos en primera persona: se dibuja por delante de todo (no atraviesa paredes), con el campo de visión y el plano cercano de la «Capa de vista» de un ancestro (si no hay, 68 grados y 1 cm). Tiene que colgar de la cámara

entity campo

SkinnedMeshRenderer.entity: Entity
La entidad que tiene este componente.

SetColor método

SkinnedMeshRenderer:SetColor(color: Color, slot: (number | string)?): (): ()
Color base de su material propio. Sin submalla, todas; la primera es la 1.

GetColor método

SkinnedMeshRenderer:GetColor(slot: (number | string)?): Color
Color base (de una submalla).

SetEmissive método

SkinnedMeshRenderer:SetEmissive(color: Color, intensity: (number | string)?, slot: (number | string)?): (): ()
Brillo propio con su intensidad.

SetTexture método

SkinnedMeshRenderer:SetTexture(texture: (Asset | string)?, slot: (number | string)?): (): ()
Textura de color (Asset o ruta; nil la quita).

SetMaterial método

SkinnedMeshRenderer:SetMaterial(material: (Asset | string)?, slot: (number | string)?): (): ()
Usa un material del proyecto (compartido); nil = el del modelo.

GetMaterial método

SkinnedMeshRenderer:GetMaterial(slot: (number | string)?): Asset?
El material de una submalla.

SetMaterialValue método

SkinnedMeshRenderer:SetMaterialValue(name: string, value: any, slot: (number | string)?): (): ()
Cualquier valor del material: "metallic", "roughness", "emissiveIntensity"...

GetMaterialValue método

SkinnedMeshRenderer:GetMaterialValue(name: string, slot: (number | string)?): any
Un valor del material.

GetSlotCount método

SkinnedMeshRenderer:GetSlotCount(): number
Cuántas submallas (materiales) tiene.

GetSlotName método

SkinnedMeshRenderer:GetSlotName(slot: number): string
El nombre del material de una ranura (submalla): el del modelo o, si no tiene, el que usa ahora. Las funciones que reciben una submalla aceptan también este nombre: malla:SetEmissive(color, 4, "M_tritio").

FindSlot método

SkinnedMeshRenderer:FindSlot(name: string): number?
El número de la primera ranura con ese material (nil si no hay ninguna).

SetParam método

SkinnedMeshRenderer:SetParam(name: string, value: number | Vec2 | Vec3 | Vec4 | Color | Asset | string | nil): (): ()
Cambia un parámetro expuesto de sus materiales por nodos solo para esta entidad: un número, Vec2, Vec3, Vec4, Color o una textura.

GetParam método

SkinnedMeshRenderer:GetParam(name: string): number | Vec4 | Color | Asset | nil
El valor de un parámetro de sus materiales por nodos para esta entidad (o el del material).
