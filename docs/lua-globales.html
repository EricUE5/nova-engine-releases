Referencia de Lua · Globales

Funciones globales

Funciones y valores que están en cualquier script sin prefijo: Script(), Entity(), IsServer(), source, los eventos con nombre...

Script función

Script(): ScriptInstance & { [string]: any }
Crea la clase de un script: local Jugador = Script(). Sus campos (Jugador.vida = 100) salen en el Inspector y se guardan con la escena; sus funciones (function Jugador:Update(dt)) son el ciclo de vida y las tuyas. El fichero termina con return Jugador. Los atributos van en comentarios: --[Range(0, 100)], --[Server]...

Entity función

Entity(): Entity?
Campo con una referencia a otra entidad de la escena: Puerta.jugador = Entity(). Vale nil hasta que eliges una en el Inspector (arrastrándola desde la Jerarquía). Un campo vacío es nil, no una entidad: self.mano:IsValid() da «attempt to index nil»; compruébalo con if self.mano then ... end (o if self.mano and self.mano:IsValid() then, si la entidad elegida puede haberse destruido).

Enum función

Enum(choices: {string} | string, default: string?): string
Campo con una opción de una lista (un desplegable en el Inspector): X.modo = Enum({ "Andar", "Correr" }, "Andar"). En Lua es un texto: self.modo == "Correr". Con un nombre, el enum compartido de ese asset .enum: Enum("TipoObjeto", "Arma") (docs/datos.md).

Asset función

Asset(typeOrPath: string): Asset?
Asset("Prefab"): campo con un asset de ese tipo ("Prefab", "Audio", "Material", "Model", "Texture", "Scene", "AnimatorController"), nil hasta que se elige. Asset("sonidos/paso.wav"): el asset de esa ruta (o nil).

Global función

Global(name: string): any
La instancia del script --[Global] de esa clase (una por partida): Global("Rondas"):Sumar(id, 1). También con la ruta: Global("reglas/Rondas.luau").

IsServer función

IsServer(): boolean
true en el servidor: el dedicado, el anfitrión y también sin red (sin red se es servidor y cliente a la vez). Ahí van las reglas: vida, puntos, quién gana.

IsClient función

IsClient(): boolean
true en las máquinas con jugador: clientes, anfitrión y sin red. false en el servidor dedicado. Ahí van sonidos, efectos e interfaz.

GetPlayers función

GetPlayers(): {number}
Los ids de los jugadores de la partida. Con su nombre, ping y más: Network.Players().

GetPlayerName función

GetPlayerName(player: number): string?
El nombre de un jugador por su id (o nil si no está).

RegisterNetEvent función

RegisterNetEvent(name: string, handler: ((...any) -> ())?): EventHandle?
Acepta un evento desde la red y, opcionalmente, lo escucha: RegisterNetEvent("tienda:comprar", function(articulo) ... end). Los eventos que no se registran se descartan. En Nova la forma principal son las funciones --[Server], --[Client] y --[Multicast].

AddEventHandler función

AddEventHandler(name: string, handler: (...any) -> ()): EventHandle
Escucha un evento en esta máquina; devuelve un identificador para RemoveEventHandler. Eventos de la partida: gameStart, gameStop, playerJoined(id) y playerDropped(id, motivo) (en el servidor).

RemoveEventHandler función

RemoveEventHandler(handle: EventHandle): ()
Deja de escuchar un evento (con el identificador que devolvió AddEventHandler o RegisterNetEvent).

TriggerEvent función

TriggerEvent(name: string, ...: any): ()
Lanza un evento en esta máquina (no viaja por la red).

TriggerServerEvent función

TriggerServerEvent(name: string, ...: any): ()
Cliente → servidor: lanza un evento en el servidor (source = quien lo envía). El servidor tiene que registrarlo con RegisterNetEvent. Hasta 16 argumentos y 8 KB; 30 eventos por segundo de cada cliente.

TriggerClientEvent función

TriggerClientEvent(name: string, player: number, ...: any): ()
Servidor → un jugador (su id) o a todos (-1): TriggerClientEvent("tienda:comprado", source, articulo).

CancelEvent función

CancelEvent(): ()
Cancela el evento local que se está atendiendo para los manejadores que vienen detrás.

WasEventCanceled función

WasEventCanceled(): boolean
true si un manejador anterior canceló el evento que se está atendiendo.

RegisterServerCallback función

RegisterServerCallback(name: string, handler: (...any) -> ...any): ()
Servidor: registra una respuesta con nombre. Lo que devuelve la función es la respuesta (hasta 16 valores); source es quien pregunta. Los clientes preguntan con TriggerServerCallback.

TriggerServerCallback función

TriggerServerCallback(name: string, callback: (...any) -> (), ...: any): ()
Cliente: pregunta algo al servidor y llama a tu función con la respuesta: TriggerServerCallback("tienda:precio", function(precio) ... end, "espada"). Sin respuesta en 10 s se olvida con un aviso.

Spawn función

Spawn(prefab: Asset | string, position: Vec3?, rotation: Quat?, options: SpawnOptions?): Entity?
Solo en el servidor: crea un prefab con Identidad de red en el servidor y en todos los clientes: Spawn("prefabs/Bala", posicion, nil, { owner = source }). owner es su dueño (por defecto 0, el servidor). Cuando vuelve, el Awake de sus scripts ya ha pasado.

SetTimeout función

SetTimeout(ms: number, fn: () -> ()): ()
Llama a la función dentro de ms milisegundos de juego (en pausa no avanza): SetTimeout(500, function() ... end). Dentro se puede usar Wait.

CreateThread función

CreateThread(fn: () -> ()): ()
Ejecuta la función como una tarea que puede esperar con Wait(ms) sin parar el juego. Las tareas de una instancia terminan cuando se destruye.

Wait función

Wait(ms: number?): ()
Espera esos milisegundos de juego. Solo dentro de CreateThread o SetTimeout (fuera es un error que lo explica).

Loc función

Loc(key: string, params: { [string]: any }?): string
El texto de una clave de la tabla de idiomas (panel Idiomas) en el idioma actual: Loc("menu.jugar"). Con parámetros, los {nombre} del texto se cambian por su valor: Loc("hola", { nombre = jugador }). Si al idioma le falta el texto, sale el del idioma base; si la clave no existe, la propia clave (y un aviso en el registro).

Struct función

Struct(nameOrFields: string | { [string]: any }, fields: { [string]: any }?): StructType
Declara un tipo de datos con sus campos y sus valores por defecto: local Objeto = Struct({ nombre = "", precio = 0 }). Úsalo como campo (Botin.objeto = Objeto), en listas (List(Objeto)), en Data Assets y en Data Tables. Objeto({ precio = 5 }) crea un valor. Ver docs/datos.md.

List función

List(element: any, items: { any }?): any
Campo lista para el Inspector: List(Objeto), List(0), List(""), List(Entity()), List(Asset("Texture")). Segundo argumento opcional: los valores iniciales.

Dict función

Dict(value: any, items: { [string]: any }?): any
Campo diccionario (claves de texto): Dict(0), Dict(Objeto).

DataAsset función

DataAsset(name: string): any
Un Data Asset (asset .datos) por su nombre o su ruta: DataAsset("Lingote").precio.

Interface función

Interface(nameOrFunctions: string | {string}, functions: {string}?): InterfaceInfo
Interface("Recogible", { "AlCoger" }): declara un contrato. Un script lo cumple con Clase:Implements(Recogible) y se llama sin saber qué script es con Interfaces.Call. Sin nombre, el del fichero.

GetOwner función

GetOwner(player: number): Entity?
La entidad del personaje (objeto jugador) del jugador con ese id (source), o nil si no tiene (aún no ha cargado, la escena no tiene «Aparición de jugadores» o se fue). Funciona en el servidor y en los clientes: local yo = GetOwner(source) dentro de un [Server] o de un evento. Para el dueño de una entidad (al revés), Network.GetOwner(entidad).

GetOwnedEntities función

GetOwnedEntities(player: number): {Entity}
Los objetos de red de ese jugador: su personaje y lo creado con Spawn(prefab, pos, rot, { owner = id }) o pasado con Network.SetOwner.

GetPlayerEntity función

GetPlayerEntity(player: number): Entity?
La entidad del personaje del jugador con ese id (source), o nil. Es la misma que Network.GetPlayerEntity(id) y GetOwner(id): la que creó su «Aparición de jugadores» (PlayerSpawner) o, si no, la entidad con Identidad de red marcada como jugador cuyo dueño es ese jugador. Sin red, con el id del jugador local (0), el primer personaje marcado como jugador. Funciona en el servidor y en los clientes.

RegisterCommand función

RegisterCommand(name: string, handler: (player: number, args: {string}, line: string) -> (string | {string})?, options: CommandOptions?): ()
Registra un comando de consola: RegisterCommand("dinero", function(jugador, args) ... end, { servidor = true, admin = false, ayuda = "Da dinero" }). Se escribe en la consola del juego (tecla º o F1), en la línea de comandos del editor y en NovaServer. La función recibe el jugador que lo escribe, las palabras (args) y la línea entera; lo que devuelva (un texto o una lista) sale en su consola, también por la red. Con servidor = true se ejecuta en el servidor; con admin = true solo el anfitrión y los administradores; con truco = true se desactiva en el juego publicado (salvo que el proyecto lo permita).

CVar función

CVar(name: string, value: number | boolean | string, options: CVarOptions?): CVarObject
Declara una variable de consola: local vel = CVar("zombis.velocidad", 2.5, { ayuda = "...", replicada = true, min = 0, max = 10 }) y se lee con vel:Get(). Desde la consola: zombis.velocidad 4. replicada = true: la fija el servidor y llega a todos; guardar = true: se recuerda en las preferencias de esta máquina; vel:OnChanged(function(nuevo, viejo) end) avisa de cada cambio.

ExecuteCommand función

ExecuteCommand(line: string): ()
Ejecuta una línea como si se escribiera en la consola de esta máquina: ExecuteCommand("tp 0 10 0").

VLog función

VLog(entity: Entity?, name: string, value: any?): ()
Graba un valor de una entidad para el Visual Logger: VLog(self.entity, "vida", self.vida). Con dos argumentos, un mensaje de esa entidad: VLog(self.entity, "me han visto"). Solo cuenta mientras se graba (ventana Visual Logger del editor o VisualLogger.Start()); si no, no hace nada.

source campo

source: number?
Dentro de una función --[Server] (o de un manejador de un evento que llega de un jugador), el id del jugador que la llamó (0 = el propio servidor). En lo demás es nil. Cambia en cada llamada: cópialo a un local si lo necesitas después.
