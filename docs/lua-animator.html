Referencia de Lua · Componente

Animator

Animador: componente (Animación). Reproduce las animaciones de un modelo

entidad:GetComponent("Animator") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

model campo

Animator.model: Asset?
Modelo (en el Inspector).

controller campo

Animator.controller: Asset?
Controlador (en el Inspector).

clip campo

Animator.clip: string
Clip (en el Inspector). Sin controlador: nombre del clip (vacío = el primero)

speed campo

Animator.speed: number
Velocidad (en el Inspector). De 0 a 5.

loop campo

Animator.loop: boolean
Bucle (en el Inspector).

playInEditor campo

Animator.playInEditor: boolean
Previsualizar (en el Inspector). Animar también en el editor, sin pulsar Play

applyRootMotion campo

Animator.applyRootMotion: boolean
Root motion (en el Inspector). El desplazamiento horizontal del hueso raíz mueve la entidad (o su CharacterController) al jugar

rootMotionBone campo

Animator.rootMotionBone: string
Hueso raíz (en el Inspector). Hueso del root motion (vacío = el primero del esqueleto, normalmente las caderas)

entity campo

Animator.entity: Entity
La entidad que tiene este componente.

currentState campo

Animator.currentState: string
El estado en el que está.

normalizedTime campo

Animator.normalizedTime: number
Por dónde va el estado: 1 = un ciclo (en bucle sigue creciendo).

SetFloat método

Animator:SetFloat(name: string, value: number): (): ()
Cambia un parámetro decimal del controlador: animador:SetFloat("velocidad", v).

SetBool método

Animator:SetBool(name: string, value: boolean): (): ()
Cambia un parámetro booleano del controlador.

SetInt método

Animator:SetInt(name: string, value: number): (): ()
Cambia un parámetro entero del controlador.

SetTrigger método

Animator:SetTrigger(name: string): (): ()
Activa un disparador del controlador (se apaga solo al usarse).

ResetTrigger método

Animator:ResetTrigger(name: string): (): ()
Apaga un disparador que aún no se ha usado.

GetFloat método

Animator:GetFloat(name: string): number
El valor de un parámetro decimal.

GetBool método

Animator:GetBool(name: string): boolean
El valor de un parámetro booleano.

GetInt método

Animator:GetInt(name: string): number
El valor de un parámetro entero.

Play método

Animator:Play(state: string, fadeSeconds: number?): (): ()
Salta a un estado (con fundido opcional, 0,2 s por defecto). Sin controlador, reproduce ese clip del modelo fundiéndose desde el que sonaba.

CrossFade método

Animator:CrossFade(state: string, seconds: number): (): ()
Pasa a un estado fundiendo durante esos segundos. Sin controlador, funde el clip que sonaba con ese clip del modelo.

IsInState método

Animator:IsInState(state: string): boolean
true si está en ese estado.

GetBoneTransform método

Animator:GetBoneTransform(bone: string, space: BoneSpace?): (Vec3?, Quat?, Vec3?): ()
Posición, rotación y escala de un hueso (o nil si no existe): local pos, rot = animador:GetBoneTransform("RightHand"). Espacio: "world" (por defecto), "model" (respecto a la entidad) o "local" (respecto al hueso padre).

GetBoneNames método

Animator:GetBoneNames(): {string}
Los nombres de los huesos del modelo.

HasBone método

Animator:HasBone(bone: string): boolean
true si el modelo tiene un hueso con ese nombre (en un humanoide también vale el nombre de un hueso humano: "RightHand", "ManoDerecha").

HasSocket método

Animator:HasSocket(socket: string): boolean
true si el modelo tiene ese socket (de sus ajustes de importación, pestaña Sockets del espacio Animación).

GetSocketTransform método

Animator:GetSocketTransform(socket: string, space: BoneSpace?): (Vec3?, Quat?, Vec3?): ()
Como GetBoneTransform, pero solo para sockets: posición, rotación y escala del socket (o nil si no es un socket del modelo).

GetSocketNames método

Animator:GetSocketNames(): {string}
Los nombres de los sockets del modelo.

GetHumanBone método

Animator:GetHumanBone(humanBone: string): string?
El nombre del hueso del modelo que hace de un hueso humano (o nil): animador:GetHumanBone("RightHand") da "mixamorig:RightHand" en un personaje de Mixamo y "Mano_D" en otro. El id en español de antes ("ManoDerecha") vale, con un aviso de obsoleto.

IsHumanoid método

Animator:IsHumanoid(): boolean
true si el modelo es humanoide (sus huesos se reconocen): sus animaciones valen para otros humanoides y al revés.

SetLayerWeight método

Animator:SetLayerWeight(layer: string | number, weight: number): (): ()
Fija el peso de una capa (por nombre o por índice; 0 = "Base") de 0 a 1: animador:SetLayerWeight("Apuntar", 0.8). Su parámetro de peso lo sigue multiplicando.

GetLayerWeight método

Animator:GetLayerWeight(layer: string | number): number
El peso efectivo de una capa (por nombre o por índice).

ResetLayerWeight método

Animator:ResetLayerWeight(layer: string | number): (): ()
Vuelve al peso de la capa que dice el controlador (deshace SetLayerWeight).

GetLayerNames método

Animator:GetLayerNames(): {string}
Los nombres de las capas del controlador (la primera es "Base").

PlayInLayer método

Animator:PlayInLayer(layer: string | number, state: string, fadeSeconds: number?): (): ()
Salta a un estado en una capa, con fundido (0,2 s si no se indica): animador:PlayInLayer("Brazos", "Recargar").

GetLayerState método

Animator:GetLayerState(layer: string | number): string
El estado actual de una capa.

GetRootMotion método

Animator:GetRootMotion(): Vec3
Desplazamiento del root motion del último frame, en el mundo.

SetFloat2 método

Animator:SetFloat2(parameterX: string, parameterY: string, x: number, y: number): (): ()
Cambia los dos parámetros de un árbol de mezcla 2D de una vez: animador:SetFloat2("velX", "velZ", v.x, v.z).

GetFloat2 método

Animator:GetFloat2(parameterX: string, parameterY: string): (number, number): ()
Lee dos parámetros a la vez: local x, y = animador:GetFloat2("yaw", "pitch").

SetFootIK método

Animator:SetFootIK(enabled: boolean, weight: number?): (): ()
Activa (true, con un peso de 0 a 1 opcional) o apaga (false) el IK de pies de este Animador, aunque el controlador diga otra cosa: los pies se apoyan en escalones y rampas. Las capas con «IK de pies» desactivado lo siguen bajando mientras pesan.

ResetFootIK método

Animator:ResetFootIK(): (): ()
Vuelve al IK de pies que dice el controlador (deshace SetFootIK).

GetFootIKWeight método

Animator:GetFootIKWeight(): number
El peso del IK de pies en el último frame (0 = apagado o sin suelo debajo).

SetIKTarget método

Animator:SetIKTarget(name: string, target: Vec3 | Entity | nil, socket: (string | number)?, weight: number?): (): ()
Objetivo de una cadena de IK de este personaje: animador:SetIKTarget("LeftHand", arma, "Grip") pone la mano izquierda en la hija «Grip» (o el socket) del arma. El objetivo es un Vec3 (mundo), una Entity o nil (la apaga). Si el componente IK no tiene esa cadena y el nombre es un hueso humano ("LeftHand", "RightHand", "LeftFoot", "RightFoot") o uno del modelo, la crea. El peso (0 a 1) va al final: SetIKTarget("LeftHand", grip, 0.5).
