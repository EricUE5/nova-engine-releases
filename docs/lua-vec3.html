Vec3

Vector 3D (el vector nativo de Luau: no reserva memoria). + - * / funcionan; v.x, v.y, v.z. Los vectores son valores: t.position.x = 1 no cambia nada, escribe el vector entero.

new función

Vec3.new(x: number?, y: number?, z: number?): Vec3
Un vector nuevo: Vec3.new(1, 2, 3).

zero campo

Vec3.zero: Vec3
(0, 0, 0)

one campo

Vec3.one: Vec3
(1, 1, 1)

up campo

Vec3.up: Vec3
(0, 1, 0): arriba

down campo

Vec3.down: Vec3
(0, −1, 0): abajo

right campo

Vec3.right: Vec3
(1, 0, 0): derecha

left campo

Vec3.left: Vec3
(−1, 0, 0): izquierda

forward campo

Vec3.forward: Vec3
(0, 0, −1): delante (las cámaras miran hacia −Z)

back campo

Vec3.back: Vec3
(0, 0, 1): detrás

positiveInfinity campo

Vec3.positiveInfinity: Vec3
(∞, ∞, ∞): el punto de partida para buscar un mínimo.

negativeInfinity campo

Vec3.negativeInfinity: Vec3
(−∞, −∞, −∞): el punto de partida para buscar un máximo.

Dot función

Vec3.Dot(a: Vec3, b: Vec3): number
Producto escalar.

Cross función

Vec3.Cross(a: Vec3, b: Vec3): Vec3
Producto vectorial.

Length función

Vec3.Length(v: Vec3): number
Longitud del vector.

LengthSq función

Vec3.LengthSq(v: Vec3): number
Longitud al cuadrado (más barata para comparar).

Normalize función

Vec3.Normalize(v: Vec3): Vec3
El vector con longitud 1 (la misma dirección).

Lerp función

Vec3.Lerp(a: Vec3, b: Vec3, t: number): Vec3
De a a b según t (0 = a, 1 = b).

Distance función

Vec3.Distance(a: Vec3, b: Vec3): number
Distancia entre dos puntos.

DistanceSq función

Vec3.DistanceSq(a: Vec3, b: Vec3): number
Distancia al cuadrado (más barata para comparar: Vec3.DistanceSq(a, b) < 25 es «a menos de 5 m»).

Angle función

Vec3.Angle(a: Vec3, b: Vec3): number
Ángulo entre dos vectores, en grados.

SignedAngle función

Vec3.SignedAngle(from: Vec3, to: Vec3, axis: Vec3): number
Ángulo en grados de desde a hasta girando alrededor de eje: positivo en sentido antihorario mirando desde la punta del eje (−180 a 180).

Min función

Vec3.Min(a: Vec3, b: Vec3, ...Vec3): Vec3
El mínimo de cada componente (de dos o más vectores).

Max función

Vec3.Max(a: Vec3, b: Vec3, ...Vec3): Vec3
El máximo de cada componente (de dos o más vectores).

MoveTowards función

Vec3.MoveTowards(from: Vec3, to: Vec3, maxStep: number): Vec3
Acerca desde a hasta como mucho pasoMaximo metros.

Project función

Vec3.Project(v: Vec3, onNormal: Vec3): Vec3
La parte del vector en la dirección de normal (su proyección).

ProjectOnPlane función

Vec3.ProjectOnPlane(v: Vec3, planeNormal: Vec3): Vec3
El vector sin su parte en la dirección de normal: movimiento pegado a una pendiente.

Reflect función

Vec3.Reflect(direction: Vec3, normal: Vec3): Vec3
La dirección reflejada en una superficie con esa normal (rebotes).

ClampMagnitude función

Vec3.ClampMagnitude(v: Vec3, maxLength: number): Vec3
El vector con la longitud limitada a maxima.

Slerp función

Vec3.Slerp(a: Vec3, b: Vec3, t: number): Vec3
Interpolación esférica: gira la dirección de a a b por el camino corto y la longitud pasa de una a otra (t de 0 a 1).

RotateTowards función

Vec3.RotateTowards(current: Vec3, target: Vec3, maxRadians: number, maxMagnitude: number?): Vec3
Gira actual hacia objetivo como mucho radianesMaximos y cambia su longitud como mucho longitudMaxima (en radianes).

SmoothDamp función

Vec3.SmoothDamp(current: Vec3, target: Vec3, velocity: Vec3, smoothTime: number, dt: number, maxSpeed: number?): (Vec3, Vec3)
Un muelle crítico para posiciones: pos, self._vel = Vec3.SmoothDamp(pos, objetivo, self._vel, 0.3, dt) (cámaras que siguen sin pasarse).

Scale función

Vec3.Scale(a: Vec3, b: Vec3): Vec3
Producto componente a componente (igual que a * b).

Abs función

Vec3.Abs(v: Vec3): Vec3
El valor absoluto de cada componente.

Floor función

Vec3.Floor(v: Vec3): Vec3
Cada componente redondeada hacia abajo (casillas de una rejilla).

Ceil función

Vec3.Ceil(v: Vec3): Vec3
Cada componente redondeada hacia arriba.

Round función

Vec3.Round(v: Vec3): Vec3
Cada componente redondeada al entero más cercano.

Clamp función

Vec3.Clamp(v: Vec3, min: Vec3, max: Vec3): Vec3
Cada componente limitada entre la de min y la de max.

Sum función

Vec3.Sum(v: Vec3): number
x + y + z.

Approximately función

Vec3.Approximately(a: Vec3, b: Vec3, epsilon: number?): boolean
true si los dos vectores están a menos de margen (0,00001 por defecto).
