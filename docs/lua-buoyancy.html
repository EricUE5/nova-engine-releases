Referencia de Lua · Componente

Buoyancy

Flotación: componente (Física). Flota en el agua (mar, lagos y ríos) con las mismas olas que se ven: con un cuerpo rígido dinámico, o siguiendo las olas sin físicas

entidad:GetComponent("Buoyancy") lo devuelve con todos sus campos (o nil). Cambiar un campo jugando tiene efecto al momento.

mode campo

Buoyancy.mode: "Física" | "Seguir las olas"
Modo (en el Inspector). Física: empuje, frenado y corriente sobre el cuerpo rígido. Seguir las olas: coloca e inclina la entidad (decorados, boyas)

volume campo

Buoyancy.volume: number
Volumen (en el Inspector). m³ que desplaza hundido del todo (0 = el de su colisionador) De 0 a 10000.

buoyancy campo

Buoyancy.buoyancy: number
Flotabilidad (en el Inspector). Multiplica el empuje (1 = Arquímedes) De 0 a 10.

waterDensity campo

Buoyancy.waterDensity: number
Densidad del agua (en el Inspector). kg/m³ (agua dulce 1000, de mar 1025) De 1 a 5000.

linearDrag campo

Buoyancy.linearDrag: number
Frenado (en el Inspector). Lo que frena el agua (1/s con todo el cuerpo hundido) De 0 a 50.

angularDrag campo

Buoyancy.angularDrag: number
Frenado del giro (en el Inspector). De 0 a 50.

currentFactor campo

Buoyancy.currentFactor: number
Corriente (en el Inspector). Cuánto lo arrastra la corriente de un río De 0 a 1.

points campo

Buoyancy.points: { Vec3 }
Puntos (en el Inspector). Puntos de muestreo (locales). Vacío = una rejilla en la caja del colisionador Es una copia: para cambiarla, asigna la lista entera.

heightOffset campo

Buoyancy.heightOffset: number
Altura sobre el agua (en el Inspector). De -50 a 50.

tilt campo

Buoyancy.tilt: number
Inclinación (en el Inspector). Cuánto se inclina con las olas (0 = siempre recto) De 0 a 1.

smoothing campo

Buoyancy.smoothing: number
Suavizado (en el Inspector). Segundos De 0 a 5.

drift campo

Buoyancy.drift: boolean
Dejarse llevar (en el Inspector). Avanza con la corriente de los ríos

submerged campo

Buoyancy.submerged: number
Hundido (en el Inspector). Fracción hundida (al jugar)

inWater campo

Buoyancy.inWater: boolean
En el agua (en el Inspector).

hasRest campo

Buoyancy.hasRest: boolean
Has Rest (en el Inspector).

restRotation campo

Buoyancy.restRotation: Quat
Rest Rotation (en el Inspector).

entity campo

Buoyancy.entity: Entity
La entidad que tiene este componente.
