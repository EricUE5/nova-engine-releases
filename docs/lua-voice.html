Voice

Chat de voz de la partida en red: voz de proximidad que sale del personaje de cada jugador (más baja cuanto más lejos, con panorama y, si quieres, apagada tras las paredes) y canales sin distancia para llamadas «por teléfono», intercomunicadores o radios, con su efecto. La voz va comprimida con Opus (~24 kbit/s) por la red del motor (IP, Steam o Nova Enlace) y el servidor solo se la manda a quien la oye. Los eventos OnVoiceStart(jugador) y OnVoiceStop(jugador) llegan con AddEventHandler en cada cliente. Guía: docs/voz.md.

SetEnabled función

Voice.SetEnabled(on: boolean): ()
Enciende o apaga tu micrófono: con true se abre y tu voz se envía cuando hablas (o mientras pulsas la tecla, con SetPushToTalk). Las voces de los demás se oyen siempre (para no oír a alguien, Voice.Mute). Empieza apagado: llámalo cuando el jugador lo active en las opciones. Vale también para las escenas siguientes.

IsEnabled función

Voice.IsEnabled(): boolean
true si tu micrófono está encendido (Voice.SetEnabled).

SetPushToTalk función

Voice.SetPushToTalk(on: boolean, action: string?): ()
Modo de tu micrófono: true = pulsar para hablar (solo se envía mientras está pulsada la acción action de Entrada, "HablarVoz" si no se pone; si el proyecto no tiene esa acción, la tecla V); false = micrófono abierto (se envía cuando detecta voz; la sensibilidad se cambia con SetThreshold).

IsPushToTalk función

Voice.IsPushToTalk(): boolean
true si estás en modo pulsar para hablar.

SetInputDevice función

Voice.SetInputDevice(name: string?): ()
Elige el micrófono por su nombre (uno de Voice.GetInputDevices()); nil vuelve al predeterminado de Windows. Si ese micrófono ya no está, se usa el predeterminado.

GetInputDevice función

Voice.GetInputDevice(): string?
El micrófono elegido con SetInputDevice, o nil si es el predeterminado de Windows.

GetInputDevices función

Voice.GetInputDevices(): {string}
Los nombres de los micrófonos del equipo, para un desplegable de opciones. Vacía en un servidor dedicado o sin sonido.

SetInputVolume función

Voice.SetInputVolume(volume: number): ()
Volumen de tu micrófono, de 0 a 2 (1 = tal cual). Además el motor ajusta solo la ganancia (sube la voz baja y baja la fuerte).

GetInputVolume función

Voice.GetInputVolume(): number
Volumen de tu micrófono (0 a 2).

SetOutputVolume función

Voice.SetOutputVolume(volume: number): ()
Volumen de las voces de los demás, de 0 a 2 (además del bus "Voice" de Audio.SetBusVolume).

GetOutputVolume función

Voice.GetOutputVolume(): number
Volumen de las voces de los demás (0 a 2).

SetThreshold función

Voice.SetThreshold(threshold: number): ()
Sensibilidad del micrófono abierto, de 0 a 1: más alto, hace falta hablar más fuerte para que se envíe (menos ruido de fondo); más bajo, se envía también lo flojo. Por defecto 0.5. Usa Voice.GetLevel() para enseñar una barra mientras se prueba.

GetThreshold función

Voice.GetThreshold(): number
Sensibilidad del micrófono abierto (0 a 1).

SetVolume función

Voice.SetVolume(player: number, volume: number): ()
Volumen de lo que oyes de un jugador, de 0 a 2 (1 = normal). Solo en tu máquina.

GetVolume función

Voice.GetVolume(player: number): number
Volumen con el que oyes a ese jugador (0 a 2).

Mute función

Voice.Mute(player: number, on: boolean?): ()
Silencia (true, o sin segundo argumento) o vuelve a oír (false) a un jugador. Solo para ti: el servidor deja de mandarte su voz.

IsMuted función

Voice.IsMuted(player: number): boolean
true si has silenciado a ese jugador.

IsSpeaking función

Voice.IsSpeaking(player: number?): boolean
true si ese jugador está hablando ahora (te llega su voz). Sin argumento, o con tu id, si tú estás enviando voz.

GetLevel función

Voice.GetLevel(player: number?): number
Nivel de la voz de ese jugador de 0 a 1 (para un icono o una barra que se mueve al hablar); 0 si no habla. Sin argumento, o con tu id, el nivel de tu micrófono aunque no estés enviando (para la prueba de micrófono de las opciones).

SetProximity función

Voice.SetProximity(options: VoiceProximity): ()
Voz de proximidad: hasta min metros (2) se oye entera, desde ahí baja en línea recta hasta max (18), donde ya no se oye y el servidor ni la envía. Con occlusion = true, si hay una pared entre los dos (un rayo de físicas) se oye más baja y apagada. Llámalo en el servidor (o en un script que corre en todos): el servidor manda sus valores a los clientes.

GetProximity función

Voice.GetProximity(): { min: number, max: number, occlusion: boolean }
Los valores de la voz de proximidad: { min, max, occlusion }.

SetChannel función

Voice.SetChannel(player: number, channel: string?, options: { mix: boolean? }?): boolean
Servidor. Mete a un jugador en un canal ("llamada1", "equipo"...) o lo saca (nil). Los del mismo canal se oyen entre ellos sin distancia, como por teléfono, y mientras están en un canal no oyen ni se les oye por proximidad; con { mix = true } también siguen en la proximidad. Devuelve false si no se pudo. Los canales se borran al cambiar de escena.

GetChannel función

Voice.GetChannel(player: number): string?
Servidor. El canal de ese jugador, o nil si no está en ninguno.

SetEffect función

Voice.SetEffect(target: string | number, effect: VoiceEffect?): boolean
Servidor. Efecto de un canal (Voice.SetEffect("llamada1", "phone"): solo lo que se oye por ese canal) o de un jugador (Voice.SetEffect(jugador, "radio"): todo lo que dice, también por proximidad). "phone", "intercom" o "radio" (paso banda, distorsión y algo de ruido; la radio hace un chasquido al soltar); nil lo quita.

GetStats función

Voice.GetStats(): VoiceStats
Estadísticas de la voz en esta máquina: kbit/s de subida y de bajada, tramas enviadas y paquetes recibidos, lo que reenvió el servidor y lo que descartó por el límite de ancho de banda, y los milisegundos de CPU del códec por trama de 20 ms.
